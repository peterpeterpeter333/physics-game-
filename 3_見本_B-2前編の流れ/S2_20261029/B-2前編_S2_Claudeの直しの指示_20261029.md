## 1. 一番大きな直し：カエルの足を主役の大きさにする（行9〜11・20〜21・25・28・43）

**今**：
- 机の上の板に、カエル1匹ぶんの緑の体が寝ていて、カメラは高く遠い所から見ています。足は横幅の2〜3割です。
- 行10・11 の寄りの画は、2本の棒の先がふれ合う所だけで、後ろの足はぼけた緑の塊です。棒が足のどこに当たっているか（真鍮＝神経、鉄＝足の肉）と、棒の反対の先どうしがふれ合うことの、2つの関係が1つの画に入っていません。
- 「ぴくっとけります」の動きも、全景では小さくて見えません。

**直し方**：
- **足の模型**：後ろ足1本（ももから先）にする。体全体は要りません。足の付け根から出る白い神経を、太めに見せる（横幅の2％以上）。
- **カメラ**：
  - 机に近い低い角度（仰角20〜30°）。
  - 足の横幅は、画面の横幅の5.5〜6.5割。
  - 説明の間は止める。
- **棒の当たる所と、輪の形を1つの画に入れる**（行10「真鍮の棒を当てます」〜「ふれ合わせると」）：
  - 真鍮の棒（金色）の先は神経に、鉄の棒（灰色）の先は足の肉に当たる。2本の棒の反対の先は、V の字のように寄ってきてふれ合う。
  - 神経 → 真鍮 → ふれ合う所 → 鉄 → 足の肉 → 足の中 → 神経、の輪の全部が1つの画に入る構図にする。
  - 札「真鍮」「鉄」「神経」は、それぞれの物に引出線で付ける。
  - ふれ合う所の寄り（今の行10・11 の画）は、1.0秒だけ使い、すぐに輪の全体へ戻る。
- **ぴくっ**：足先が、ひざから25〜35°はね上がる（0.15秒で上がり、0.4秒で戻る）。「ぴくっ」の語の0.1秒前より先に動かさない。離した時は動かない。

## 2. テレラ（行2〜8）

**今**：
- 球が真っ黒な塊で、地球にも磁石にも見えません。
- 置いた方位磁針は、横幅の5％ほどしかありません。
- 赤いてっぺん（磁石のN極）が上にあるので、地球が逆さまに見えます。「地球の北にあるのは、磁石のS極」と言う所（行4）で、見る人が北と南を取り違えます。
- 行5 の力の線は、左は小さな輪、右は大きな輪で、左右がそろっていません。球も横幅の2.5割と小さいです。

**直し方**：
- **向き**：
  - 地球と同じく、北を上にする。
  - 上（北）に青い S 極、下（南）に赤い N 極を置く。
  - B-1 のテレラと色の決まり（赤＝N、青＝S）は同じにする。
  - 球の表面に、うすく大陸の形を描く（地球の模型だと分かる程度）。
  - 札「北」「南」は大きく（ほかの札と同じ文字の大きさ）、球のすぐ外に付ける。
- **行2〜3（小さな方位磁針を置く）**：方位磁針に寄る（横幅の2.5割以上）。
- **行4（一段目）**：今の透明な球と棒磁石の画はよい。北を上にした向きで描き直す。
- **行5（二段目）**：
  - 球を横幅の4.5割以上にする。
  - 線は左右対称に、南（N）から出て北（S）へ入る形を4〜6本描く。
  - 「N極から出て」「S極へ入ります」の語で、線の上を光の粒が流れる。
- **行6〜7（三段目・四段目）**：
  - 方位磁針を置く所は、球の下半分（南半球、オーストラリア）にする。
  - 寄りの画には、球の輪郭の一部と、地面（その場所の水平）を表す白い線を入れる。
  - 針の北を向く先（赤）が、白い水平の線より上に傾くのが見えるようにする。
- **行8（北半球のロンドンとは）**：
  - 球の上半分（ロンドン）にも方位磁針を置く。
  - 2つの寄りを左右に並べて、比べる：ロンドン「下に 傾く」、オーストラリア「上に 傾く」。

## 4. 段階報告 7章（台本の保留）への答え
台本・声・字幕の文言は、どれも変えません。

1. **行15「管を流れる水の量が、電流」**：札だけ「流れる 量（1秒に どれだけ）＝ 電流」にする。管の中を流れる水のつぶの速さで、量の違いが見えるとよい。
2. **行28・34「カエルの電気ではない」の論理**：台本の行36 で「崩れたのは、ガルヴァーニの考えのうち、〜という所」と限っています。この範囲で十分です。画は今のとおりでよい。
3. **行33 の検電器の操作**：上の2枚の板は、本物に近い形なので残す。札「電気を ためる 板」だけ足す（3章の表）。操作の説明は足さない。
4. **行39「びりびりが続きます」**：台本どおり。画は3章の表のとおり。
5. **安全**：3章の表のとおり、指や電気魚にさわる画に、注記「まねを しない」を付ける。説明欄への追加は、ユーザーが公開の時に決めます。
