## 全体の傾向

### 高校力学（作り直し済み。今回は変更しない）
- 式変形を一段ずつ見せる丁寧さと、絵から式を作る場面の質は高い。読み（ふりがな）の誤りは434文でゼロ。
- 弱点：冒頭がほぼ全本「今回は、〜を確かめます」で単調。「私たちは」の翻訳調。上級の式変形が長すぎる（11段）。
- 内容の抜け：垂直抗力・張力・摩擦・斜面、力のモーメント、反発係数、慣性力、単振り子。エネルギー章の本編に ½mv²・mgh が出ない。
- 同じ音の記号（振幅 A と加速度 a、G と g）が耳で区別できない。

### 大学力学（旧動画）— 差し替えの理由
1. **画面とナレーションの食い違い**が最大の問題。台本の「見せたい動き」がほとんど描かれず、別単元の図の流用やほぼ静止画が30秒続く。
2. **物理の誤りが画面にある**：v–t グラフの面積に「増えた速度の分」（正しくは進んだ距離）、慣性力 −mA の矢印が前向き、衝突後も運動量の矢印が変わらない、振り子に張力が描かれない、「反発する」題名なのに台車がくっつく。
3. **数式が素の文字**（`d(r×p)/dt`、`∫[t前→t後]`）で、文字と図の重なりが多い。
4. **読み**：ふりがな指定がなく、「同じ力」→「おなじりょく」、「前と後」→「ぜんご」、「値」→「ね」、「和」→「やわ」、「五分の二」→「ごふんのに」などの誤読の危険。
5. **順序**：万有引力が紹介前に使われる、初級に外積・積分・慣性テンソル、自動生成の初級・中級段が「復習3枚」だけ、など。

## 対応

- 大学力学の動画43本を、`docs/video-revision-20260924/umech/` の新しい台本と `scripts/umech/` の新しいアニメーションで作り直した（執筆ルールは [../AUTHORING.md](../AUTHORING.md)）。
  - 題名は問い、1文1考え、記号は声で読む、色は量ごとに固定、式は図から組み立てる、式の変形は差分だけが動く。
  - 読みは全文をひらがなで指定し、`scripts/umech/check-readings.py` で Nemo の実際の発音と照合（不一致0）。
- 大学力学のレッスン本文の物理の誤り・誤解を招く言い回しを修正した（月の距離、重力の仕事、負号の意味など）。
- カリキュラムの並べ替え（単元の分割・移動）は影響が大きいため行っていない。推奨順は各報告の「順序」の項を参照。
