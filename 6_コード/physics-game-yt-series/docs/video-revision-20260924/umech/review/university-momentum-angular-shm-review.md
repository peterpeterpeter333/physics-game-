## A) トピックごとの総評

**uc-momentum（運動量と力積）**
- 中級の既存ステージ um-momentum-change は、0.15 kg・±20 m/s・600 N→60 N と具体的で、この3トピックの中で最も良い教材です。
- 一方で、初級動画は運動量 p=mv を定義しないまま「運動量保存」と「系の境界」から始まります。偏差値30の生徒には何が保存されるのかが見えません。
- 動画は3本中2本が同じ台車アニメです。衝突後も p₁→ と p₂← の矢印が同じ長さで残り、上級は題名が「反発する」なのに台車がくっつきます。絵が物理とナレーションの両方に合っていません。
- 中級動画は、場面3のナレーション「平均の力が同じでも Δp は違う」と、画面の「面積一定で高さが下がる」が逆のことを言っています。
- 台本案（差し替え台本_06）の mc-why-12・13 は数値も正しく良い内容です。ただし初級動画は【そのまま】の扱いで、p=mv の定義と絵の修正が抜けています。

**uc-angular（トルクと角運動量）**
- 前提が崩れています。高校編（mechanics.ts）には力のモーメントも角速度 ω も無いのに、復習スライドと mc-link-06 は「高校の力のモーメントが大学のトルク」として既習扱いです。
- 初級のスライドに外積 N=r×F と sinθ が入っていて、「外積が怖い」生徒が初級で止まります。
- 動画の問題：
  - 中級の3D図は汎用の外積部品のままで、ラベルが A・B・A×B（r・p・L ではない）です。
  - 中級には未習の慣性モーメント I を使った I dω/dt=N が出ます。
  - トルクの記号が N と τ で混在し、同じ動画の中でも両方出ます。
  - 初級は「作用線」「垂直な距離」「基準点を移す」と言いますが、画面にはどれも描かれていません。
- 上級動画の楕円と扇形（面積速度）は、太陽を焦点に置いた正しい図で良い素材です。ただ文字が楕円に重なり、2つの扇形を並べて比べる場面がありません。

**uc-shm（振り子と振動）**
- 初級動画は問いが「張力？重力？」なのに、張力の矢印が一度も描かれません。
- 初級動画には中級の式 ml(d²θ/dt²)=−mg sinθ が常に表示され、初級の目標である「エネルギーの交換」はまったく出てきません。
- 中級動画は初級と同じ絵の使い回しです。ナレーションの「左右に質量が入る」は、振り子が左右に振れる話と混同されます。
- 上級動画は、台本の見た目指定（外力の振動数 Ω を変えて曲線を描く、抵抗係数 b でピークを比べる、流入と損失を色分け）が実装されておらず、静止した共振曲線だけです。「無限とは限らない」という問いの前提（抵抗が無いと振幅が際限なく育つ）も一度も見せていません。
- 高校 m-shm の「振り子の周期は振幅によらない」には小角の条件が無く、大学側の説明と矛盾します。
- 台本案の mc-why-16・17 と中級場面3の差し替えは、数値を検算して正しいことを確認しました（sin0.1=0.0998、共振の振幅0.33・1.25・0.19、周期2.0 s と 4.0 s）。ただし、絵の実装漏れにはまったく触れていません。

**ui-turning-motion（向きだけ変える力）**
- スライドは丁寧です。
- 動画は、速度の変化 Δv が中心を向く「決め手の絵」がなく、dW=F·dr の式が文字だけで出ます。
- 初級なのに内積の記号が出ます。

## C) 各動画の作り直し案（3Blue1Brown風）

色の約束（全動画共通）：力＝赤、速度＝水色、運動量＝シアンの太矢印、位置 r＝白、トルク・角運動量＝黄、運動エネルギー K＝緑の棒、位置エネルギー U＝橙の棒、外力＝赤の破線。

**1. uc-momentum-intro**
- 問い：「氷の上で、体重60 kgの人と30 kgの子が押し合ったら、どっちが速く滑る？」
- 場面1
  - 見せるもの：押し合う2人。
  - 動くもの：押している間、同じ長さの赤い矢印が逆向きに出る。
  - できる式：F₁₂ = −F₂₁
  - 決めの一言：「押す力はいつも同じ大きさ、逆向き。」
- 場面2
  - 見せるもの：勢いの矢印 p=mv。
  - 動くもの：60 kg×1 m/s と 30 kg×2 m/s の矢印が同じ長さで逆向きに伸びる。白い「合計」矢印は0のまま。
  - できる式：p=mv、p₁+p₂=0（前）=0（後）
  - 決めの一言：「軽い子は2倍の速さで同じ勢い。」
- 場面3
  - 見せるもの：2人を箱（系）で囲む。
  - 動くもの：床の摩擦（赤い破線）を加え、押し合う時間が短いほど、摩擦×時間の小さな長方形が細ることを見せる。
  - できる式：外力の力積 ≈ 0 → 合計 p は一定
  - 決めの一言：「保存するかは、どこまでを一組と囲むかで決まる。」
- 前提の橋渡し：右を＋とする速度の符号、作用反作用（高校）。

**2. uc-momentum-middle**
- 問い：「同じ卵を床と布団に落とす。卵が受ける『変化』は同じなのに、なぜ割れ方が違う？」
- 場面1
  - 見せるもの：速度計の矢印が Δt の間に縮む。
  - できる式：F=ma、a=Δv/Δt → FΔt = mΔv = Δp
  - 決めの一言：「力×時間が、勢いの変化。」
- 場面2
  - 見せるもの：山型の F(t) 曲線を短冊に分け、短冊を1本ずつ足して面積を積み上げる。
  - できる式：Δp ≈ ΣFᵢΔtᵢ → ∫F dt
  - 決めの一言：「力が変わっても、面積を足せばいい。」
- 場面3
  - 見せるもの：面積6.0のまま、幅を0.010 s から0.10 s に引き伸ばす。
  - 動くもの：高さが600 N から60 N に下がる。
  - できる式：F平均=Δp/Δt
  - 決めの一言：「布団は Δp を変えず、時間を伸ばす。」
- 前提の橋渡し：面積＝掛け算の合計、跳ね返りの符号（−20→+20で差は40）。

**3. uc-momentum-advanced**
- 問い：「ビリヤードで、同じ重さの球を正面からぶつけると、当てた球がピタッと止まるのはなぜ？」
- 場面1
  - 見せるもの：p₁ と p₂ の棒グラフ。
  - 動くもの：衝突中、片方の棒が減った分だけもう片方が増える。合計の棒は動かない。
  - できる式：m₁u₁+m₂u₂=m₁v₁+m₂v₂
  - 決めの一言：「内側の押し合いは合計を変えない。」
- 場面2
  - 見せるもの：衝突後の速度 v₁・v₂ に「？」が2つ、式は1本。
  - 動くもの：e を 0→0.5→1 と動かし、近づく相対速度と離れる相対速度の矢印の比が変わる。
  - できる式：v₂−v₁=e(u₁−u₂)
  - 決めの一言：「弾み具合は材料が決める、もう1本の式。」
- 場面3
  - 見せるもの：2 kg・3 m/s の台車と、静止した1 kg の台車（e=0.5）で連立を解く。
  - 動くもの：代入すると v₁=1.5、v₂=3.0。運動エネルギーの棒は 9→6.75 J。さらに e=1・同じ質量にすると速度が入れ替わり、問いに答える。
  - できる式：v₁=[(m₁−em₂)u₁+(1+e)m₂u₂]/(m₁+m₂)
  - 決めの一言：「e=1・同じ質量なら速度を交換。」
- 前提の橋渡し：連立一次方程式の代入、相対速度。

**4. uc-angular-intro**
- 問い：「ドアを蝶番のすぐそばで押すと、なぜ開かない？」
- 場面1
  - 見せるもの：上から見たドア。
  - 動くもの：押す点が蝶番から端へ滑り、同じ1秒で回る角度の棒が伸びる。
  - できる式：τ = F×d
  - 決めの一言：「同じ力でも、遠くを押すほどよく回る。」
- 場面2
  - 見せるもの：力の矢印の作用線（点線）。
  - 動くもの：力の向きを回すと、蝶番から作用線への垂線 d が縮み、蝶番を向いたとき d=0 になる。
  - できる式：d = r sinθ → τ = rF sinθ
  - 決めの一言：「軸をまっすぐ狙う力は回さない。」
- 場面3
  - 見せるもの：シーソー。
  - 動くもの：支点を動かすと、同じおもりでも τ の数値（0.8 m×10 N=8 N·m、30°なら4 N·m）が変わる。
  - できる式：τ は基準点で変わる
  - 決めの一言：「まず『どこを中心に回すか』を決める。」
- 前提の橋渡し：直角・垂線、掛け算。高校で力のモーメントを習っていない前提で作る。

**5. uc-angular-middle**
- 問い：「回っているものの『回る向き』を、1本の矢印で書けるだろうか？」
- 場面1
  - 見せるもの：円運動する質点。
  - 動くもの：r（白）と p（シアン）が張る平行四辺形。右手の指を r→p に巻くと、親指の黄色い L が面から立ち上がる。
  - できる式：L=r×p、|L|=rp sinθ
  - 決めの一言：「回る面に垂直な矢印が、回転の向き。」
- 場面2
  - 見せるもの：p の代わりに F を置く。
  - 動くもの：τ が L と同じ向きなら L の矢印が伸び、逆向きなら縮む。
  - できる式：τ=r×F
  - 決めの一言：「L は回転の勢い、τ はそれを変える原因。」
- 場面3
  - 見せるもの：数値の確認。
  - 動くもの：2 kg・3 m・4 m/s の円運動で L=24。p を r に平行に傾けていくと L→0。
  - できる式：円運動なら L=mrv（sin90°=1）
  - 決めの一言：「直角なら掛けるだけ、平行ならゼロ。」
- 前提の橋渡し：外積の右手ルール（数学の um-cross）、sinθ＝直角成分の割合。

**6. uc-angular-advanced**
- 問い：「彗星は太陽の近くで猛スピード、遠くではのろのろ。誰がブレーキを踏んでいる？」
- 場面1
  - 見せるもの：L=r×p の時間変化を2つの項に分ける。
  - 動くもの：v と mv の矢印が重なり、平行四辺形がつぶれて0になる。
  - できる式：dL/dt = v×mv + r×F = τ
  - 決めの一言：「速度と運動量は同じ向き、だから消える。」
- 場面2
  - 見せるもの：楕円軌道の各点。
  - 動くもの：重力は r と同じ直線上（逆向き）なので、平行四辺形がぺしゃんこ。黄色い L の矢印が凍りついたように一定。
  - できる式：τ=0 → L 一定
  - 決めの一言：「中心を引く力は、回転の勢いを変えられない。」
- 場面3
  - 見せるもの：同じ時間に掃く扇形を、近日点側と遠日点側に並べる。
  - 動くもの：扇形を三角形 ½·r·v⊥dt に近似。面積の数値が一致する。
  - できる式：dA/dt = L/(2m)。数値は r=1・v=4 と r=2・v=2
  - 決めの一言：「遠いほどゆっくり、面積は同じ。」
- 前提の橋渡し：積の微分、同じ向きの外積は0。

**7. uc-shm-intro**
- 問い：「振り子を真ん中へ引き戻すのは、糸？重力？」
- 場面1
  - 見せるもの：糸の張力 T（糸方向）と mg。
  - 動くもの：mg を「糸方向」と「弧に沿う方向」に分解する。
  - できる式：弧方向の力 = −mg sinθ
  - 決めの一言：「糸は円からはみ出さない係、戻すのは重力の弧方向の分。」（注：糸方向は T−mg cosθ=mv²/ℓ で、打ち消し合うわけではない）
- 場面2
  - 見せるもの：振れる振り子と、U（橙）・K（緑）の棒。
  - 動くもの：最下点で弧方向の力が0、速度矢印が最大。U と K の棒が入れ替わり、合計の線は一定。
  - できる式：K+U=一定
  - 決めの一言：「力がゼロでも、勢いで通り過ぎる。」
- 場面3
  - 見せるもの：y=sinθ と y=θ のグラフ。
  - 動くもの：原点を拡大すると2本がほぼ重なる（0.1 rad→0.0998、0.2 rad→0.199）。
  - できる式：mg sinθ ≈ mgθ
  - 決めの一言：「小さく振れば、ばねと同じ『ずれに比例して戻す』。」
- 前提の橋渡し：力の分解（三角比）、ラジアン。

**8. uc-shm-middle**
- 問い：「鉄球とピンポン玉を同じ長さの糸でつるすと、どちらが速く往復する？」
- 場面1
  - 見せるもの：弧の長さ s=ℓθ を糸で測る。
  - 動くもの：s を2回微分して加速度 ℓθ″ にする。
  - できる式：mℓθ″ = −mg sinθ（両辺の m を光らせる）
  - 決めの一言：「重いほど強く引かれ、重いほど動きにくい。」
- 場面2
  - 見せるもの：両辺の m を消し、sinθ を θ に置き換える。
  - 動くもの：ばねの式 x″=−(k/m)x と横に並べ、対応する部分を色で合わせる。
  - できる式：θ″=−(g/ℓ)θ、ω²=g/ℓ、T=2π/ω=2π√(ℓ/g)
  - 決めの一言：「ばねの k/m が、振り子では g/ℓ。」
- 場面3
  - 見せるもの：数値の確認。
  - 動くもの：ℓ=1 m で2.0 s、4 m で4.0 s。60°まで振ると周期が約7%長くなる。
  - 決めの一言：「質量は消える。でも振幅が大きいと式はずれる。」
- 前提の橋渡し：ω×T=2π、二回微分＝加速度。

**9. uc-shm-advanced**
- 問い：「ブランコは小さな押しで大きく揺れる。では、押し続ければ宇宙まで揺れる？」
- 場面1
  - 見せるもの：b=0、Ω=ω₀ で押し続ける。
  - 動くもの：振幅が周期ごとに育ち続け、エネルギーの棒も伸び続ける。
  - 決めの一言：「抵抗ゼロなら、タイミングが合うと際限なく育つ。」
- 場面2
  - 見せるもの：抵抗を入れる。
  - 動くもの：1周期ごとに入るエネルギー（緑の矢印）と、出ていくエネルギー（赤、振幅が大きいほど増える）。やがて釣り合って振幅が止まる。
  - できる式：m x″+b x′+kx = F₀cosΩt
  - 決めの一言：「入る量＝逃げる量で、振幅が決まる。」
- 場面3
  - 見せるもの：Ω を動かして共振曲線を描き、b を小さくするとピークが高く鋭くなる。
  - 動くもの：数値 m=1・k=4・b=0.4 で、Ω=2 のとき A=1.25。
  - できる式：A=F₀/√((k−mΩ²)²+(bΩ)²)。Ω=√(k/m) で A=F₀/(bΩ)
  - 決めの一言：「分母に bΩ が残る限り、無限にはならない。」（有限の b ではピークがわずかに低い振動数側にずれる、と一言添える）
- 前提の橋渡し：ω₀=√(k/m)、仕事＝エネルギーの出入り。

**10. uc-shm-advanced-followups-1**
- 問い：「分母の (k−mΩ²) と bΩ は、どこから来た？」
- 場面1
  - 見せるもの：x=C cosΩt + D sinΩt。
  - 動くもの：回転する矢印（円周上の点）で、微分すると cos→−sin、sin→cos と90°回ることを見せる。
  - 決めの一言：「微分は90°回すこと。」
- 場面2
  - 見せるもの：cos の列と sin の列の表。
  - 動くもの：代入した各項が、それぞれの列に落ちていく。
  - できる式：(k−mΩ²)C+bΩD=F₀、(k−mΩ²)D−bΩC=0
  - 決めの一言：「いつの時刻でも成り立つには、列ごとに一致。」
- 場面3
  - 見せるもの：直角三角形。
  - 動くもの：2辺が (k−mΩ²) と bΩ、斜辺が √(…)。2式を2乗して足すと、CD の項が＋と−で消える。
