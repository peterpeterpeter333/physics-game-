# ラジアンと角速度

対象：prep-radian。差し替え台本04の「そのまま」指定に対応し、元の数値例・学習内容は維持した上で描画と途中の説明を再構成。

弧を図で特定 → 円の大きさを変えても同じ角度を表す比 → s/rの定義 → 半径2 m・弧1 mの例 → 一周と半周 → 4秒で一周する点 → 角速度 → 両辺に半径を掛ける → 両辺を時間で割る → v=rω → 外側の点との比較。

- 図の色を弧・半径・角度・速度に対応させ、数式画面と切り替える。
- 一周完了時の位置は0秒と4秒に共通するため「0 / 4 s」と表示。3秒の目印が下の説明に重ならないよう配置変更。
- 表示時刻と角度の丸めが不一致に見えないよう、終端では一周を完了して値を保持する。
- 半径一定・一定の速さという条件を入れ、有限時間の比を速さと角速度に置き換える。
