# 深掘りショート 構成案「箱の地図」— 11「水の中の光」から

2026-10-16。Claude が書いた。

## 構成の考え方（ユーザーの方針）
1. **概要回**：現象の全体を一本で説明する。説明の中で使った「中身を見せていない所」は、隠さずに**ブラックボックス（箱）として画面に示す**。箱があること自体が、見る人の違和感になる。
2. **深掘り回**：箱を一つずつ開け、**最深部まで**細分化して一本にする。開けた箱の中から、さらに小さな箱が出てくることがある。それも同じように開けていく。
3. **横への広がり回**：同じしくみで説明できる、別の現象へ横に広げる。「あれも、これも、同じ理由だった」というつながりの気持ち良さ。
4. 一つの概要回から、10本ほどの箱へ深掘りし、横にも広げる。

## 箱の4つの種類
| 種類 | 何が難しいか | 開け方 |
|---|---|---|
| 現象の箱 | 「本当にそうなっているの？」が見えない | 実験・観察で見せる（誰が、どうやって確かめたか） |
| 数学の箱 | 計算や図形の操作が、頭の中で追えない | 一段ずつの計算・図形の動きで見せる |
| 理論の箱 | 「なぜその結果になるか」の筋道が長い | 仮説 → 予言 → 事実の論理の鎖で見せる |
| 物理学の箱 | 自然の根本の決まりそのもの | 決まりが見つかった歴史と、それで説明できることの広さで見せる。今の物理でも分からない所は、謎として示す |

## 概要回 11 の画面に、箱を示す
- 11 の中で、中身を見せずに使った所に、小さな箱の印と番号を付ける（例：「箱② 原子はほとんど空っぽ？」）。
- 最後に、この回で開いた箱の一覧を出す。見る人が「次にどれを開けるか」を選べる形にする（アプリでは、箱を押すとその深掘り回へ進む）。

## 11 から開く箱（10本）

### 現象の箱
**箱① 原子の中は、本当にほとんど空っぽ？**（11 行4）
- 違和感：机も水も、ぎっしり詰まって見えるのに。
- 掘り方：1909〜1911年、ラザフォードの実験。金の薄い箔にアルファ粒子を撃ち込むと、ほとんどが素通りし、ごく一部だけが大きく跳ね返った。「ほとんど空っぽで、中心に小さな重い核がある」と結論した論理を、一段ずつ追う。
- さらに奥の箱：では、なぜ空っぽの原子でできた手が、机を突き抜けないのか？（電子どうしの反発と、原子がつぶれない理由 → 物理学の箱へ）

**箱② 霧と雲は、なぜ白い？**（11 行21）
- 違和感：水は透き通っているのに、細かい水の粒になると白い。
- 掘り方：粒の大きさと光の波の長さの比べ。粒が波より大きいと、どの色も同じように散らす → 白。ミルク、砂糖の粒、すりガラスも同じ。
- 横への広がり：波の長さと同じくらいの粒（火星のちり）では色がつく。

**箱③ 押し縮めた空気では、本当に光が遅くなる？**（11 行30）
- 違和感：空気はほとんど空っぽなのに、詰めると変わるの？
- 掘り方：気体では、光の遅くなり方が詰まり具合に比例する（測定の歴史）。
- 横への広がり：**蜃気楼と、かげろう**（熱い道路の上の空気はまばら → 光が曲がる）。**星がまたたく理由**（空気の詰まり具合のむら）。

### 数学の箱
**箱④ 波を足すと、なぜ消えたり大きくなったりする？**（11 行18〜19）
- 違和感：光と光を足したら、暗くなることがあるの？
- 掘り方：波を数の列として足す。山＋山、山＋谷を、一点ずつ足して見せる。ずれの大きさで、和がどう変わるか。
- さらに奥の箱：波を「回る矢印」で表すと、足し算が矢印の足し算になる（次の箱⑤の道具）。

**箱⑤ 少し遅れた小さな波を足すと、なぜ山が後ろにずれる？**（11 行24）
- 違和感：足しただけなのに、なぜ形がずれる？
- 掘り方：回る矢印（波の大きさと、ずれの角）で、元の矢印に、横向きの小さな矢印を足す → 合わせた矢印が少し回る → 山がずれる。ずれの角＝「小さな矢印の長さ÷元の長さ」でほぼ決まる。
- さらに奥の箱：この回る矢印の正体（三角関数と円、そして数学で最も美しいと言われる式へ）。

**箱⑥ 小さなずれの積み重ねが、なぜ「遅い速さ」になる？**（11 行25）
- 違和感：ずれるのは山の位置だけなのに、速さが変わる？
- 掘り方：一層ごとに山が少し後ろへ → 同じ時間に進む山の数が減る → 波の長さが縮む → 山の並びの進む速さが 1/1.33 になる。速さ＝波の長さ×振動数（振動数は変わらない）の一段。
- さらに奥の箱：では、山の並びではなく、光の「知らせ」はどの速さで進む？（物理学の箱⑩へ）

### 理論の箱
**箱⑦ 出し直した光を全部足すと、なぜ4分の1波だけ遅れる？**（11 行23。11 で唯一「計算の結果」と札を付けた箱）
- 違和感：一つ一つの電子は、遅れずに揺れているのに。
- 掘り方：一枚の面に並んだ電子からの光を、近い電子から遠い電子へと順に足していく。遠い電子ほど道のりが長く遅れて届く → 全部足すと、ちょうど4分の1波遅れた形になる（箱⑤の回る矢印で、矢印を一本ずつつなぐと、渦巻きが描かれ、その終点が4分の1回転した所に来る）。
- これは数学（矢印の足し算）と理論（電子の面）の両方を使う、シリーズの山場の一つ。

**箱⑧ 横の光は、本当に全部消える？　なら、空はなぜ青い？**（11 行18 と、1分版「空はなぜ青い」の食い違い）
- 違和感：むらなく並ぶと横は消える、と言った。でも空気も分子の集まりなのに、空は横から青く光っている。
- 掘り方：気体の分子は、むらなく並んでいない。熱でばらばらに動き、ある場所にたまたま多く集まったり少なかったりする。この「むら」の分だけ、横の光が消え残る。それが空の青。
- 横への広がり：海や深いプールの青。こちらの主な理由は散らされ方ではなく、水が赤い光をほんのわずかずつ吸い込むこと（別のしくみだと見分ける回にできる）。

### 物理学の箱
**箱⑨ 揺さぶられた電子は、なぜ光を出す？**（11 行13〜14）
- 違和感：揺れるだけで、なぜ光が生まれる？
- 掘り方：電気の力は、電子のまわりに広がっている。電子が揺れると、そのまわりの電気の力の向きが揺れ、その揺れが外へ伝わっていく。それが光（電波）。
- さらに奥の箱：その揺れが、なぜ何もない空間を、決まった速さで伝わるのか（マクスウェルの発見、ロードマップ A1）。事実②「何もない空間では、光はいつも同じ速さ」の根拠そのもの。

**箱⑩ 山の並びが遅くなるなら、山の並びが光より速くなることもある？**（11 行26 の裏返し）
- 違和感：出し直しの波で山が「前に」ずれる場合は？
- 掘り方：実際に、X線をガラスに通すと、山の並びは光より速く進む（屈折率が1より少し小さい）。それでも、知らせ（エネルギーや情報）は光より速くならない。山の並びの速さと、知らせの速さは別物。
- さらに奥の箱：「知らせの速さ」とは何か（波のかたまりの速さ）。そして、なぜ知らせは光を越えられないのか（ロードマップ C1 とつながる）。

## 横への広がり（同じしくみで説明できる現象）
- ダイヤモンドがきらきら輝く理由（光が大きく遅くなる → 中で何度も跳ね返る）
- 光ファイバー（光が外へ出られずに閉じこめられる）
- 眼鏡とカメラのレンズ（遅くなり方で光を曲げて集める）
- 蜃気楼・かげろう・星のまたたき（空気の詰まり具合のむら）
- 雲の白、夕焼けの赤（散らされ方のちがい）。海や深いプールの青は、水が赤い光を吸い込む別のしくみ（似て見えて理由が違う例として）

## 開ける順番の案
1. **箱⑦ 4分の1波の遅れ**（11 で唯一、計算の結果として残した箱。数学と理論が組み合わさるシリーズの山場）
   - 先に**箱④ 波の足し算**と**箱⑤ 回る矢印**を開けると、⑦が自分で追える。だから順番は ④ → ⑤ → ⑦。
2. **箱⑧ 空はなぜ青い**（11 の「横は消える」と、空の青の食い違い。違和感が最も強い）
3. **箱① 原子はほとんど空っぽ**（事実②の土台。実験の論理が美しい）
4. 以降、見る人のモヤモヤの声も見ながら、残りの箱と横への広がりへ。
