# 技術の疑問の鎖 序章2（改）暗号の3本 ナレーション（正本・第2版）

2026-10-20。Claude が書いた日本語。字幕はこの文のまま使う（1行＝1 cue）。字幕が4行に収まらないか、1 cue が3文以上になるときだけ、文の区切りで cue を分けてよい（文言は変えない）。

## なぜ作り直すか（ユーザーの指摘）
- 序章2（第1版）は「説明が早すぎる。解説はちゃんとしているが、数学的に複雑で、頭をこねくり回さないと分からない」。
- 指示：**一つの暗号を、三つの側面から解説する**。たとえ話、具体例など、いろいろな側面から説明して、分かりやすくする。

## 作り方の約束
- 序章2（第1版、4:43）を、3本に分ける。
  - **2-1**：カエサル暗号、入れ替え暗号、文字を数えて解く方法
  - **2-2**：アルベルティの円板、ヴィジュネル暗号
  - **2-3**：カシスキーの解き方、回る円板（エニグマの誕生）
- 一つの暗号ごとに、三つの側面を、画面の札で示す。
  - 「具体例」：1文字ずつ、手で計算する。
  - 「たとえ話」：身の回りのものにたとえる。
  - 「破る側から」：敵の立場で見る（または、別の見方）。
  - 札は、その側面を話している間ずっと出しておく。
- **計算は1段ずつ画面に出す**：
  - 声がその文字・数を言う窓で出す。
  - 1段の計算の後には、間（pause 1.0〜1.5 秒）を置く。
  - 声を遅くはしない（声の速さはエンジンの標準）。
- 文字の輪（アルファベットを時計のように輪にした図）を、3本で共通の道具として使う。2-1 で作り、2-2・2-3 で同じ見た目で使う。エニグマの円板（序章・序章3）とも見た目をそろえる。
- 年と人物を左上に残す。ブラックボックス0。誇張・省略には注記を付ける。
