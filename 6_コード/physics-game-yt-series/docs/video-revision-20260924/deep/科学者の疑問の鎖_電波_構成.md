# 科学者の疑問の鎖 ― 電波は、どうやって発明されたか（構成・第1版）

2026-10-19。Claude が書いた。

## この企画の約束（ユーザーの方針）
- 一つの技術を選び、**科学者が思いついた順番で**、その人の目線に立って、発明と考え方の大転換（パラダイムシフト）を言葉にする。
- 理工学の発明を中心にし、その途中で生まれた**数学・物理の発明**も見せる。
- 一人の科学者の答えが、次の科学者の疑問になる。**疑問から次の疑問へ飛んでいく**。
- **ブラックボックスは0**。使う主張は、次の三つのどれかでなければならない。
  1. **実験で見せる**：誰が、何を使って、何を見たか。
  2. **一段ずつ導く**：計算や論理を、飛ばさずに見せる。
  3. **自然の決まりだと明示する**：それ以上分解できない決まりは「自然はこうなっている。それを最初に見つけたのはこの実験」と見せる。隠さない。
- 当時の科学者が知らなかったことを、後から持ち込まない。その時代に分かっていたことだけで、次の一歩を考える。

## なぜ「電波」を選んだか
- 1600年から1901年まで、約300年の疑問の鎖が、途切れずにつながっている。磁石と琥珀の違い → 電池 → 電流と磁石 → 電磁誘導 → 場 → 光の正体 → 電波 → 無線通信。
- 途中で、物理の歴史で最も大きな大転換が二つ起きる。
  - 「力は離れた所に直接届く」から「力は空間（場）を伝わる」へ。
  - 「光は光、電気は電気」から「光は電気と磁気の波」へ。
- 数学の発明も、自然に出てくる。距離の2乗の法則、単位の比べ方（次元）、場の方程式。
- 深掘りショート 11 で残した箱⑨「揺さぶられた電子は、なぜ光を出す？」の答えが、この鎖の到着点になる。

## 疑問の鎖（全12話の案）
各話の形：**その時に分かっていたこと → 科学者の疑問 → やったこと → 見たもの（違和感） → 考えの飛躍 → 次の疑問**。

### 第1話 1600年 ギルバート「琥珀と磁石は、同じ力なのか？」
- **分かっていたこと**：こすった琥珀は、わらくずを引き寄せる。磁石は鉄を引き寄せる。どちらも「引き寄せる不思議な力」として、ひとまとめにされていた。
- **疑問**：この二つは、同じ力なのか。
- **やったこと**：小さな針を軸に乗せた道具（ヴェルソリウム）を作り、いろいろな物をこすって近づけた。磁石とも比べた。
- **見たもの**：
  - こすると引き寄せる物は、琥珀だけでなく、ガラスや硫黄など、たくさんある。
  - 引き寄せる相手が違う。こすった琥珀は何でも引き寄せるが、磁石は鉄だけを引き寄せる。
  - こすった琥珀の力は、湿気ですぐに消える。磁石の力は、消えない。
- **考えの飛躍**：二つは別の力だと分け、こすった琥珀の力に「電気」という名前を付けた（琥珀を意味する言葉から）。
- **次の疑問**：では、電気の力は、どんな決まりで働くのか。

### 第2話 1785年 クーロン「電気の力は、距離でどう変わるのか？」
- **分かっていたこと**：電気には、引き合う組み合わせと、反発し合う組み合わせがある（2種類の電気）。重力は、距離の2乗に反比例して弱くなる（ニュートン）。
- **疑問**：電気の力も、距離で決まった変わり方をするのか。
- **やったこと**：細い糸に棒をつるし、糸のねじれで、とても弱い力を測る道具（ねじればかり）を作った。
  - 力の測り方：糸は、ねじった角度に比例して戻ろうとする。だから、ねじれの角度を読めば力が分かる（ばねと同じ考え方）。
- **見たもの**：距離を半分にすると、反発の力は4倍。
- **考えの飛躍**：電気の力も、重力と同じく、距離の2乗に反比例する。**数学の発明**：弱すぎて直接測れない力を、ねじれの角度に置き換えて測る。
- **次の疑問**：電気は、こすってためる一瞬のものだった。電気を、ずっと流し続けることはできないのか。

### 第3話 1791〜1800年 ガルヴァーニとヴォルタ「カエルの足は、なぜ動いた？」
- **分かっていたこと**：電気は、ためて、一瞬で放つもの（火花）。
- **ガルヴァーニの疑問と見たもの**：カエルの足の神経に、二種類の金属を触れさせると、足がぴくっと動く。ガルヴァーニは「動物の体の中に電気がある」と考えた。
- **ヴォルタの疑問**：電気は、本当にカエルの中にあるのか。それとも、二種類の金属の方にあるのか。
- **やったこと**：カエルを使わずに、二種類の金属（亜鉛と銅）の間に、塩水でぬらした布をはさんだ。それを何段も積み重ねた。
- **見たもの**：積み重ねた柱の両端をつなぐと、電気が流れ続ける。段を増やすほど、強くなる。
- **考えの飛躍**：電気を、一瞬ではなく、**流れ続けるもの（電流）**として手に入れた。電池の発明。
- **次の疑問**：流れ続ける電気は、まわりに何か起こすのか。

### 第4話 1820年 エルステッド「電流は、方位磁針を、どちらへ向ける？」
- **分かっていたこと**：電池で電流を流せる。電気と磁気は、ギルバート以来、別の力と考えられていた。
- **疑問**：電気と磁気には、つながりがあるのではないか。
- **やったこと**：南北に張った導線の下に、方位磁針を置いて、電流を流した。
- **見たもの（大きな違和感）**：
  - 針は動いた。
  - しかし、導線に引き寄せられるのでも、押しのけられるのでもない。導線と**直角の向き**に回った。
  - 導線の上に針を置くと、逆向きに回った。
- **考えの飛躍**：電流は磁気の力を生む。しかもその力は、導線に向かう向きではなく、**導線の周りを回る向き**に働いている。それまでの力（重力・電気の力）は、すべて、二つの物を結ぶ線の向きだった。この力だけが違う。
- **次の疑問**：電流が磁石を動かすなら、電流と電流の間にも、力が働くのか。

### 第5話 1820年 アンペール「電流と電流は、引き合うのか？」
- **疑問**：電流が磁石に力をおよぼすなら、電流どうしにも力があるのではないか。
- **やったこと**：平行な2本の導線に電流を流した。
- **見たもの**：同じ向きの電流は引き合い、逆向きの電流は反発する。
- **考えの飛躍**：磁石の中にも、小さな輪の電流が回っているのではないか。そうなら、磁気の力は、すべて電流どうしの力として説明できる（アンペールの仮説。今では、電子の動きや性質がその正体だと分かっている）。
- **数学の発明**：力が電流の大きさと、導線の長さに比例し、距離に反比例することを、式にした。
- **次の疑問**：エルステッドの「周りを回る力」を使えば、何かを回し続けられないか。

### 第6話 1821年 ファラデー「周りを回る力で、モーターは作れるか？」
- **疑問**：力が導線の周りを回る向きに働くなら、導線を磁石の周りで回し続けられるはずだ。
- **やったこと**：水銀の入った器の真ん中に磁石を立て、上からつるした導線の先を水銀にひたし、電流を流した。
- **見たもの**：導線が、磁石の周りを回り続けた。
- **考えの飛躍**：電気の力を、回り続ける動きに変えられる（モーターの始まり）。
- **次の疑問**：電流が磁気を生むなら、**磁気から電流を生む**こともできるのではないか。

### 第7話 1831年 ファラデー「磁石のそばに導線を置いても、なぜ電流が流れない？」
- **分かっていたこと**：電流は磁気を生む（第4話）。
- **疑問**：逆に、磁気から電流を作れないか。多くの人が、強い磁石のそばに導線の輪を置いて試したが、電流は流れなかった。
- **やったこと**：一つの鉄の輪に、二つのコイルを巻いた。片方に電池をつなぎ、もう片方に、電流を測る針（検流計）をつないだ。
- **見たもの（違和感）**：
  - 電池をつないだまま、待っていても、針は動かない。
  - 電池を**つないだ瞬間**と、**切った瞬間**にだけ、針がぴくっと振れた。向きは逆。
  - 磁石をコイルに出し入れしても、動かしている間だけ電流が流れる。
- **考えの飛躍**：電流を生むのは、磁気そのものではなく、**磁気の変化**。だから、置いておくだけでは流れなかった。発電機と変圧器の始まり。
- **次の疑問**：では、「磁気の変化」は、どうやって離れた導線に伝わったのか。間には何もないのに。

### 第8話 1831〜1846年 ファラデー「力は、何もない空間を、どうやって伝わる？」
- **分かっていたこと**：ニュートン以来、力は、離れた物に直接、一瞬で届くと考えられていた。
- **疑問**：磁石の周りに鉄粉をまくと、線の模様が浮かぶ。この線は、ただの模様なのか。
- **ファラデーの考え**：磁石と磁石の間の空間には、**力の線**が本当に張りつめている。力は、この線を伝わって届く。電磁誘導は、導線が力の線を横切ることで起きる。
  - こう考えると、第7話の「変化のときだけ流れる」が説明できる。線の数が変わるときだけ、導線が線を横切るからである。
- **さらに見たもの（1845年）**：強い磁石のそばのガラスに光を通すと、光の揺れの向きが回る（ファラデー効果）。光と磁気がつながっている、最初の証拠。
- **考えの飛躍（1846年）**：光は、この力の線を伝わる、揺れなのではないか。ファラデーは、数式を使えなかったので、言葉で書き残した。
- **次の疑問**：この「力の線」の考えを、数式にしたら、何が分かるのか。

### 第9話 1856年 ウェーバーとコールラウシュ「電気の単位の比べ方から、なぜ速さが出てくる？」
- **分かっていたこと**：電気の量は、二通りに測れる。
  - 電気の力で測る（第2話。ためた電気どうしの反発の強さ）。
  - 磁気の力で測る（第5話。流したときの電流どうしの引き合いの強さ）。
- **疑問**：同じ電気の量を、二つの測り方で測ると、どう比べられるのか。
- **やったこと**：瓶にためた電気の量を、電気の力で測った。同じ電気を導線に流して、その磁気の力で測った。
- **見たもの（違和感）**：二つの測り方の比べから出てくる数は、**速さの単位**を持っていて、その値は、およそ1秒に31万キロメートルだった。
- **一段ずつ導く（数学の発明：単位で考える）**：電気の力と、電流の磁気の力の式を並べ、単位だけを比べると、比べた数が「長さ÷時間」の形になることを、一段ずつ見せる。
- **次の疑問**：電気と磁気の比べから出てきた、この「速さ」は、何の速さなのか。

### 第10話 1861〜1865年 マクスウェル「その速さは、光の速さではないか？」
- **分かっていたこと**：
  - 光の速さ：1849年、フィゾーが、回る歯車と鏡で、およそ1秒に31万キロメートルと測っていた。
  - ファラデーの力の線の考え（第8話）、ウェーバーとコールラウシュの数（第9話）。
- **疑問と考えの道筋**：
  1. ファラデーの力の線を、数式にした。
  2. 式を並べると、つじつまの合わない所が見つかった。コンデンサーに電気をためている間、導線には電流が流れているのに、二枚の板の間には電流が流れていない。それでも、板の間の周りにも磁気が生まれていないと、式が矛盾する。
  3. そこで、「**電気の力の変化も、磁気を生む**」という一項を足した（マクスウェルは、空間を満たすものの模型から考えた。この話では、同じ結論を、コンデンサーの矛盾から導く）。
  4. すると、磁気の変化が電気を生み（第7話）、電気の変化が磁気を生む。互いに生み合いながら、**空間を伝わっていく波**ができるはずだと分かった。
- **一段ずつ導く（波の速さ）**：空間を進む「電気と磁気の段差」を考える。
  - ファラデーの法則から、電気の強さ＝速さ×磁気の強さ。
  - 足した一項から、磁気の強さ＝（電気の定数と磁気の定数の積）×速さ×電気の強さ。
  - 二つを掛け合わせると、速さの2乗＝1÷（電気の定数×磁気の定数）。
  - この数は、第9話で測られた数そのものであり、1秒に約31万キロメートル。
- **見たもの（大転換）**：電気と磁気だけから計算した波の速さが、測られていた光の速さとぴったり合った。
- **考えの飛躍**：**光は、電気と磁気の波である**。光学、電気、磁気の三つが一つになった。ファラデーが言葉で書いた予想（第8話）が、数で確かめられた。
- **次の疑問**：光が電気と磁気の波なら、**電気の回路で、同じ波を作れる**のではないか。マクスウェルは、それを見ずに1879年に亡くなった。

### 第11話 1887年 ヘルツ「電気の火花から、目に見えない光は出ているか？」
- **疑問**：マクスウェルの言う波が本当にあるなら、電気を速く揺らせば、波が出て、離れた所に届くはずだ。
- **やったこと**：
  - 2本の金属の棒のすき間に、高い電圧で火花を飛ばした。火花が飛ぶたびに、電気が棒の中を、1秒に何千万回も行き来する。
  - 離れた所に、すき間のある金属の輪を置いた。
- **見たもの**：
  - 送る側で火花が飛ぶと、離れた輪のすき間にも、小さな火花が飛んだ。導線でつながっていないのに。
  - 波を金属の壁で反射させ、行きと帰りの波を重ねると、輪の火花が強い所と消える所が、等しい間隔で並んだ。間隔から波の長さが分かる。
  - 波の長さと、揺れる回数を掛けると、光の速さになった。
  - この波は、光と同じく、反射し、屈折し、揺れの向き（偏り）を持っていた。
- **考えの飛躍**：マクスウェルの波は、本当にある。目に見えない、波の長い光（電波）を、人が作れた。
- **次の疑問**：この波を使えば、導線なしで、遠くに知らせを送れるのではないか。

### 第12話 1895〜1901年 マルコーニ「電波は、どこまで届くか？」
- **疑問**：ヘルツの波は、部屋の中の数メートルしか届かなかった。もっと遠くまで送れないか。
- **やったこと**：
  - 送る側も受ける側も、長い導線を空に高く張り、片方の端を地面につないだ（アンテナと接地）。
  - 受ける側には、電波が来ると電気が通りやすくなる金属の粉の管（ブランリーとロッジの検波器）を使った。
- **見たもの**：
  - アンテナを高くするほど、遠くまで届いた。
  - 1901年、大西洋を越えて、約3500キロメートル先で信号を受けた。
- **最後の違和感（次の鎖への入口）**：電波は光と同じく、まっすぐ進むはずだ。それなのに、なぜ丸い地球の向こう側まで届いたのか。
  - この疑問から、空の高い所に、電波をはね返す層があるという考えが生まれ（1902年）、のちに確かめられる（1924年）。

## ブラックボックスを0にするための段（各話で必ず入れる）

| 3 | 金属と塩水で、なぜ電気が流れ続ける | 二種類の金属で、電子を手放しやすさが違うこと。塩水の中を電気を帯びた粒が動いて、流れが続くこと |

| 7 | 変化のときだけ流れる理由 | 第8話の力の線で、線の数が変わるときだけ導線が線を横切ることを見せる |
| 9 | 比べた数が、なぜ速さになるか | 二つの力の式の単位を、一段ずつ並べて割る |
| 10 | 足した一項がなぜ要るか | コンデンサーの矛盾を、図で一段ずつ見せる |
| 10 | 波の速さの式 | 電気と磁気の段差が進む図で、二つの法則を一回ずつ使い、掛け合わせる |
| 11 | 1秒に何千万回の揺れを、どう知ったか | 棒の長さと、つながったコンデンサー・コイルの大きさから計算した値と、波の長さから出した値を突き合わせる |
| 12 | 金属の粉の管が、なぜ電波を感じるか | 粉の粒どうしのすき間に小さな火花が飛び、粒がくっついて電気が通りやすくなる |

- それ以上分解できない決まりは、「自然の決まり」と明示する。
  - 対象：電気の力の2乗の法則、電磁誘導、電気の変化が磁気を生むこと。
  - それぞれ、最初に確かめた実験を見せる。電気の変化が磁気を生むことは、ヘルツの実験が確かめた。
- その時代に分かっていなかったことを、後の知識で先回りしない。例：第5話の「磁石の中の輪の電流」は、アンペールの時代には仮説だった。正体（電子）は、後の話として一言だけ添える。

## 動画にするとき
- 一話＝一本、縦長で約5分。深掘りショートと同じ画面を使う。
- 各話の終わりに、次の話の疑問を置く。最初の疑問は、前の話の最後の疑問と同じにする。
- 画面の札：「その時に 分かっていたこと」「疑問」「実験」「違和感」「考えの 飛躍」「次の 疑問」。数学の発明には「数学の 発明」の札。
- 年と人物は、画面の左上に小さく残す（いつ、誰の目線かが、いつも分かるように）。
- 第9話・第10話は、計算を一段ずつ見せるので、二本に分けてもよい。

## 台本を書くときに検算・確認すること
- 年号・人物・装置の細部を、一次資料に近いもので確かめる。ヘルツの波の長さと揺れの回数、マルコーニの距離、ウェーバーとコールラウシュの値（ウェーバーの定数は光の速さの√2倍で、マクスウェルは310,740 km/s として使った）、フィゾーの値、など。
- 第10話の「コンデンサーの矛盾」は、今の教え方による言い直しである。マクスウェル自身の道筋（空間を満たすものの模型）と違うことを、画面で正直に示す。
