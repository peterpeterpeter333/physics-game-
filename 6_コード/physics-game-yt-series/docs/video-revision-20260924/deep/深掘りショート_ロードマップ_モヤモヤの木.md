# 深掘りショート ロードマップ「モヤモヤの木」（案）

2026-10-16。Claude が書いた。

## 考え方
- 違和感やブラックボックスは悪ではない。**残したモヤモヤは、次の動画の種**。
- 01〜10 で「いつか別の動画で」と残したもの、言い切ったまま中身を見せていないもの、見る人が「じゃあ、これは？」と思いそうなものを、全部拾い出した。
- それぞれを1本の深掘りにし、**どの本のどの行から生まれたか**を書いた。見る人は、モヤモヤを一つ解くたびに、次のモヤモヤへ進む。
- 枝は別々に伸びるが、**途中で何度もつながる**（例：「揺れる電子」が、電波・水の中の光・色・空の青をすべて説明する）。つながった瞬間が、このシリーズ最大のアハ体験になる。
- 1本の形は今までと同じ：モヤモヤ → 予想 → 思考（難所）→ 解決 → 次のモヤモヤ。

## 木の全体像

```
               ┌─ A 揺れる電子 ─── 電波 → 水の中の光 → 色 → 空の青 → 夕焼け
               │
  01〜10 ──────┼─ B 粒か波か ───── 光電効果 → 光のひとかたまり → 原子の段 → 磁石の電子
               │
               ├─ C 時間と空間 ─── 光を追い越せない → 長さが縮む → 双子 → 重力＝時間のゆがみ → ブラックホール
               │
               └─ D 形と空と ───── 虹の円すい → 過剰虹（虹の内側の縞）→ 北極星と地軸 → 同じ周波数の4機が混ざらない理由
```

## A 揺れる電子（06 の「電子が揺さぶられる」から）

### A1「電波は、なぜ何もない宇宙を伝わってくる？」
- **生まれたモヤモヤ**：06 行7「電波の正体は、空間を伝わってくる電気の力の揺れ」。では、何もない宇宙で、何が揺れているのか。音は空気がないと伝わらないのに。
- **予想**：宇宙で電波を伝えているのは？ A 見えない空気のようなもの／B 何もない（揺れが自分で進む）／C 光の粒。
- **難所**：電気の力の揺れが磁石の力の揺れを生み、磁石の力の揺れがまた電気の力の揺れを生む。二つが互いを生み合いながら進む。昔の人は、見えない「エーテル」が揺れていると考え、09 の実験で否定された（09 とつながる）。
- **解決**：マクスウェル（1864年）は、電気と磁石の式から、この揺れが進む速さを計算した。出てきた値が、光の速さと一致した。光は、電波の仲間だった。
- **次のモヤモヤ**：光も電子を揺さぶるなら、水の中の光が遅くなるのも、電子のせい？

### A2「光は、水の中で、なぜ遅くなる？」
- **生まれたモヤモヤ**：01〜02 で「水の中では4分の3の速さ」と確かめたが、なぜ遅くなるのかは言っていない。光の速さは変わらない（09）はずでは？
- **予想**：水の中の光が遅いのは？ A 水の分子にぶつかって回り道する／B 光そのものが疲れる／C 水の中の電子が出し直す光と重なる。
- **難所**：水の分子の電子が光に揺さぶられ、少し遅れて自分も光を出す。元の光と、少し遅れた光が重なると、合わせた波の山が、少し後ろにずれて進む。一つ一つの光は光の速さのまま、合わせた波だけが遅く見える。（重ね合わせは 09 の縞と同じ考え）
- **解決**：「遅くなる」の正体は、無数の電子の出し直しの重なり。09 の「光の速さはいつも同じ」と矛盾しない。
- **次のモヤモヤ**：では、色によって遅くなり方が違う（03）のは、なぜ？

### A3「色によって、なぜ曲がり方が違う？」
- **生まれたモヤモヤ**：03 行14「遅くなり方が、色によってほんの少し違う」を言い切っただけ。
- **予想**：ブランコを押すとき、ブランコが一番大きく揺れるのは？ A ゆっくり押す／B ブランコ自身のリズムに合わせて押す／C 速く押す。
- **難所**：水の中の電子にも「揺れやすいリズム」がある。そのリズムは紫より少し速い所（紫外線）にある。青や紫は、そのリズムに近いので、電子を大きく揺さぶり、出し直しの効果が大きくなる。だから、より遅れる。（08 の「振動数がぴったり合うと大きく反応する」とつながる）
- **解決**：紫が赤より大きく曲がるのは、電子の揺れやすいリズムに近いから。
- **次のモヤモヤ**：電子が光を出し直すなら、空気の分子も光を出し直しているのでは？

### A4「空は、なぜ青い？」（1分版を深掘り）
- **生まれたモヤモヤ**：05 の最後の問い。1分版では「4乗に反比例」を言い切っただけ。
- **予想**：空気の分子が散らす光は、青と赤で何倍違う？ A 同じ／B 約2倍／C 約6倍。
- **難所**：散らす強さが、なぜ振動数の4乗なのか。揺さぶられた電子が出す光の強さは、電子の揺れの「加速の大きさ」の2乗で決まる。振動数が2倍なら、加速は4倍（2の2乗）、出す光の強さは16倍（4の2乗）。（06 の「揺れる電子が電波を出す」とつながる）
- **解決**：(700/450) の4乗 ≈ 5.9。青は赤の約6倍散らばる。紫がもっと散るのに紫に見えない理由（太陽の光と目の感じ方）。
- **次のモヤモヤ**：夕焼けは赤いのに、火星の夕焼けは青い。なぜ？

### A5「夕焼けは赤いのに、火星の夕焼けは、なぜ青い？」
- **生まれたモヤモヤ**：A4 の最後。
- **予想**：火星の夕焼けの色は？
- **難所**：散らすものの大きさで、散り方が変わる。空気の分子は光よりずっと小さいので青を散らす。火星のちりは光の波と同じくらいの大きさで、太陽のまわりの前の方へ、青を強く散らす。
- **解決**：「何に散らされるか」で空の色が決まる。雲が白い理由も同じ（水滴は光より大きく、どの色も同じように散らす）。

## B 粒か波か（02「この問いについては波の説」・08「なぜ振動数でエネルギーが決まるかは謎」から）

### B1「光は波なのに、なぜ粒のようにふるまう？」
- **生まれたモヤモヤ**：02 で「光は波」と決着した。08 で「振動数が決まると、一度に渡せるエネルギーの大きさも決まる」と、謎のまま残した。
- **予想**：金属に光を当てると電子が飛び出す。赤い光をどんなに明るくしても、電子が出ない金属がある。では、青い光を、とても暗くして当てると？ A 出ない／B 少しずつ出る／C 明るくしないと出ない。
- **難所**：波なら、明るくすればいつか電子は飛び出すはず。ところが実験では、色（振動数）で決まり、明るさでは決まらない。アインシュタイン（1905年）は、光は振動数で大きさの決まった「ひとかたまり」でやって来ると考えた。
- **解決**：光は、広がるときは波、エネルギーを渡すときはひとかたまり。08 の謎の正体。
- **次のモヤモヤ**：では、原子の段（08）は、なぜ決まった高さしかないのか？

### B2「原子の中の電子は、なぜ決まった段にしかいられない？」
- **生まれたモヤモヤ**：08 で「二段のエネルギー」「段差はぴったり決まった大きさ」と言い切った。
- **予想**：弦をはじくと鳴る音は？ A どんな高さでも出る／B 決まった高さだけ出る。
- **難所**：電子も波の性質を持つ。原子の中に閉じこめられた波は、弦と同じく、ぴったり収まる形しかとれない。だから、エネルギーは飛び飛びの段になる。
- **解決**：原子の段は、閉じこめられた波の「音階」。だから、原子ごとに決まった色の光を出す（ネオンサインの色）。
- **次のモヤモヤ**：08 の「電子は小さな磁石」は、なぜ？ 電子は回っているのか？

### B3「電子は、なぜ小さな磁石なのか？」
- **生まれたモヤモヤ**：08 行13「原子核も電子も、小さな磁石のような性質を持っています」を言い切った。
- **予想**：電子は自分で回っている？ A 回っている／B 回っていない／C 誰にも分からない。
- **難所**：回る電気は磁石になる。でも、電子を回る玉と考えると、表面が光より速く回らなければならず、矛盾する。電子の磁石は「回っているかのような」生まれつきの性質で、スピンと呼ばれる。
- **解決**：正直に言うと、なぜ電子が生まれつき磁石なのかは、今の物理の、最も深い所にある。（ここは謎を謎として楽しむ回）
- **次のモヤモヤ**：08「同じ種類の原子は、まったく同じ」。なぜ、まったく同じでいられるのか？（さらに深い枝。いつか）

## C 時間と空間（09「双子のパラドックス」・10「ブラックホール」から）

### C1「なぜ、光より速く進めない？」
- **生まれたモヤモヤ**：09 で「速さの足し算が、光にだけは効かない」。では、光の速さで走る電車から、さらに前へボールを投げたら？
- **予想**：光の99%で進むロケットから、前へ光の99%でボールを投げると、外から見たボールの速さは？ A 光の198%／B 光の100%ちょうど／C 光の99.99…%。
- **難所**：09 の時計の遅れと、長さの縮み（C2）を組み合わせると、速さの足し方そのものが変わる。足すほど、光の速さに近づくが、決して越えない。
- **解決**：答えは C。光の速さは、宇宙の速さの上限。

### C2「速く動くものは、なぜ縮む？」
- **生まれたモヤモヤ**：09 では時間だけを扱った。でも、時間が遅れるなら、長さはどうなる？
- **予想**：上空で生まれ、本当なら660 mで消えるはずのミューオン。地上まで届くのを、ミューオンの側から見ると？
- **難所**：地上から見ると「ミューオンの時計が遅れる」。ミューオンから見ると、自分の時計は普通なのに、「近づいてくる地面までの距離が縮んでいる」。同じ出来事を、時間と長さで、両側から説明する。
- **解決**：時間の遅れと長さの縮みは、一つのことの両面。時間と空間は、別々ではない。

### C3「双子のパラドックス」
- **生まれたモヤモヤ**：09 行21「どちらが本当に遅れたかは、もう一度並べて比べたときに決まる」。
- **予想**：光に近い速さで宇宙へ行って戻った兄と、地球に残った弟。再会したとき若いのは？ A 兄／B 弟／C 同じ。
- **難所**：お互いに相手の時計が遅く見えるのに、なぜ答えが一つに決まるのか。兄だけが、途中で向きを変えている（止まって、逆へ走り出している）。向きを変える瞬間に、兄から見た「地球の今」が一気に飛ぶ。
- **解決**：答えは A。対称に見えて、対称ではなかった。1971年の飛行機の実験（09）も、この考えで計算されている。

### C4「物は、なぜ落ちる？　答えは、時間の進み方にあった」
- **生まれたモヤモヤ**：10 で「重力は時間の進み方を変える」。では逆に、時間の進み方の違いが、重力そのものなのでは？
- **予想**：手を離したボールが落ちるのは？ A 地球が引っ張る力のせい／B 下ほど時間がゆっくり進むせい／C 両方の言い方ができる。
- **難所**：物は、時間の進み方が場所でちがう所では、「時間がゆっくり進む方」へ曲がっていく。光の速さのたとえ（01 の「列が向きを変える」と同じ形！）。足元の方が時間がゆっくりなので、止まっていたボールも、下へ向きを変える。
- **解決**：アインシュタインの答えは「重力とは、時空のゆがみ」。01 のぬかるみの列が、ここで宇宙の形の話になる。
- **次のモヤモヤ**：時間のゆがみが極端になると？

### C5「ブラックホールのそばでは、時間はどうなる？」
- **生まれたモヤモヤ**：10 の最後の問い。
- **予想**：ブラックホールへ落ちていく人の時計を、遠くから見ると？ A 速くなる／B ゆっくりになり、止まって見える／C 普通。
- **難所**：10 の「重力が強いほど時間がゆっくり」を極端まで進めると、ある境目（事象の地平面）で、遠くから見た時計は止まる。光さえ、その境目から出てこられない。でも、落ちていく本人の時計は、本人から見れば普通に進む。
- **解決**：「止まって見える」と「本人は普通」は、どちらも正しい。C2 と同じく、見る側によって時間はちがう。

## D 形と空と（04・05・06・07 の残り）

### D1「同じ角度の方向を集めると、なぜ円になる？」（虹の円すい）
- **生まれたモヤモヤ**：04 で「42度離れた方向を全部集めると円」と言ったが、頭の中で立体を回せない人が多い（ユーザーの指摘）。
- **予想**：懐中電灯を、壁に対して斜めに向けると、光の形は？ 傘を開いて真上から見ると、骨の先が並ぶ形は？
- **難所**：目から、太陽と反対の点への線を「軸」にする。軸から42度傾けた棒を、軸のまわりに一周回すと、棒の先は円を描く。ランプのかさ、傘の骨、アイスのコーンで、手で触れる形にする。
- **解決**：虹の円は、目を頂点とした、見えないコーンの口。だから、一人一人に自分の虹がある（04）。

### D2「虹の内側に見える、うすい縞の正体は？」（過剰虹）
- **生まれたモヤモヤ**：04 は光を線（光線）で考えた。でも、光は波（02）。波で考えると、虹に何か足りないものはないか？
- **予想**：主虹のすぐ内側に、ピンクと緑のうすい縞が何本か見えることがある。この縞は？ A 別の雨粒の虹／B 光の波が重なってできる縞／C 目の錯覚。
- **難所**：04 の「42度に集まる」所では、雨粒の別々の所を通った二つの光が、同じ向きに出てくる。通った道の長さが少し違うので、09 の干渉計と同じく、強め合ったり弱め合ったりする。
- **解決**：過剰虹は、光が波である証拠。1803年ごろ、ヤングがこの考えで説明した。雨粒が小さいほど、縞は広がる。

### D3「北極星は、なぜいつも北にある？」
- **生まれたモヤモヤ**：07 行5「北極星の高さで、どれだけ北かが分かる」。でも、なぜ北極星だけ動かないのか？
- **予想**：北極星が動かないのは？ A 一番近い星だから／B 地球の回る軸の先にたまたまあるから／C 一番明るい星だから。
- **難所**：地球は軸のまわりを回るので、星空も軸のまわりを回る。軸の真上にある星だけが、ほとんど動かない。軸は、2万6000年かけてゆっくり首を振るので、北極星もいつかは変わる。
- **解決**：答えは B。今の北極星は「たまたま」。1万2000年後には、ベガ（織姫星）が北極星の近くに来る。

### D4「4機の衛星が同じ周波数で話しているのに、なぜ混ざらない？」
- **生まれたモヤモヤ**：07 で「衛星ごとに違う模様」と言ったが、全部の衛星が同じ周波数（1秒に約15億回）で同時に送っている。部屋で何人もが同時に話すと聞き取れないのに？
- **予想**：同時に届いた4機の電波から、1機の分だけを取り出す方法は？
- **難所**：スマホは、ある衛星の模様を、届いた電波全体に重ねる。その衛星の電波だけがぴったり重なって大きくなり、ほかの衛星の電波は、プラスとマイナスが打ち消し合ってほとんど0になる（07 の「重ねてずらす」と同じ道具）。
- **解決**：模様は、名前であり、ものさしであり、仕分けの鍵でもある。スマホの電話（携帯電話）でも、同じ考えが使われてきた。

## 作る順番の案
1. **D1 虹の円すい**（ユーザーが「意味不明」と指摘した所。すぐに埋めたい）
2. **A2 光は水の中で、なぜ遅くなる？**（01・02・06・09 が一気につながる回）
3. **B1 光は波なのに、なぜ粒？**（08 の謎を回収）
4. **C3 双子のパラドックス**（09 の謎を回収）
5. **C4 物は、なぜ落ちる？**（01 のぬかるみの列が宇宙の形になる、シリーズ最大のアハ）

その後は、各回の「次のモヤモヤ」をたどって、枝の先へ進む。新しく見つかったモヤモヤ（見る人の「ここがモヤモヤ」の声を含む）は、この木に枝として足していく。

## 注意
- 各回の数値と年号は、台本を書くときに検算する（この表は案の段階）。
- 「謎として残す」所（B3 の電子が磁石である理由、その先の「同じ原子がまったく同じ理由」など）は、ごまかさず、謎だとはっきり言う。謎を謎として楽しむ回があってよい。
