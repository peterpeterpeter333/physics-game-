## 検算・確認
- ギルバート『磁石について』（1600年）。テレラの実験。磁石とニンニクの言い伝えを試して否定した。
  - ニンニクの言い伝えは古代から伝わる。ギルバートより前に、デッラ・ポルタ（1558年ごろ）も試したとされる。台本では「最初に試した」とは言っていない（行9は「ギルバートは〜塗りました」）。
  - 図の担当が、英語版 Wikipedia「De Magnete」などで確かめる。
- 1569年のメルカトルの地図：北極の近くに、磁極を表す黒い岩の島が描かれている（北極点の Rupes Nigra とは別の場所）。行5は「北極の近くに、黒い磁石の岩」。図の担当が確かめる。
- ノーマン『新しい引力』（1581年）：ロンドンでの伏角 71°50′ →「約72度」。ノーマンは航海用の道具を作る職人。
- 磁石の決まり：異なる極は引き合い、同じ極は押し合う。方位磁針の北を向く端を N 極と呼ぶ → 地球の地理上の北の近くにあるのは、磁石としての S 極。
- 傾き：伏角は、北半球では N 極が下、南半球では N 極が上を向く。
- 行22〜23：双極子の磁場の線は、磁石の N 極から出て S 極へ入る。テレラで「線が入っていく」てっぺん（青＝S、地球なら北）の近くで、針の N の先は下を向く。
- 行25：双極子の伏角 tan I ＝ 2 tan λ。ロンドン λ＝51.5° → tan I ＝ 2.51 → I ≈ 68° →「およそ70度」。測定の72度と並べ、「一致」とは言わず「合った（星・島の予言とはまるで違う）」と言う。
- 行26：
  - 星：北極星はロンドンから見て仰角約51度の空にある → 針は上を向くはず。
  - 北の果ての島（北極点の近くに置いた点）へ向かうまっすぐな線は、地面の下を通る弦になる。水平からの下がりは、中心角の半分 ＝ (90−51.5)/2 ≈ 19° →「20度ほど」。島を一つの点として引っぱる、という言い伝えのいちばん素直な読み。
- 行22の鉄の粉：ギルバートの時代の実験ではない。いまの見せ方として注記する。
- 磁北と真北のずれ（偏角）：行14 の注記で触れるだけ。

## 問題編への接続（いまは作らない。入れるときのため）
- **挑戦の問題**：南半球のオーストラリアでは、方位磁針の北を向く先は、下に傾くか、上に傾くか。
- **答え**：上に傾く。
- **解き方の段**：
  1. 地球の北には磁石の S 極、南には N 極がある（行32）。
  2. 線は、N 極（地球の南）から出て、回って、S 極（地球の北）へ入る（行22）。
  3. 線が出てくるてっぺんの近くでは、針の先は上を向く（行23）。
  4. オーストラリアは南、線が出てくる側なので、針の N の先は上に傾く。
- **予備の問題**：
  - やさしい：N と N を近づけると、どうなる？（押し返し合う）
  - ふつう：赤道の上では、方位磁針は傾く？（ほぼ水平）
  - むずかしい：地球の北の磁極の近くで、方位磁針はどちらを向く？（真下に近い向き。線が地面にもぐる向きになる）

## 点検で直した所（2026-10-23）
- 点の数え違い：言い伝えは3つ。行28 で星と島が崩れて「0 − 3」。
- 星と島の説が崩れた理由を、行26 の「ほかの言い伝えの予言」（上／約20度下）で示した。測った1点（72度）を、3つの予言と比べる形にした。
- 「端」→「てっぺん」。線が入る側と出る側を分け、出る側では針が上を向くことを本編で言った（挑戦の手がかり）。
- 中心の考え「地球は磁石」に、たとえ話（行30 の寝かせた棒磁石）を足した。ニンニクを「破る側から」にした。
- ノーマンを紹介し、「ギルバートより前に測っていた」と年の順を明示。分度器を画面に。
- 行5：島と黒い岩の言い方を直した。行9：主語をギルバートに。行17：天然の磁石の石。
- 「次のB軸の回」→「この先の、電気と電波の回」。
- 2回目の点検（2026-10-23）：約70度の出どころ（テレラの同じ場所）を言った。島の約20度の理由（線が地面の下を浅く通る）。線は N極から出て S極へ入る、南は N極、と声で言った。「針の、北を向く先」にそろえた。「確かめた人は、まだ」。
