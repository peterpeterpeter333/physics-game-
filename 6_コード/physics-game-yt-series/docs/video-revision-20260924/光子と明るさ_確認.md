# 光子と明るさ：個別確認

- 対象：a-photon-intro（68.6秒、手動3ページ）、ha-why-01（55.1秒、手動2ページ）。台本03の緑の光5.5×10¹⁴ Hz、約3.6×10⁻¹⁹ J、約2.3 eVを保持。
- 必要なエネルギー → 光子一個からの吸収 → E=hν → 同じ色の明るさ → 金属ごとの閾値、の順。
- 光の量子の関係を古典的な波の公式から導けるかのように扱わず、実験を説明する出発点として明記。通常の一光子光電効果という範囲を保持。
- 指数の加算、36.5×10⁻²⁰からの桁の整理、電子ボルトへの換算を段階的に表示。電子が高い電位へ加速する向きも図示した。
- 光子の記号と実際の形を区別し、波の表示は大幅に遅くしている旨を明記。固定振動数のエネルギー棒を伸ばすと蓄積するように見えるため、棒の高さは固定してフェードに修正。
- 図7種、11区間44時点の描画テスト。実MP4全音声区間の80%時点を抽出して図・字幕・式を目視。全編デコード、音声トラック、尺、30 fpsを確認。
