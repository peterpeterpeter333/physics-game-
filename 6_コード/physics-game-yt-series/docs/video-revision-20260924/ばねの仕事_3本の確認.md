# ばねの仕事と位置エネルギー

対象：prep-spring、m-energy-advanced、hm-why-15。差し替え台本01・04に対応。

## 構成

自然長と変位 → 戻す力の符号 → フックの法則は経験的な出発点 → 手の仕事と蓄積 → 変化する力の仕事 → 短い区間の長方形 → 細分化と三角形 → 底辺・高さの対応 → x×xをx²に整理 → 放した物体の運動エネルギー → 曲線に対する積分の動機。

- 前提では仕事と面積の対応を予告し、詳しい代数的な導出は上級に置いた。同じ導出の重複を避ける。
- 「三角形の底辺・高さ」を説明するときに式だけが出ないよう、専用の図を1発話追加。その後に計算画面へ切り替える。
- 自然長を通過する場面は、左端の折り返しまで進めず、速度を持ったまま通過したところを見せる。往復全体は別場面で扱う。
- 手の力の矢印と、蓄積エネルギーの表示が重ならないように修正。
- ばね定数100 N/m、伸び0.2 mでは最後の力20 N、エネルギー2 J。長方形の4 Jとの差、単位の消去、伸び2倍でエネルギー4倍も保持。
- 補足は台本指定の上級場面2の後。前提4区切り、上級3区切りで手動移動する。

24発話・96時点・17種類の図を描画検査。完成MP4から全発話の確認フレームを抽出し、説明と表示を照合した。往復運動は最初と最後が同じになるので、途中の複数時点を含めて動きを検査する。
登録時は全MP4のデコード、台本・時間・字幕・読みの一致を検証。
