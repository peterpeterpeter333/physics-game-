# Codex 作業指示書 — 動画教材の改善(「さっと学ぶ」「とことん学ぶ」の2モード)

リポジトリ: https://github.com/peterpeterpeter333/physics-game-
この指示書と一緒に渡すもの: 「差し替え台本_01〜08」と「差し替え台本_01-02_追補と対照表」(全単元の台本)。「台本_01_ガウスの法則」は参考資料で、差し替えには使わない
方針: 台本の日本語・式・数値は、渡した台本のとおりに使う。あなたの判断で文面を書き換えない。台本にない単元は、この指示書の6章の規則で台本を作ってから、人間の確認を待つ。

---

## 1. 作るもの(全体像)

1. 動画画面に「さっと学ぶ / とことん学ぶ」の切り替えを付ける
2. とことんモードでは、本編の場面の間に「なぜ?」の短い動画(差し込み)を自動で挟む
3. 本編は両モードで共通。新しく作るのは差し込み動画と、直した本編だけ
4. 全動画で、字幕(画面に出す文)と読み(Nemo に渡す文)を分ける
5. 前提動画を、大学電磁気を含む全単元に割り当てる

---

## 2. モードの仕様

| 項目 | さっと学ぶ | とことん学ぶ |
|---|---|---|
| 再生するもの | 前提動画 → 本編 | 前提動画 → 本編の場面の間に差し込み動画 |
| 画面の名前 | 「さっと学ぶ」 | 「とことん学ぶ」 |
| 切り替え | 動画の上にボタン。再生中でも切り替えられる。切り替えたら、今の場面の続きから再生 |
| 保存 | 単元ごとに最後のモードを localStorage に保存(キー例: `physics-quest:video-mode:{単元ID}`) |
| 初級・中級・上級との関係 | 別の軸。3段階 × 2モード。差し込み動画は段階ごとに割り当てる |

- 名前に「浅い」「深い」は使わない(手を抜いているように聞こえるため)
- 差し込み動画の割り当ては、前提動画と同じ仕組み(`prerequisite-routes` の生成と同様)で、`insert-routes.generated.json` を作る。形: `{ 本編動画ID: { afterScene: 場面番号, inserts: [差し込み動画ID...] }[] }`
- 一つの「なぜ」は一つの差し込み動画だけに置く(台帳方式)。同じ理由を二か所で説明しない。ほかの単元からは同じ差し込み動画を参照する

---

## 3. 台本と字幕の形式

見本の台本は、場面ごとに次の項目を持つ。これを動画一覧 JSON に取り込む。

| 項目 | 中身 | 使い道 |
|---|---|---|
| 場面ID | 例 `gauss-s-01-1`(さっと)、`gauss-d-02`(差し込み) | ファイル名・ルート |
| モード | 共通 / とことんのみ | 再生リストの組み立て |
| 画面 | 図・アニメーションの指示 | 描画スクリプト |
| 式 | LaTeX。日本語は必ず `\text{}` で囲む | MathJax で描画 |
| 字幕 | 画面に出す文。1行30字以内を目安に、文の区切りで改行 | 映像に焼き込む字幕 |
| 読み | Nemo に渡す文。字幕と同じ内容を、読み間違えない表記にしたもの | 音声生成 |

- 字幕と読みは、文の数・順番を必ずそろえる(1対1)。字幕の表示時間は、読みの音声の長さで決める
- 字幕は漢字・記号のまま(読みやすさ優先)。読みはひらがな・カタカナに開いてよい
- 場面の秒数は、音声を作ってから決める。説明を削って秒数に合わせない

## 5. 今日の点検で出た改善点(全部)

### 5-1. アプリの動き(1.5 を出す前に)

1. 動画が再生できないとき、代わりに「文字とスライドで読む」を出す。今は、スライド・動く図・端末の読み上げに、どこからも行けない
2. 動画のエラー文言を直す。iOS版は動画を同梱しているので「通信状態を確認」は誤り。「この端末では動画を再生できませんでした。文字とスライドで読めます」に
3. ストアの説明文・審査メモから、1.5 で使えなくなる機能(読み上げ、スライドへの切り替え)の記述を消すか、1 の対応で残す
4. 問題バトル: 不正解のとき正解の選択肢を光らせない(または再挑戦の正解はダメージ半分)。今は見えた正解を押すだけで勝てる
5. 問題バトル: 解き方を文字でも読めるようにする(`steps` のデータはある)
6. 問題バトル: 敵の欄の `position:sticky; top:8px` を `top: calc(env(safe-area-inset-top) + 8px)` に
7. 問題バトル: 勝利画面の「3問クリア」を `problems.length` に。解いた問題を正答数・スター・復習に記録する
8. 更新のお知らせ: App Store を開くリンクを `@capacitor/browser` か `itms-apps://` にする(実機で確認)
9. 同じ単元の分割動画のタイトルが同じ(10組以上)。「(1/3)」を付ける。電磁気のタイトルを問いの形にそろえる
10. 補足欄に「場面の最後の一文」を機械的に出すのをやめ、場面ごとの要点データにするか、欄を消す

### 5-2. 動画の中身(さっとモードでも直す — 迷子にさせない最低限)

1. 大学電磁気の全40単元と、高校「電場とクーロンの法則」など、前提動画のない45の単元・段階に、既存の前提動画を割り当てる
2. 記号を初めて声に出すとき、読み方と意味を言う(ε₀、k、ℏ、h、G、μ₀、λ など)
3. 「一様」「透磁率」「抵抗率」「自然対数」「平行軸の定理」「離心率」を、初出で一文で定義する
4. 媒介変数 u を説明する前提動画を新設する(台本は別途)
5. 画面の式と声の数字をそろえる(例: prep-graph-slope 場面2。声「二割る一」、画面「6÷3」)
6. 上級電磁気で、1場面の画面の式を2〜3段までにする(今は最大11段)。足りなければ場面を分ける
7. 結果だけ言う文(149文)は、さっとモードでは「ここは〇〇を使うとこうなります」と、使った操作の名前だけは言う
8. 「次は〜します」と、次に来ない動画を予告する10か所を直す
9. 同じ文字を別の意味で使わない(ガウスの法則の「ずれ d」→ a、「距離の二乗 u」→ s など)
10. 数式の中の日本語を `\text{}` で囲む(`\rm 内`、`\rm 直線`、`\rm 全方向` など。ue-integrals-03、ue-gauss-05・06)
11. 橋渡し・発展の18本を、他と同じ文体で書き直す(「私たちは」など)
12. 画面の文字の「微小」「変位」「正味」「系」を、声と同じ言葉にそろえる。内積の記号を中黒「・」から「·」に

### 5-3. とことんモードで足す(差し込み動画)

原則(ガウスの法則の会話から作った10個)。差し込み動画はこの原則を満たすように作る。

1. 動機: 何が意外で、なぜ要るかを問いで示す
2. 出どころ: 式・法則・定数が「実験で見つかった出発点」「約束」「前に導いた結果」のどれかを言う
3. 記号・言葉: 読み方・意味・量の種類(総量か密度か)・前の記号との違い
4. 比喩: 手で再現できる操作に言い直す
5. 省いた一段: 代入・くくり出し・約分・足し合わせを省かない。消えるものが同じものだと言う
6. 図形: 弧・三角比・表面積を、ラジアン・直角三角形の比まで戻す
7. 比べるとき: 何を同じにして何を変えたかを言う
8. 既習: 高校のやり方と同じものであることを、数字で見せる
9. 直感 → 厳密: 区切って足す(数字)→ 細かくする → 積分
10. 確かめ: 単位・数値・極端な場合

形式: 1本40〜90秒、1場面4〜5文、新しい考えは1つ、式は一行ごとに日本語で言い直す。

新設が必要な差し込み・前提(数学の道具箱): 加法定理、eˣ と ln の微分、マイナス乗・分数乗の微分、置換積分、sin²+cos²=1、余弦定理、球面座標、平方完成、媒介変数。

### 5-4. 出発点の名前(両モード共通、1〜2文足すだけ)

慣性の法則、運動方程式、作用・反作用の法則、万有引力の法則、クーロンの法則、重ね合わせの原理、電荷の保存、エネルギーの保存、フックの法則、ボイルの法則、シャルルの法則、E = hf、ド・ブロイの関係、ファラデーの法則 — それぞれの初出で「実験で確かめられた出発点です。ここからは導きません」と言う。

## 6. 残りの単元の台本の作り方

1. 見本(ガウスの法則)と同じ形式で、単元ごとに「さっと(本編)」と「とことん(差し込み)」を作る
2. 本編は、今の台本をもとに 5-2 の12項目を直したもの
3. 差し込みは、「全単元_説明不足一覧.md」のその単元の項目と、5-3 の原則から作る
4. 字幕と読みを1対1で付け、4章の辞書を適用した読みにする
5. 作った台本は、音声・動画を作る前に人間に確認を求める(物理の正しさの点検は、別のAIに依頼する)

## 8. 確認

- `npm run build` と、CI の自動チェック(20本+問題バトル)がすべて通ること
- 追加: 字幕と読みの文の数が一致すること、読みに 4-1 の語が漢字のまま残っていないことを検査するテストを足す
