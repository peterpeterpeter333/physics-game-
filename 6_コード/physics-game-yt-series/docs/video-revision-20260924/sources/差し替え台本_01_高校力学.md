# 差し替え台本 第1弾 — 高校・力学(30本)

既存の動画を土台に、「さっと学ぶ」(本編)と「とことん学ぶ」(本編+差し込み)の台本をまとめたもの。
参考にした点検: 全単元_説明不足一覧、新機能点検レポート、初心者つまずき洗い出し、なぜの鎖 監査レポート。

## 記号の意味

| 記号 | 意味 |
|---|---|
| 【そのまま】 | 既存の場面の字幕・映像をそのまま使う |
| 【字幕差し替え】 | 映像はそのまま。字幕と読みだけを、下の表に差し替える |
| 【映像修正】 | 画面の式・記号の説明・図の一部を、指示のとおり変える |
| 【場面追加】 | 既存の動画に、新しい場面を足す(両モード共通) |
| 【差し込み】 | とことんモードだけで、指定した場面の後に挟む新しい短い動画 |
| 【新規動画】 | 完全に新しく作る動画 |
| 【データ修正】 | 条件文など、動画の一覧データの文言を直す |

- 字幕は画面に出す文、読みは Nemo に渡す文。1行ずつ対応させる
- 読みでは、読み間違えやすい語をひらがな・カタカナに開いている
- 差し込み動画の ID は `hm-why-番号`(高校力学の「なぜ」)。一つの「なぜ」は一本だけ。ほかの単元から同じ理由を使うときは、同じ差し込みを再生する

## 深さの分け方(この分野での判断)

- さっと: 既存の説明のまま、迷子にさせない最低限だけ直す(出発点の法則の名前、記号の読み方、省いた一段の名前、次に来ない予告の削除、画面の表記)
- とことん: 「なぜその式になるか」「なぜその定義にするか」を、代数の一段ずつと、数値・単位の確かめまで見せる。差し込み22本と、新規の前提動画1本(加法定理)
