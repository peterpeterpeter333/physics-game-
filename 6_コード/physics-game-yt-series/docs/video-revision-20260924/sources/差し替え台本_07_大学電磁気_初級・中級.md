# 差し替え台本 第7弾 — 大学・電磁気 初級(32本)・中級(39本)

形式・記号の意味は第1弾と同じ。差し込み動画の ID は `me-why-番号`。
この分野は動画数が多いので、まず全体に効く3つの直し(タイトル、前提、画面の表記)を表でまとめ、そのあとに場面ごとの台本を並べる。

## 深さの分け方(この分野での判断)

- さっと: タイトルを問いの形に(全71本)、前提動画の割り当て(今は全単元ゼロ)、出発点の法則の出どころ、打ち消す理由・結果だけの一段、画面の表記(正味・\rm・マクスウェル方程式の並べ方)
- とことん: 中級の計算(電流と電子の速さ、磁場中の円運動、直線電流の磁場、回転コイルの起電力、時定数、交流)を数値で確かめる差し込みと、アンペールの法則の周回積分を区切って足す差し込み

### 2. 正しさで確かめたこと
- um-ac-maxwell-02 の画面の四本の式のうち、三本目が「V = −dΦ/dt」になっていた。マクスウェル方程式としては「電場の一周の線積分 = −dΦ_B/dt」が正しいので、映像修正に入れた

- me-why-07: 周期 2πm/(qB) に速さが入らないことは、第3弾以降の説明(高校のサイクロトロンの話)とも合う
- アンペールの法則の出どころ: アプリの上級(ue-ampere)ではビオ=サバールの法則から導いているので、中級では「上級で導く」と言う形にした
