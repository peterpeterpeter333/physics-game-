# 初心者向けレッスン改訂（2026-09-15）

## 実装

- 56ステージ、元の229ステップに手書きの399補足を論点の位置へ挿入し、計628スライド（各10〜17枚）。文章の自動分割や埋め草での枚数調整は使わない。
- ステージ・レッスン・問題IDと266問を保持。既存の進捗データを消去・変換しない。
- 前ステージのクリア条件とバトル前のレッスン必須条件を撤廃。
- 「ここでいったん止まろう」などの自動チェック文と旧スライド生成器を撤去。
- 1画面1スライド、前へ・次へ・任意選択。全スライドに登録済みのアニメーションを割り当てる。
- 図は一時停止、0.5/1/2倍速、最初からの再生に対応。動きを減らすOS設定では停止状態から始められる。
- 3D座標を投影する磁束・外積・らせん・電磁波図。視点の変更と物理パラメータの変更を分離。
- 縦波、定常波、ヤングの干渉、充電仕事の面積、核種、質量エネルギーの図を追加。
- 静止していたパラメータ図を自動掃引にし、エネルギー図の画面座標と高さの対応を修正。

## 内容の原則

定義、実験をまとめた基本法則、仮定から数学的に導ける結果を区別する。基本法則を代数だけで証明したとは扱わない。光子のE=hν、物質波λ=h/p、相対論のエネルギー関係などには理論上の出発点を明示する。

補足は記号・単位・正負・系の境界・初期条件・途中計算・適用範囲を主題ごとに著述。原文の論点を保持しつつ、速度と変位、保存則の外力条件、小角近似、静電位差と起電力、磁束鎖交数、ロケットの開放系などの誤解を生む記述を補正した。公式集の87項目もレッスンの条件と整合させた。

## 検証

`npm run test:lessons` は次を検査する。

- 56ステージのID・順序と元の266問の不変性。
- 各ステージ10枚以上、補足の挿入漏れ・同一本文の重複なし。
- 全628スライドの図ID解決（利用図124種類）。
- 数式のKaTeX構文検査、数式区切りの対応、公式集からのリンク先。
- 全利用図のReact静的描画、SVGのNaN/Infinity/負の寸法なし。
- 解放制限と旧自動分割器がUIに残っていないこと。

ブラウザーでは全8分野のレッスン・バトルボタンが初期進捗でも有効なこと、最終ステージを直接開けること、前後移動と任意スライド選択、4種類の3D図のフレーム変化と停止、視点変更時の物理量不変、外積順序と電荷符号の変更を検査。静的検査は文章の教育的品質や全時間での物理的正しさを自動保証するものではない。
