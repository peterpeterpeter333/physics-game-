# スライド表示と式変形の改修（2026-09-16）

## 実装済み

- スライド選択は点のボタンに戻す。現在の点、キーボードフォーカス、見出しの読み上げに対応。
- 現象の図の下に、途中式を縦に並べたSVG画像を表示。手送り・再生・停止に対応。
- 213枚のスライドに、手で記述した代入・展開・移項・約分・微分・積分の手順を追加。
- その他の既存TeX数式も画像表示し、合計394枚に数式画像を表示。参照式は導出手順と区別し、等価変形を自動推論しない。
- 1,058点の数式SVGをビルド時に生成。文字の画像生成AIではなく数式組版からパスを生成する。ブラウザーには巨大な数式変換ライブラリを含めず、表示する画像だけを読み込む。既存の公式カードの式も省略しない。
- `ue-integrals` の17枚、`ue-gauss` の11枚は、各スライド専用の現象アニメーションへ置き換え。描画プリミティブのみを共有し、各場面の対象・動かす量・観察内容は個別に実装。
- 現象と途中式は両方残す（ユーザー確認済み）。

## 未完了を明記

全628枚のうち、現象アニメーションの完全個別化は28枚まで。残り600枚には既存の共通図が残っている。「全章で使い回しをなくした」という状態ではない。

数式画像の表示と、全ての導出を十分に補完することは別。全213枚の詳細手順以外にも、文章だけで計算を述べた箇所の追加監査・執筆が必要。

次の作業では現象の図を削って数式だけに置き換えない。色・速度・IDだけの変更も専用アニメーションとして数えない。各スライドの内容に対応した新しい観察の動きを作り、途中式をその下に置く。

## 検証

`npm run build`、`npm run test:lessons`、`npm run test:calculations`。
後者は画像の欠落、TeXエラー、専用図とスライドの対応、複数時点での変化、同一描画列の重複、3Dカメラの無効化を検出する。ただし物理的な妥当性や教育上の十分性の自動証明ではない。

新しいスライドや計算データの編集後は `npm run equations` を実行する。数式SVGと索引は生成物であり、Gitには含めない。開発・公開ビルド時に自動生成する。
