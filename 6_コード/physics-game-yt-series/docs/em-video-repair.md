# 電磁気動画の日本語・図と式の対応修正

## 修正範囲

大学電磁気の初級16・中級14・上級10単元、動画100本、元の315場面。
以前の日本語レビュー184件と、映像レビュー171件を対象にした。重複を含むため、355個の独立した不具合という意味ではない。

- 182場面の台本を個別に修正。対象・条件・操作を明記し、長い式の直訳を短い文に分けた。
- 図・数式だけを修正する場面も含めた対象は239場面（修正版の確認で追加した2場面を含む）。残り76場面の台本・学習内容は変更しない。
- 各動画に少なくとも一つ対象場面があるため、置き換えるMP4は100本。動画を追加するのではなく、既存のID・URLで更新する。
- 100本の合計は約74.1分。各動画は約21〜67秒。理解に必要な説明を削って時間を合わせることはしていない。
- 元のアニメーションは原則として再利用。対象を描いていなかった図は、その場面用の図に差し替えた。
- バトル、点による移動、視聴完了前の章移動は残した。無関係な見出しを「前の問いを使って」と機械的につなぐ文は削除した。

## 主な修正

「磁力線の本数は比喩」「球面積の二乗」「速度成分が円運動する」などを修正した。単位法線の1、代表点、極限、電位差、起電力、正負の向き、固定する条件も具体化した。

字幕の文に対応する式を指定し、場面の時間を均等に割って無関係な途中式を切り替える処理を修正した。文の間の短い無音区間に、最後の字幕が先に出る不具合も修正した。数式変換の失敗と字幕の切り捨ては、生成時にエラーにする。

曲線の位置・移動、円形コイルとソレノイド、分岐点、電荷数密度、放電、位相差、小長方形によるマクスウェル方程式の導出などでは、発話が指す対象を図で確認できるようにした。途中の値と全体の値の区別、固定した数値例、角度変化の向きも調整した。

音声は従来と同じVOICEVOX Nemo 男声1。誤った古い音声へ修正版字幕を重ねる方式ではなく、修正した台本から音声を生成した。電場・磁場の入力読みは「でんば」「じば」。音声エンジンは配布アプリに同梱しない。

## 再生成と回帰確認

1. `node scripts/build-em-film-plan.mjs`
2. ローカルのNemoエンジンを50123番で起動し、`python scripts/render-em-film-audio.py`。末尾に動画IDを指定すれば、その動画だけ更新できる。
3. `FFMPEG=/path/to/ffmpeg node scripts/render-em-films.mjs`。末尾に動画IDを指定可能。`EM_FILM_PREFLIGHT=1` は映像を書き込まず、字幕と数式の描画を事前確認する。
4. `npm run test:em-videos`、`npm run test:em-video-repairs`、`python scripts/check-em-video-media.py`、`npm run test:ten-principles`、`npm run build`。
5. `EM_REVIEW_OUT=/path/to/new-review python scripts/review-em-video-frames.py` で更新後の実際のMP4から字幕ごとの確認画像を抽出する。古い確認画像は使い回さない。

描画結果の指紋が同じ動画は再出力しない。指紋には台本・時間・見出し・字幕時点の図と式を含む。式や図だけの変更を、台本が同じだからという理由で見落とさない。

## 確認の限界

自動テストは対象漏れ、台本と字幕の一致、数式・図の生成、メディアの破損、バトルなどの回帰を調べるもの。すべての説明が誰にでも理解できることを保証するものではない。全音声の通し試聴、学生による理解度テスト、iPhone実機確認は別途必要。App Storeへの新バージョン提出は、この動画修正とは別の作業。
