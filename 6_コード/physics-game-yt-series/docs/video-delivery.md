# 動画配信の切り替え

Backblaze B2で179本の大学編新シリーズと既存のMP4を配信する手順は [backblaze-video-delivery.md](backblaze-video-delivery.md) を参照。B2の全件アップロード・URL検証が済むまでは、このページにある従来のローカル/YouTube方式のまま動作します。

`src/content/video-delivery.json` の `videos` に、アプリ内の動画IDと公開済みYouTube動画IDを登録します。例：

```json
{"schema":1,"videos":{"em/ue-gauss-01":"ABCDEFGHIJK"}}
```

動画IDは `public/media` からの相対パス（拡張子を除く）です。新しい大学編シリーズは `b2-series/<動画ID>` を使い、動画カタログの `stageId`・`level`・`part` に従って単元へ配置します。同じファイル名が複数フォルダーにあるため、フォルダー名も必須です。問題・解説動画もそれぞれ別のIDを登録します。未登録の動画は従来のローカルMP4を再生します。ビルド時には、YouTubeへ差し替えた単元・難易度の旧本編動画とポスターを生成物 `dist/media` から除外します。元ファイルは削除しません。

2026-10-03時点で、新シリーズの公開済み110本を対応付け済みです。11本目の下書き1本と未投稿の68本は対象外で、該当単元は旧本編を残します。初級・中級・上級は別々に切り替えるため、一つの難易度だけ公開されても他の難易度は消えません。学び方は動画の上の「さっと学ぶ／とことん学ぶ」で切り替えます。現行の新シリーズでは「さっと」が最初の1本、「とことん」が公開済み全編です。最初の1本だけでは単元全体を扱わない場合があるため、要約版動画ができるまでは「さっと」を完全な代替教材とは扱わないでください。

品質確認・公開設定・字幕や音声の確認が済む前に、YouTubeへ一括アップロードしないでください。YouTubeの限定公開もURLを知る人は視聴できます。IDの誤登録や埋め込み無効設定ではアプリで再生できません。登録後は実機で冒頭、途中、一時停止、末尾、次へを確認してください。オンライン動画には通信が必要です。

報告フォームは公開済みの「Physics Quest 誤り・不具合・わかりにくいところの報告」に接続済みです。別のフォームに差し替える場合のみ、ビルド時に `VITE_REPORT_FORM_URL=https://forms.gle/...` を設定します。

進捗画像の共有は、ネイティブアプリでは Capacitor Share / Filesystem、WebではWeb Share APIまたはPNG保存を使います。iOSプロジェクトはこのリポジトリには入っていません。iOS版へ組み込むときは `npx cap sync ios` と実機確認が必要です。また、FilesystemプラグインのためにAppleのPrivacy Manifestへ `NSPrivacyAccessedAPICategoryFileTimestamp` / `C617.1` を登録してください。
