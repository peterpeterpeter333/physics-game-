## 2. 台本 .mjs の書き方（chain-1-1v6.mjs が見本）

- **冒頭のコメント**：版の位置づけ、直したこと、cue の分け方、検算を書く。export-script-md が、そのまま ChatGPT 用に出す。
- **場面の包み**（`S` は `docs/video-revision-20260924/umech/schema.mjs`）：
```js
const VOICE={kai:10001,mio:10005};
const S5=(heading,...cues)=>{const s=S(heading,...cues);s.utterances=s.utterances.map((u,i)=>({...u,speaker:VOICE[cues[i].speaker]}));s.deskFrame='1-1v6';return s;};
```
- **キーの頭**：`const K='c11v6-'`
- **KANA 表**：`const KANA={'rows:a':"デ'ワ、ココカラ'/ド'オ/…", …}`
  - `/` は句の区切り、`'` はアクセント、`、` は間、`_` は無声化。
  - □ は「しかく」と読む。
  - アルファベットは `エ'エ`・`ビ'イ`・`スィ'イ`・`ダ'ブリュウ` のように書く。
- **cue を作る関数**：
```js
const cue=who=>(cap,reading,key,o={})=>{ const sub=cap.flat().join(''),parts=reading.split('|');
  if(parts.length!==cap.length)throw…; if(!KANA[key]&&!DRAFT)throw Error('kana が無い '+key);
  return D(sub,parts.join(''),K+key,{speaker:who,kana:KANA[key],cap,capReading:parts,...o}); };
const kai=cue('kai'),mio=cue('mio'); const V1='具体例',V2='たとえ話',V3='破る側から';
kai([["では、"],["ここから","どう進むかを、"],["一段ずつ見ます。"]],
    "では、|ここから どう すすむかを、|いちだんずつ みます。", 'rows:a',{pause:.8})
```

| 項目 | 意味 |
|---|---|
| `cap` | 字幕の区切りの配列。区切り1つが1〜2行で、1行は13字幅まで（全角1、半角0.55）。つなぐと正本と一字一句同じになること。 |
| `reading` | ひらがなの読み。`\|` で区切りの境目を示し、区切りの数は cap と同じ。 |
| `kana` | KANA 表から入る。全 cue に必要（lint が確かめる）。 |
| `speaker` | `'kai'` か `'mio'`。 |
| `pause` | 声の後の間（秒）。理解のための間は 0.8〜1.5、一時停止の問いは 3.0、最後は 2.0。 |
| `sfx` | `[['whoosh',0]]`、`[['ding','e+0.05']]`、最後に `[['chime','e+0.05']]`。大きさ：whoosh .8、tick .6、pop .5、ding .4、chime .4、thump .4。 |
| `view` | 三つの見方の札（V1／V2／V3）。その cue の間ずっと出す。 |
| `face` | 顔。例：`{who:'mio',ex:'hirameku',a:0,b:1}`、`at:'カンペキ'`（その語から）、`small:true`（右上の小さな丸）、`then:{who,ex}`（次の顔）。 |
| `score` | 得点。例：`{at:'キャット',make:0,brk:1}`。 |
| `music` | `'solve'|'solved'|'dark'|'toll'|'after'`。 |

- build-experiment が確かめること：1 cue は2文まで、reading に漢字なし、「。」の数が字幕と読みで同じ。

## 3. Blender の場面（scripts/blender/desk_1_1v6.py）

### 3.1 つくり
- 場面を1度だけ作り、`apply(t)` で時刻 t の状態にして、1コマずつ JPEG に書く。キーフレームは使わない（同じ t なら同じ絵）。
- コマ番号は j＝round(t×30)。
- 時刻は、`<cache>/<ID>.json`（字幕の始まりと終わり）と、`phrase-times.json` から決める。
  - `S(key)`：cue の始まり
  - `E(key)`：cue の終わり
  - `VE(key)`：声の終わり
  - `T(key,'カナ',occ,end)`：声がその語を言い始める時刻（end なら言い終わる時刻）
  - `TSEQ(key,[語…])`：語を順に
- **物の動きは、必ず声の語の時刻に合わせる。** 秒を直に書かない。

### 3.2 描き方の設定
- エンジン `BLENDER_EEVEE`、`taa_render_samples=16`。1080×1920、JPEG 品質92、背景は不透明。
- 色の変換：`view_transform='Standard'`、look は None、exposure 0。モーションブラーはなし。
- world：色 `#6b5a4a`、強さ .35。

### 3.8 カメラ（一番大事）
- 姿勢：`P(見る点, 距離, 方位°, 仰角°, レンズ)`。
- キー：`at(t,pose,cut=False)`。止めるときは `hold(t0,t1,pose)`。同じ姿勢の2点を置くと、その間は1画素も動かない。
- 動く区間は、3次エルミートでつなぐ。端の速さを0にして、ゆっくり始まり、ゆっくり止まるようにする。動く時間は 0.9〜2.2秒。
- 揺れは、笑いの所だけにする（猛スピード回転で、振幅 .006）。
- **説明の間は止める。** 動かすのは、場面の切り替わり・見せる瞬間・笑いの所だけ。
- 動いている割合は `camera_motion()` で数え、`blender/camera-motion.json` に書く。合格は2割以下（第6版 12.4％、第5版 17.0％）。

### 3.9 動きの作り方
- **手が物を動かす**：手の先を `hand_path`／`vlerp`＋smoothstep で動かす。物は、手の先の位置に付けて動かす。
- **タイルが裏返る**：`f=lin(t, T(key,'語'), +.4)` を `place_tile(flip=f)` に渡す。
- **塔が積み上がる**：暗号文の文字の順に、1枚ずつ積む（`counted()`）。
- **巻物**：区切りの語4つに合わせて伸び、`**1.6` で加速して床へ。
- **猛スピード回転**：5回転したあと、「1つ、2つ、3つ」の声で1目盛りずつ戻る。2D の回転の線も重ねる。
- **人形の寝返り**：「ネガエッテ」の声で、向きを −70°→−290°。少し行き過ぎて戻り、跳ねる。
- **使う関数**：`seg`（smoothstep）、`lin`、`back`（行き過ぎ）、`hop`（4h·u(1−u)）。

### 3.10 書き出しの時間（Apple M5、メモリ 16GB）
- 1コマ 1.1〜2.7秒。8分の回をすべて書くと、約4〜5時間かかる。
- 2本並列にする方法：`見本_1-1第6版/キャッシュの小物/v5_tools/` の worker0.sh・worker1.sh・merge.py を参照。
  1. まずアンカーを全コマ計算する。
  2. 約15秒ずつの区間を、互い違いに2本で書く。
  3. 最後に merge.py で1つにまとめる。
- 長くかかるときは、途中で止めない。残り時間の見込みを報告する。

### 4.2 字幕

## 5. 音

### 5.1 声
- `scripts/render-dialogue-audio.py`。カイは10001（男声1）、ミオは10005（女声1）。
- kana のある cue は、speedScale .90、prePhonemeLength .08、postPhonemeLength .10 になる（この仕組みの決まり。変えない）。
- 声は、字幕の始まりの0.04秒後に置く。字幕の終わり＝始まり＋声＋.12＋pause。

### 5.2 音楽（mix-chain-desk-audio-1-1v6.py、合成）
| 区間 | 中身 |
|---|---|
| base | C→Am→F→G、1小節2.4秒。マリンバの分散和音、はじく低音、和音の持続音 |
| solve | 解ける瞬間。高い分散和音を足して ×1.25 |
| solved | 解けた所。C の長調の和音と chime を4.5秒 |
| dark | 結末。D の短調の持続音と、1.2秒ごとの低い鼓動。base は止める |
| toll | 処刑。持続音を弱くし、低い鐘（110Hz）を1回 |
| after | base に戻る |

- 効果音：
  - 点が入る音：G6＋C7、×.22
  - 円板のカチ：2600Hz＋900Hz
  - サイコロ：220Hz
  - 回転：低く濾した雑音
- 音楽は ×.20。声の間は、声の包絡で最大55％下げる（途切れさせない）。
- ebur128 で、−14 LUFS±0.3 になるまで、最大3回利得を直す。最後に、やわらかい制限（−1.5 dBFS）をかける。
- 音楽は0秒から最後まで続け、無音を作らない。

## 8. 落とし穴
- **画像の扱い**
  - sharp は `file://` の画像を、黙って空にする。画像は data: URI で入れる。
  - base64 の中の N・I・u は `%4E`・`%49`・`%75` に置き換わる（自動）。mxr-review が SVG の中の「NaN」で止まるため。
- **図ファイル**
  - `-diagrams.mjs` で終わる名前は、全員の書き出しで自動に読み込まれる。必ず `*.tmp.mjs` で書き、`node --check` を通してから移す。
  - `export *` はしない（キーが重複して、全員の書き出しが止まる）。
  - desk-*.mjs は、この語尾を避けている。
- **書き直しの範囲**
  - `scripts/umech/` に .mjs を1つ足すと、縦長の動画は全部、次の書き出しでキャッシュが効かなくなる（中身は同じ）。
  - Blender の .py を1行直すと、全コマ書き直しになる。一部だけなら `--from/--to` を使う。
  - 字幕・pause・声を変えると、時刻がずれる。Blender の全コマと mix を、作り直す。
- **得点の時刻**は3か所に書いてある（3D の `SCORE_T`、2D の `scoreHUD`、mix の `score.at`）。全部直す。
- **Nemo**：応答しないときだけ起動する（共有なので、動いていれば触らない）。
```
cd "$HOME/Library/Application Support/physics-quest-tools/nemo" && nohup ./run --host 127.0.0.1 --port 50123 > ../nemo.log 2>&1 &
for i in $(seq 1 40); do curl -s -m 2 http://127.0.0.1:50123/version && break; sleep 2; done
```
- **python の SSL エラー**：`export SSL_CERT_FILE=/etc/ssl/cert.pem`
- **キャッシュ**：`/private/tmp` は、再起動で消える。
