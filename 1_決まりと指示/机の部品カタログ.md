# 机の部品カタログ（1-2 制作用）

## 共通の決まり

1-1 第6版の `desk_1_1v6.py` の材質・部屋・光・カメラ値を `scripts/blender/desk_lib.py` に写した。新しい部品も同じ `mat`、`wood`、`box`、`cyl`、`tile` を使う。角を丸めた、温かい机上の模型として見せる。写真の質感にはしない。

- 色：平文＝白 `#f6f2e8`（2D は `#fff`）、暗号文＝橙 `#f08a2c`（2D は `#ffa04a`）、鍵＝青 `#2f7bf0`（2D は `#5b9bff`）。
- 読ませる字幕は 2D で最小 36px。円板の字はカエサル円板と同じ3D文字と放射材質。表は机上の印刷テクスチャと、必要に応じて `vigenereGrid()` の拡大表示を使う。
- 机 2.1×1.1×.05m、上面 z=0。床 z=−.76、壁 y=1.25。窓、額、植木、本の山も原版通り。
- 照明：key 70W `#ffd8a8`、fill 18W `#dfe6ff`、rim 30W `#ffe2c0`、floorL 20W `#ffd8a8`。EEVEE 16 samples、Standard、1080×1920。
- カメラ：`P(target,d,az,el,lens)`。F値 `2.0+2.2*clamp((d−.3)/1.2)`、ピントは見る点。説明の間は止める。
- アルベルティの外輪26文字は**説明用の図式化**。史実の24文字との違いを注記する。

画像リンクは `desk_1_2_catalog.py` の書き出し先。置かれた52枚は修正前の画像なので、修正後のコードで再書き出しと目視点検を行う。斜め上は部品幅が画面の約5〜7割になる距離を部品別に選び、仰角40°で壁と窓を背景に入れる。

```sh
blender -b --factory-startup -P scripts/blender/desk_1_1lib.py -- --cache /private/tmp/ys/ys-chain-1-1v6 --base /private/tmp/ys/ys-chain-1-1v5 --times 293.5,410.5 --out /private/tmp/ys/desk_lib_compare
```

1-2 の回ごとの Blender ファイルでは `import desk_lib as d` の後に必要な factory を呼び、`frame(t)` 内で `seg` と各 set 関数を声の時刻から動かす。`alberti_anchors` と `vigenere_anchors` を `project` に渡し、2D は `desk-overlay-lib.mjs` の `albertiLetters`・`vigenereGrid`・`stepsRow` を重ねる。`C+K=M`、`A+E=E`、`T+Y=R`、`AAA→KEY` を本体の計算で assert する。
