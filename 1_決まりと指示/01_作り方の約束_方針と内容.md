# 技術の疑問の鎖 作り方の約束（1）方針と内容

この文書は、ユーザーと Claude の壁打ち（2026-10-12〜10-22）で決まったことと、Claude が制作中に気を付けていたことを、すべて書き出したもの。

見本は、1-1 第6版「女王を処刑台に送った手紙」（8:11）。ユーザーはこれを「完璧です。これが完成形」とした。この文書の決まりは、すべてこの見本から取り出したもの。迷ったら、見本の動画とコマを見て、同じにする。

---

## 1. この教材が目指すもの（ユーザーの言葉から）

### 1.1 特殊的好奇心に全振りする
- ユーザーの言葉：「難しいところ、逃げたくなるところ、頭に負荷がかかるところこそが、この教材の売り」。
- 流れは「モヤモヤ・疑問 → 予想・思考 → 解決」。
- 疑問は、「なぜでしょう？」と言って作らない。**見る人が知っている事実を並べると、その間に自然に違和感が生まれる**ように作る。違和感を掘るたびに少しずつ分かり、その「分かった」が気持ちよい形にする。
- **論理的思考を見せる**：仮説 → 「もしそうなら、〜のはず」→ 実際の事実と比べる → 合わなければ捨てる。捨てた仮説も、次の手がかりになる。
- 目的は **100％理解させる**こと。面白さのために、理解を削ってはいけない（第4版で一度失敗した。7章）。

### 1.2 ブラックボックスは0
- 「計算で求めた」「〜で分かる」のような、中身を見せない言い方をしない。手順は、小さく具体的な段に分ける。
- 使ってよい主張は、次の3つだけ。
  1. **実験・試作で見せる**：誰が、何を使って、何を見たか。
  2. **一段ずつ導く**：計算・論理・手順を、飛ばさずに見せる。
  3. **自然の決まりだと明示する**：それ以上分解できない決まりは「自然はこうなっている。最初に確かめたのはこの実験」と示す。
- **物語にもブラックボックスを作らない**（第6版で直した）。
  - 出来事には、必ず原因を示す。例：なぜ秘密の手紙が敵に渡ったのか → 運び役が寝返っていたから。
  - 「誰が、誰に、何をしたか」を、毎回はっきりさせる。
- 推理の途中で、候補を当てはめて選ぶときは、候補を全部並べ、なぜ一方を捨てるかを言う。
  - 例：「Q が I なら □EET IT THE、Q が A なら □EET AT THE。AT THE の方が英語として自然」。
  - 例：「□EET は MEET か FEET。AT THE の前なら MEET」。
- 中身を見せずに使う所が残るなら、隠さずに「箱」として示し、後の回で開ける。

### 1.3 一つの考えを、三つの見方で
- ユーザーの言葉：「説明が早すぎる。数学的に複雑で、頭をこねくり回さないと分からない。一つの暗号に対して、三つの側面から解説して」。
- 三つの見方：
  - **具体例**：1つの場合を、手で、一段ずつ計算する。
  - **たとえ話**：身の回りの物にたとえる。
  - **破る側から**：敵の立場で見る。題材によっては「別の見方」でよい。
- 画面の左上に、木の札「見方：具体例／たとえ話／破る側から」を、その見方の間ずっと出す。
- 1本に詰め込まない。1つの考えに、時間をかける。

### 1.4 見ていて面白い
- ユーザーの言葉：
  - 「知的好奇心の面はバッチリ。でも、見ていて面白くない」（第2版）。
  - 「ユーモアと映像の変化を取り入れて」。
  - 「3D の質は非常に良い。ディズニーのように動き回る 3D は残して」（第4版）。
- 取り入れた要素（他チャンネルの調査と「無限の机」の分析から。正本フォルダの2つの文書）：
  - **人の命が懸かった物語から始める**（1-1 はメアリー女王）。
  - **作る側と破る側の攻防**：得点板で、勝ち負けを見せる。
  - **掛け合い**：カイ（作る側の味方、自信満々のボケ）とミオ（破る側、冷静なつっこみ）。
  - **誤解から入る**：ミオの「今度こそ絶対に破れませんね！」。
  - **一時停止して考えさせる**、**解ける瞬間を見せる**、**最後に挑戦の問題**。
  - **ユーモアは絵で作り、ナレーションは真顔**。
  - **机の上の舞台**、**0秒から手が物を動かす**、**最後の1〜2秒で冒頭に戻る**。

### 1.5 声の速さ
- 声を遅くして、長さを稼がない。
- 1-1 の声の設定は、この仕組みの決まり（speedScale 0.90）のまま。変えるのは、ユーザーが決めたときだけ。

## 2. 1本の組み立て（1-1 の型）

| 部分 | 中身 | 1-1 での例 |
|---|---|---|
| 冒頭（0〜10秒） | 0秒から手が物を動かす。強い一言。聞き手の驚き。 | 手が封を切る。「この一枚の手紙が、女王を処刑台に送りました」「え、手紙一枚で？」 |
| 物語の入口 | 人と、賭けられているもの。得点板 0−0。 | とらわれのメアリー、たるの栓の手紙 |
| 作る側の一手 | 仕組みを、三つの見方で。 | カエサル暗号（具体例・時計のたとえ・25通り） |
| 破る側の一手 | 笑いの場面。得点が入る。 | 円板の猛スピード回転、「3秒で、破られました」 |
| でも → そこで | 作る側の改良。また三つの見方で。 | 入れ替え表、枝分かれの木、床まで伸びる巻物 |
| 誤解 | ミオが言う。 | 「今度こそ絶対に破れませんね！」 |
| 一時停止 | 見る人に考えさせる（約3秒、音楽は止めない）。 | 「全部試さずに解く方法は？」 |
| 破る側の大きな一手 | 一番大事な考えを、三つの見方で。論理の筋で確かめる。一段ずつ解く。 | 名札の人形、E→X の塔、サイコロ、JVX 14回、穴埋め |
| 物語の結末 | 原因と結果を、ブラックボックスなしで。 | 寝返り、写し、偽の追伸、処刑 |
| 次への引き | 弱点と、作る側の次の一手の予告。 | 「同じ文字が、いつも同じ記号になること」 |
| 挑戦 | 見る人に解かせる。答えは次の回。 | MYEXD DRO VODDOBC |
| 回収 | 最後の1〜2秒で、冒頭の物に戻る。 | 冒頭の手紙 |

- 長さ：今の深さで作ると、6〜8分になる（1-1 は 8:11）。短くするために、理解の段を削らない。
- 「でも／しかし」と「そこで」の段を、4段以上入れる。「無限の机」の分析では、伸びた回の中央値が4段、伸びなかった回は0段だった。

## 3. ナレーション（正本）の書き方

日本語は、すべて Claude が書く（ユーザーの指示：「ChatGPT にはできない作業なので、Claude がすべてやる」）。動画を作る側は、文言を変えない。

- **正本の表**：番号｜場面｜話す人｜ナレーション｜画面。1行＝1 cue。
- **cue を分けてよいとき**：1 cue が3文以上のとき、または字幕に収まらないとき。分けるのは文の区切りだけで、文言は変えない。
- **文の作り方**：
  - 短い文にする。
  - 数・計算は、声がその数を言う所で、画面に1段ずつ出す。
  - 英語は、画面に出してよいのは記号・単位・暗号文字だけ。日本語の説明に英語を混ぜない。
- **ふりがな（読み）**：
  - 読みは、ひらがな（外来語はカタカナ）で、文節ごとに半角スペースを入れる。漢字を残さない。数字も読みで書く。
  - 語頭の「は」は「ハ」と書く（ハいる、ハかる、ハやさ）。
  - 句の途中の助詞「へ」は「え」と書く。
- **アクセント（kana）**：
  - まず kana なしで作り、prosody.py の案を写して直す。
  - すべての句に `'` を1つ付ける。数字の途中で句を切らない。
  - 女声（ミオ）も、女声の声で確かめる（prosody-speaker.py）。
- **検算の欄**：数は全部計算し直して書く。史実は資料（英語版 Wikipedia、公文書館、大英図書館、NSA の資料など）で確かめ、出典を書く。言い過ぎた史実は、確かめられた範囲の言い方に直す。
  - 1-1 で直した例：
    - 「フェリペスは数えて解いた」→「どう解いたかの記録はないが、数える方法が使える」
    - 「暗殺の計画に同意した」→ 言わない
    - 「しくみは同じ、入れ替え表」→「中心は、入れ替え表」

## 4. 画面（3D と 2D）の決まり

数値・ファイルの詳しい値は「02_作り方の約束_3Dと仕組み.md」にある。ここでは、考え方を書く。

### 4.1 舞台は「机の上」
- 木の机、白っぽい壁と窓、植木、暖かい光、背景のぼけ（被写界深度）。
- 写真のようでなくてよい。温かい模型のような、ディズニーやピクサーの雰囲気にする。
- 地図や昔の場面も、机の上の模型として見せる。

### 4.2 物
- 話に出てくる物は、机の上の物にする：手紙、たる、円板、タイル、巻物、本、ろうそく、得点板、人形、時計、木の模型、サイコロ。
- **色の意味を、シリーズで固定する**：平文は白、暗号文は橙、鍵は青。
- 中を見せるときは、半透明・断面・分解のどれかを使う。点線の丸は、ほぼ使わない。

### 4.3 手
- ミトンのような簡単な手で、物を動かす：封を切る、円板を回す、羽根ペンで書く、手紙を渡す。
- 手が出ると、画面に人の気配が出る。0秒の画面には、必ず手か、動く物を出す。

### 4.4 カメラ（第5版で直した一番大事な点）
- **説明している間は、カメラを止める。** 止めたまま、物の動き（指、円板、タイル、線、人形、塔）で見せる。
- カメラを動かすのは、次の3つだけ。
  - 場面の切り替わり
  - 何かを見せる瞬間（巻物が伸びる、塔が立つ、手紙が戻る）
  - 笑いの所
- 目安：カメラが動いている時間は、全体の2割以下（1-1 第6版は12.4％）。第4版はほぼ100％動いていて、ユーザーに「多すぎる」と言われた。

### 4.5 顔（カイとミオ）
- 表情のある、簡単な顔の絵。色は、カイが青、ミオが桃色。
- 表情：得意・困る・驚く・ひらめく・じと目・がっくり・腕まくり・きらきら。
- 節目で、画面いっぱいのアップにする（1話に6回前後）。それ以外は、右上に小さく出す。

### 4.6 2D の重ね
- **字幕**
  - 2行まで、1行13字幅まで、白の太字（66px）に、影と縁。
  - 位置は、画面の高さの約65〜69％。
  - 声に合わせて、区切りごとに切り替える（表示時間の中央値は約1.3秒）。
  - 頭に、話す人の名前と色の印を付ける。
  - 題の大きな帯は付けない。series と題は、冒頭2秒だけ小さく出して消す。
- **札**：
  - 年と場所（左上）
  - 見方の札（左上、木の板）
  - 得点板
  - 論理の筋（仮説 → もし正しいなら → 予言 → 事実 → 判定）
  - 「分かった文字」の札
  - 注記（「再現」「大きく誇張」「たとえ（ローマの物ではない）」）
- **文字の大きさ**：最小 36px。

### 4.7 音
- 声の下に、音楽を途切れず流す。無音を作らない（「無限の机」27本中23本が無音0回）。
- 全体の音量は −14 LUFS 前後。
- 音楽は、解ける瞬間と結末で変える。得点が入る時や目盛りの所に、小さな効果音を入れる。
- 一時停止や考える間でも、音楽は止めない。

## 5. 見せ方の細かい約束（制作中に気を付けていたこと）

壁打ちでは出てこなかったが、制作中に必ず守っていたこと。

1. **文字や答えを、声より先に出さない。** 計算の段・札・答えは、声がその言葉を言い始める時刻に出す。
2. **1段の計算や「なるほど」の後には、間を置く**（0.8〜1.5秒）。1-1 第6版は34か所以上。
3. **物が少ない画面を、2秒以上続けない。** 第5版に1か所あった（3:22〜3:24）。
4. **前の場面の物を、意味なく残さない。** 逆に、続きの場面は同じ物を使い、世界をつなげる。
5. **誇張・再現には、必ず注記を付ける。**
   - 例：「巻物の長さは 大きく誇張」「手紙の記号は 再現」「時計は たとえ（ローマの物ではない）」。
6. **数の例は、全部実際に計算して作る。** assert で確かめ、検算の欄に書く。
   - 例：暗号文の塔の高さは、541文字の英文を実際に入れ替え表で暗号にして数えた（X 70、J 60、JVX 14）。
7. **短い例で、統計を語らない。** 頻度の話は、数百文字以上の文で作る。
8. **字幕と声と画面の文言をそろえる。** 字幕は正本と一字一句同じにする（lint で機械的に照合）。
9. **はみ出し・重なり・36px 未満の文字を、全コマ一覧で探して直す。**
10. **画面の右端と下端（YouTube の操作ボタンと題名の場所）に、大事な物を置かない。**
11. **史実の年号・人物・数値は、一次資料に近いもので確かめる。** 確かめられない所は、言い切らない。
12. **前の版を消さない。** 直す前の mp4 は `旧版/` に、名前の末尾に版を付けて移す。
13. **既存の動画を変えない。** 共通の部品を変えたら、ほかの動画を書き出し直して、バイト単位で同じことを確かめる。
14. **耳での確認はできない。** 音は数値で確かめ、報告に「耳での確認はしていない」と書く。

## 8. シリーズ全体の流れ
- 構成：正本フォルダの `技術の疑問の鎖_暗号解読機からスマホとAIまで_構成.md`。全体は約300本の予定（一覧は Claude が作る）。
- 得点板・色の意味・カイとミオの役・机の世界は、全回で同じにする。
- 各回の最後の疑問が、次の回の最初の疑問になる。
- 「次の回で答えを見せる」と言った挑戦は、必ず次の回で答える（1-1 の挑戦は 1-2 で答える）。
