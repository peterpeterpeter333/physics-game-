## 深さの基準（レビュー末尾「修正完了の判定」）
各項目について、映像と語りで次が分かること：
(a) 求めたい量 (b) 使う前提 (c) その操作を選ぶ理由 (d) 式・図の対応 (e) 結論の範囲（どこまで示したか）。
- **実験法則は実験法則を底にする**（クーロンの法則、重ね合わせ、ファラデーの法則など）。「ここが出発点（実験で確かめられた法則）」と一度言う。証明していない一般化を証明済みのように言わない。
- **等号の正確さ**：平均と瞬間（Δ と d）、近似（≈と条件）、符号付きの量、係数（μ₀I の μ₀ を省かない）。
- **モデルと条件を一言**：点電荷・静止・真空、中心の点電荷、固定した輪、電荷の流れのない領域、平面波、理想化した板…。
- 深さは式の数ではなく「前提から結論までのつながり」で担保する。媒介変数・球面座標など、この動画で不要な道具は持ち込まない。
- **補足**（レビューで「補足」分類のもの、および各章で「根まで戻れる入口」が必要なもの）は、本編の流れを止めない短い区間にし、画面に「補足」ラベルを出す（`word('補足',…)` など）。1つ 1〜2 文まで。

## 共通の道具は、決めた章で一度だけ説明し、後は同じ言葉で呼び戻す
| 道具 | 初出の章 | 言い方 |
|---|---|---|
| 1個あたり・割合（割り算の意味） | 2章（E=F/q の数値例 2 C に 6 N → 1 C あたり 3 N） | 「〜あたり」 |
| 重ね合わせの原理（実験で確かめられた原理） | 2章 | 「それぞれの電荷が作る電場を、同じ地点で矢印として足す」 |
| ベクトルの成分・内積 | 2章（傾けた窓、法線方向の成分×面積）、4章で道の向き版（平行＋・直角0・逆−・斜めは平行成分） | 「〜方向の成分」 |
| 細かく分けて足す（近似和→極限） | 2章（面）、4章（道） | 「小さな面ならほぼ平ら・場もほぼ一定」 |
| 符号の約束（面の向き↔周回の向き、外向き＋） | 2章（閉じた面は外向き＋）、4章（周回方向と囲んだ電流の正の向き）、7章で使う | 「正の向きをこう決める」 |
| 変化率（平均→瞬間） | 5章 | 「区間の平均」「その瞬間」 |
| 仕事と起電力（1 C あたりの仕事、V=J/C） | 5章 | 「1 C を一周運ぶ仕事」 |

## 映像 QA（全章）
- 式変形の場面では図を退かせる（薄くする・小さくする）。図と複数式を同時に主役にしない。
- 読ませる情報を暗くしすぎない（補助ラベルも 22px 以上・十分な明るさ）。
- 力線をなぞる点は「向きをなぞる目印」と分かる見た目にし、電流の粒と記号を分ける。
- カメラを動かしたのか、面を選び直したのか、場が変わったのかを語りと図で区別。
- 図の出るタイミングは字幕の文字位置から推定している。重要な要素は語句が読まれる少し前に出るよう余裕を持たせる。
