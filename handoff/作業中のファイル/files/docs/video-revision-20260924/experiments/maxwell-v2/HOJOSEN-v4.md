# v4：数式を理解するための「考え方の補助線」

v3（45分47秒、深く学ぶモード）は説明の量は十分になった。ところが**数式を理解するところがすごくわかりにくい**という評価。
v4 では、式が出る場面ごとに「考え方の補助線」を入れる。補助線とは、
1. **比喩・例え話**（日常の、誰でも体で知っている場面に置き換える）
2. **図と式の対応を画面上で一緒にやる**（一片 → 数値カード → 合計、の同じ番号・同じ色）
の二つ。レビュー `REVIEW-48-hojosen.md`（48項目）は参考資料で、全部に従わなくてよい。ただし**物理・整合性の修正（下の「必ず直す」）は全部やる**。

## 補助線の約束
- 比喩は**式が出る直前か直後に一言**。「たとえば」「〜に似ています」で入り、**必ず本物に戻る**（「本物の電場では…」）。比喩の限界が誤解につながるものは一言で断る（例：電気束は本当に何かが流れているわけではない）。
- 比喩は章をまたいで**同じものを使い回す**（下の表）。同じ道具に別の比喩を持ち込まない。
- 比喩の場面は絵にする（雨と窓、改札、向かい風の散歩…）。簡単なピクトグラムでよい。画面に「たとえ」と小さなラベル（`word('たとえ',…)`）を出し、本物の図へ戻るときにラベルを消す。
- 「式の一項」と「図のどこか」は、**同じ番号・同じ色**で結ぶ（①②③の数値カード）。色だけに頼らず番号も付ける。
- 主役は一つ。式変形の間は図を薄く、図を見せる間は式を小さく。操作は一度に一つ。
- 説明は置き換え優先。既存の文を比喩入りの文に書き換えられるなら、文を増やさない。ただし数式の理解に必要な一段は足してよい。

## 必ず直す（整合性・物理）
1. **7章 二つ目の面のカメラ（レビュー45）**：上向きの電場を**上から見下ろすと手前向き（⊙）**。現在「見下ろすと奥向き ⊗」は誤り。案B（上から見下ろすを維持し、E は ⊙、B は画面上で正しい向き、正の周回は面の正の向き＝⊙ に合わせて反時計回り、左辺の符号を物理的に正しく）で直すか、案A（下から見上げる視点に統一）で直す。どちらでも最終式 B＝ε₀μ₀vE が同じになることを確認。世界の上向きの軸とカメラ（目）のアイコンを出す。
2. **4章 定常の条件（レビュー27）**：「一定の電流＝各場所の電流が時間で変わらない定常状態。そのため電荷もどこにもたまっていかない」。
3. **4章 半径と一歩（レビュー21）**：半径と道に沿った一歩を別の文字・別の矢印で示す（トラックの比喩）。
4. **有限の和は ≈（レビュー29）**：場所で場が変わるときの Σ は近似（≈）、細かくした極限で積分の＝。一様な例だけ＝。
5. **起電力の記号（レビュー34）**：起電力は ℰ（イー）で書き、単位 V と区別。ℰ＝2 V、R＝4 Ω → I＝0.5 A の一例。※読みは「イー」ではなく「起電力」と言えば足りる。
