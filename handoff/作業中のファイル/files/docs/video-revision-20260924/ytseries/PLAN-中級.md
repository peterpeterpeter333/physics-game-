## 1. um-average-rate（微分・中級）— 易・2本
理由：初級で x＝5t² の t＝1 を数表と (1+h)² で済ませた。新しいのは「t を文字のまま」展開・約分する一手と、lim と導関数という記号だけ。（本0〜本8、補0〜補4＝上級 um-derivative:2,3,4,5,7。補0・補1は初級 01 と同じ内容なので振り返り1場面に留める）

**1/2 本0〜本5（＋補2、foundation 例題）「近づく先を、数表を作らずに式から取り出すには？」**
- 最初の問い：（初級の締め）近づく先を、数表を作らずに、式から直接取り出すにはどうするか？
- 要点：平均変化率 Δx/Δt＝2点を結ぶ直線の傾き。幅を h と書く。x＝t² の t＝1 で h＝1→3、0.1→2.1、0.01→2.01、0.001→2.001（初級 01 の 15、10.5、10.05 と同じ近づき方）。t を文字のまま：(t+h)²−t²＝2th+h²。h≠0 なので約分でき、差商は 2t+h。
- 補助線：①正方形 t×t を t+h に広げる図：右の帯 th、上の帯 th、角 h² を式の各項と同じ色（初級 03-1 の x＝3→3.1 の正方形を文字に置き換え）。②例題 t＝1、h＝0.1：(1.1²−1²)/0.1＝0.21/0.1＝2.1 を、式 2t+h＝2+0.1 と並べる（数表の1行＝式への1回の代入）。
- 最後の問い：2t+h の h に、そのまま 0 を入れてよいのか？

**2/2 本6〜本8（＋補3、補4）「h を0に"近づけた先"は、どう書き、何が得られる？」**
- 最初の問い：h＝0 を代入してよいか？
- 要点：約分前に h＝0 を入れると 0/0 で決まらない。約分後の 2t+h で h→0 とすると 2t。行き先を lim_{h→0}、得た値を dx/dt と書く（単位 m/s）。結果は数ではなく関数：t＝2 で 4、t＝−3 で −6（負の傾き＝戻る向き）。微分＝位置の関数から、各時刻の傾きを返す関数を作る操作。sin に同じ手順を使うときはラジアン（補4。初級 04-1 の確認として一言）。
- 補助線：①新しい数値例：t＝1 で h を負の側からも近づける：h＝−0.1 で (0.81−1)/(−0.1)＝1.9、h＝0.1 で 2.1 → 両側から同じ 2 へ（数直線の両側から矢印）。②x＝t² のグラフと、その下に dx/dt＝2t のグラフを上下に並べ、各 t の接線の傾き＝下のグラフの高さを同じ色の点で結ぶ。
- 最後の問い：位置の式から傾きの式が作れた。逆に、速度の式から、進んだ距離を式で取り出すには？

**このステージで前提にしていて、中級でまだ教えていないもの**：なし（(t+h)² の展開は初級 01-2）。lim の厳密な定義（ε-δ）は扱わない、と明言する。

## 2. um-sum-to-integral（積分・中級）— 中・3本
理由：Σ の添字・上下限・極限の記号・上下の入れ替えと、原始関数・積分定数・F(b)−F(a) が一度に出る。スライドが多い（本11＋補6）。（本0〜本10、補0〜補5＝上級 um-integral:2,3,4,5,7,8）

**1/3 本0〜本5（＋補2、foundation 例題）「速度の式から距離を式で出すには？――まず n 本に分ける」**
- 最初の問い：速度の式から、進んだ距離を式で取り出すには？
- 要点：部品は細い長方形（高さ f(xᵢ)、幅 Δx）。範囲 a〜b を先に決め、Δx＝(b−a)/n。代表点は左端と約束。Sₙ＝Σ_{i=1}^{n} f(xᵢ)Δx（i は番号、上端 n は本数）。f(x)＝x、0〜4：n＝4 で 6、n＝8 で 7、n＝16 で 7.5。左端なので正しい値より小さいまま増える。
- 補助線：①Σ の各項（i＝1 の短冊、i＝2 の短冊…）を式の項と同じ番号・色で（初級 02-2 の Σ vᵢΔtᵢ の続き）。②n＝4、8、16 の短冊を重ね、正しい三角形（面積 8）との「欠け」の小三角形が縮む。一般に Sₙ＝8(n−1)/n（新しい数値例：n＝100 で 7.92）。
- 最後の問い：n を限りなく増やした行き先を、どんな記号で書く？

**2/3 本6〜本10（＋補0、補1、補3）「∫ は、何を・どこからどこまで足せという指示？」**
- 最初の問い：n→∞ の行き先をどう書くか？
- 要点：∫_a^b f(x)dx＝lim Σ f(xᵢ)Δx。∫ は S を伸ばした形、dx は Δx の行き先。f(x)dx は細い1本。物理での読み：m/s×s＝m、N×m＝J、N/C×m＝J/C。上下を入れ替えると向きが逆で符号だけ反転（∫₀³＝5 なら ∫₃⁰＝−5）。Σ は有限で止め、∫ は行き先。x(t)−x(t₀)＝∫_{t₀}^{t} v(s)ds の s は集計中の時刻、上端を変数にすると関数になる（補0・補1）。
- 補助線：①Σ と ∫ の式を上下に並べ、Σ→∫、f(xᵢ)→f(x)、Δx→dx を同じ色の矢印で対応。②数直線を右向き／左向きにたどる矢印で、Δx の符号が変わる図。
- 最後の問い：毎回 n を増やして極限を取るのは大変。行き先 8 を、短冊を数えずに一発で出せないか？

**3/3 補4〜補5「短冊を数えずに、積分の値を出すには？」**
- 最初の問い：短冊なしで 8 を出せるか？
- 要点：微分の表を逆から読む：(x²/2)′＝x（ステージ1 の (t²)′＝2t を半分に）。微分すると f になる F が原始関数、F+C の集まりが不定積分（t² も t²+7 も微分すると 2t＝微分は出発点の情報を消す）。定積分＝F(b)−F(a)：∫₀⁴x dx＝16/2−0＝8、1/3 の極限と一致。C は差で消える。初期条件が1本を選ぶ（初級 08-2 で名前だけ出した「積分定数」の回収）。
- 補助線：①曲線の家族 x²/2+C を縦にずらして重ね、どれも x＝0→4 で高さの増え方は 8（固定＝差、変化＝C）。②「面積の増え方＝その場所の高さ」：右端を dx だけ動かすと増える短冊が f(x)dx（F′＝f の図による納得。証明ではないと明言）。
- 最後の問い：x² や x²/2 の微分はできた。では (2t+1)² のように中に式が入った関数、掛け算の関数、2つの変数で決まる関数の傾きは？

**前提（未習）**：微積分の基本定理（上級で導く。ここでは図で納得させ、証明ではないと明言）。tⁿ の積分公式（補4に一般形が出るが、中級で使うのは x と定数だけにする）。

## 3. um-function-rules（微分の法則・中級）— 中・2本
理由：連鎖律・積の微分は初級で数値と図で見た。中級は「差の比の極限」で理由を付け、偏微分（新しい記号 ∂）を加える。（本0＝上級 um-rules:1、本1＝:4、本2＝:5、本3＝:8、本4＝:9）

**1/2 本0〜本2（＋foundation 例題）「連鎖律はなぜ"掛け算"で、積の微分はなぜ"和"になる？」**
- 最初の問い：中に式が入った関数、掛け算の関数の傾きは？
- 要点：Δy/Δt＝(Δy/Δu)(Δu/Δt)（Δu≠0 の区間で成り立つ有限の比の掛け算）→ 極限で dy/dt＝(dy/du)(du/dt)。y＝(2t+1)²、t＝1：外側 2u＝6、内側 2 → 12（6 は内側の倍率を落とした誤り）。x＝A sin(ωt+φ) の2回目の微分も中身の ω が掛かり a＝−ω²x（初級 03-2 の確認として短く、本1）。積：Δ(fg)＝gΔf+fΔg+ΔfΔg、Δt で割ると最後の項は (Δf/Δt)Δg で 0 へ。
- 補助線：①新しい数値例：y＝(2t+1)²、t＝1、Δt＝0.01：u は 3→3.02、y は 9→9.1204、Δy/Δt＝12.04 → 12。表の列を「内側の倍率 2」「外側の倍率 6」で色分け（初級 03-1 の二段の歯車）。②初級 03-1 の正方形の帯の図を再利用：f＝g＝t、t＝3 で、角 ΔfΔg を Δt で割った量は Δt そのもの（0.1、0.01…と 0 へ）。
- 最後の問い：変数が2つある関数――山の高さ h(x, y)――では、「傾き」はどう測る？

**2/2 本3〜本4「2つの変数で決まる量の傾きは、どう測る？――偏微分」**
- 最初の問い：h(x, y) の傾きはどう測るか？
- 要点：一方を固定してもう一方だけ動かす＝偏微分。∂ は「他の変数は凍結中」の印で、計算は普通の微分。h＝x²y：y 固定で ∂h/∂x＝2xy、x 固定で ∂h/∂y＝x²。同じ地点でも歩く向きで傾きが違う。電位から電場を出すとき再会する（ステージ22）。
- 補助線：①新しい数値例：点 (1, 2) で ∂h/∂x＝4、∂h/∂y＝1。数値でも h(1.01, 2)＝2.0402 → (2.0402−2)/0.01＝4.02、h(1, 2.01)＝2.01 → 1.00。等高線図の東西・南北の断面を2枚並べ、それぞれの接線の傾き 4、1。②式 x²y の y に鍵の印（凍結）を付け、x² だけ微分して 2x×y。
- 最後の問い：傾きが分かれば、少し先の値を予想できる。曲線を直線や2次式で置き換えると、どこまで正確か？

**前提（未習）**：等高線の読み方（1文で補う）。sin・cos の微分は初級 03-2・04-1。

## 4. um-approximation（近似とテイラー展開・中級）— 中・2本
理由：接線近似は易しいが、係数を微分で決める手順と、捨てた項で範囲を見積もる考えが新しい。初級 04-2 の「θ³/6 はテイラー展開で中級で導く」を回収する。（本0＝上級 um-taylor:3、本1＝:4、本2＝:5、本3＝:8）

**1/2 本0〜本1（＋foundation 例題）「曲線を1本の直線で置き換えるなら、どの直線が最良？」**
- 最初の問い：傾きから、少し先の値を予想できるか？
- 要点：なめらかな曲線は拡大すると直線に見える。f(x)≈f(a)+f′(a)(x−a)：値と傾きの2つを合わせた唯一の直線＝接線。近似する場所 a を指定して初めて式が決まる。√(1+x)≈1+x/2 に x＝0.02 → 1.01（本当は 1.00995、差 約0.00005）。≈ と ＝ を区別。
- 補助線：①新しい数値例：f＝x²、a＝3 → 9+6(x−3)。x＝3.1 で 9.6（本当は 9.61、差 0.01＝0.1²）。差が初級 03-1 の正方形の角 h² であることを同じ色で。②√(1+x) の微分は未習なので、両辺を2乗して確かめる：(1+x/2)²＝1+x+x²/4 → 1+x より x²/4 だけ大きい（x＝0.02 で 0.0001）。
- 最後の問い：直線では曲がりが表せない。2次式まで使うと係数はどう決まるか？ 初級で見た sinθ の誤差 θ³/6 はどこから来るのか？

**2/2 本2〜本3「2次・3次の項を足すと、どこまで近づき、どこで使えなくなる？」**
- 最初の問い：2次の係数はどう決まり、θ³/6 はどこから来るか？
- 要点：a₀+a₁x+a₂x² を x＝0 で値・1回微分・2回微分を合わせる → a₀＝f(0)、a₁＝f′(0)、2a₂＝f″(0)。cos x≈1−x²/2（cos 0.1＝0.995004、近似 0.995）。同じ手順をもう1回：3次の項は 6a₃＝f‴(0)。sin は 0、1、0、−1 の順なので sin x≈x−x³/6 ――初級 04-2 の差 θ³/6 の正体。次の項 x⁵/120 で使える範囲を見積もる：x＝0.1 で約 8×10⁻⁸、x＝0.5 で約 0.00026（実際の差 sin 0.5−(0.5−0.5³/6)＝0.00026）。項を増やせばどこでも良くなるとは限らない。
- 補助線：①係数を決める表：行「x＝0 での値・1回・2回・3回微分」、sin の列 0、1、0、−1 を同じ色で並べ、1、2、6（＝1×2×3）で割って係数 1、0、−1/6（! の記号は出さない）。②sin のグラフに x と x−x³/6 を重ね、0 付近で重なり、離れると外れる。
- 最後の問い：ここまでは1本の数直線上の関数。力や速度のような3次元の矢印の式は、何を主張しているのか？

**前提（未習）**：√(1+x) の微分（補助線②で2乗して代える）。sin・cos の3回微分（初級 03-2 の繰り返しで得られると1文）。余りの厳密な評価（上級）。

## 5. um-vector-components（ベクトル・中級）— 易・1本
理由：三平方を2回と割り算。考え方の新しさは「ベクトルの式1本＝成分の式3本」だけ。（本0＝上級 um-vector:3、本1＝:7、本2＝:8）

**1/1 本0〜本2（＋foundation 例題）「ベクトルの式1本は、何本の式？ 3次元の長さと向きはどう出す？」**
- 最初の問い：3次元の矢印の式は、何を主張しているのか？
- 要点：𝐅＝m𝐚 ⇔ Fₓ＝maₓ、F_y＝ma_y、F_z＝ma_z（1本に見えて3本）。高校の「水平と鉛直で別々に立式」は束をほどく作業。3次元の長さは三平方を2回：√(Aₓ²+A_y²+A_z²)。単位ベクトル＝全成分を長さで割る：(0,3,4)/5＝(0, 0.6, 0.8)。零ベクトルは向きが決まらず割れない。位置ベクトルと移動ベクトル（2点の差）を区別。
- 補助線：①直方体の対角線：底面の対角線（影）を三平方 → その影と高さが直角 → もう一度三平方。新しい数値例：(1,2,2) で影 √5、全体 √(5+4)＝3。②新しい数値例：𝐅＝(6, 0, −20) N、m＝2 kg → 𝐚＝(3, 0, −10) m/s²。3本の式を成分ごとの行で並べる。
- 最後の問い：成分に分けた2本の矢印――力と移動――の内積を、角度を測らずに成分だけで計算できないか？

**前提（未習）**：3次元の座標軸の向き（右手系はステージ7）。

## 26. um-current-field（アンペールの法則・中級）— 中・2本
理由：∮ と正の向きの約束、μ₀ が初出。直線電流の式は対称性で1行。初級 26 の「一周の和は電流に比例」の係数を回収する。（本0＝上級 ue-ampere:5、本1＝:6、本2＝:7、本3＝:9、本4＝:10）

**1/2 本0〜本1「アンペールの法則 ∮𝐁·d𝐫＝μ₀I は、何を足して何と比べている？」**

- 最後の問い：この一周の和から、直線電流のまわりの B の大きさを1行で出せるか？

**2/2 本2〜本4（＋foundation 例題）「直線電流の磁場 B＝μ₀I/(2πr) は、なぜ1行で出る？」**

## 27. um-induction（電磁誘導・中級）— 難・3本
理由：「一周の起電力」と電位差の区別、負号と向きの約束、cos の微分、動く導線の2つの見方と、誤解しやすい区別が重なる。（本0＝上級 ue-faraday:3、本1＝:4、本2＝:5、本3＝:6、本4＝:7、本5＝:8）

**1/3 本0〜本1「一周の電場の和が 0 にならない――起電力 ℰ＝−dΦ/dt とは？」**
- 最初の問い：一周の E の和が 0 にならないのは、どんなときか？
- 要点：静電場なら ∮𝐄·d𝐫＝0（ステージ22）。磁場が時間変化すると循環する電場ができ、固定した輪で ∮𝐄·d𝐫＝−dΦ_B/dt。この一周の量が起電力 ℰ（単位 V、電位差と区別：初級 27-2）。ファラデーの実験法則で、代数から証明する式ではない。負号：面の法線と周回の正方向を右手でそろえたとき、変化を妨げる向き（初級 27 のレンツ）。
- 補助線：①静電場の一周（坂を上って下りる、合計 0）と、誘導電場の一周（回り続ける矢印、合計≠0）を並べ、坂の比喩が対応しない所を明示。②新しい数値例：1巻き、Φ が 0.1 s で 0.02 Wb 増える → ℰ＝−0.2 V（負号＝選んだ向きと逆に回る）。
- 最後の問い：N 巻きのコイルなら？ そして磁場の中でコイルを回し続けると、起電力はどう変わる？

**2/3 本2〜本4（＋foundation 例題）「発電機の交流 ℰ＝NBAω sin ωt を、微分で導く」**
- 最初の問い：N 巻き、そして回るコイルの起電力は？
- 要点：各巻きを同じ Φ が貫けば Ψ＝NΦ、ℰ＝−N dΦ/dt（10巻き、0.2 Wb/s → −2 V）。回るコイル：Φ＝BA cos ωt（初級 27-1 の「法線との角」）。cos の微分 −sin、中身から ω（ステージ3）→ ファラデーの負号と打ち消し ℰ＝NBAω sin ωt。速く回すほど振幅が大きい（電気の周波数は極の数にもよる）。
- 補助線：①Φ–t の cos と ℰ–t の sin を上下に並べ、Φ の傾きが最も急な時刻に ℰ が最大（ステージ1 の傾き）。②微分の一操作ずつ：−N×BA×(−sin ωt)×ω、負号2つの打ち消しを枠で。新しい数値例：N＝100、B＝0.1 T、A＝0.01 m²、50 Hz（ω≈314 /s）→ 振幅 約31 V。
- 最後の問い：磁場が一定でも、導線が動けば起電力は生まれるのか？

**3/3 本5「磁場が変わらなくても、動く導線はなぜ起電力 Blv を生む？」**
- 最初の問い：一定の磁場の中を動く導線に起電力は生まれるか？
- 要点：長さ l の棒が B に垂直に速さ v で動くと、囲む面積が毎秒 lv 増える → dΦ/dt＝Blv → |ℰ|＝Blv。同じ結果を棒の中の電荷の磁気力から：単位電荷あたり vB の力が棒に沿って働き、長さ l で vBl（ステージ25）。「磁束の変化」と「動く電荷の力」の2つの見方が一致。回路が閉じていれば I＝ℰ/R（初級 27-2）。
- 補助線：①レールと棒の図：Δt ごとに増える面積の帯 lvΔt を色付け。②棒の中の＋電荷に働く q𝐯×𝐁（棒に沿う）と、面積の増え方を左右に並べ、同じ値。新しい数値例：B＝0.5 T、l＝0.2 m、v＝3 m/s → 0.3 V。
- 最後の問い：起電力を持つ回路にコンデンサをつなぐと、電荷と電流は時間とともにどう変わる？ その変化を式で解けるか？

**前提（未習）**：なし（Wb は初級 27-1）。静電場でない電場という区別はステージ22 の 3/3 で予告しておく。

## 29. um-ac-maxwell（マクスウェル方程式・中級）— 中・2本

**1/2 本0〜本2「コイルの電圧は、なぜ電流より 1/4 周期進み、振幅比は ωL なのか？」**
