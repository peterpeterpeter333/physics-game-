## 補助線の入れ方
1. **比喩・例え話**：式が出る直前か直後に一言。画面に「たとえ」の札を出し、必ず本物の図と式に戻る。比喩が誤解を生む点は一言で断る（電気束は本当に何かが流れる量ではない、など）。
2. **図と式の一項を同じ番号・同じ色で結ぶ**：一片①を選ぶ → その値をカード①にする → カード②③… → 足す → Σ → 細かくして ∫。
3. **同じ比喩を章をまたいで使い回す**（4章の「風の中の散歩」を5章・7章でも、6章の「駅の改札」を8章でも）。

## 直した誤り・不正確な点
- 第7章：二つ目の面を「上から見下ろす」説明なのに、電場を奥向き（⊗）で描いていた。実際は手前向き（⊙）。カメラを本当に上から見下ろす向きに直し、磁場・周回の向き・符号を計算し直した（結果 B＝ε₀μ₀vE は同じ）。カメラの位置と世界の上向きを小窓で表示。
- 第4章：「一定の電流」＝どの場所でも電流も電荷の量も時間で変わらない定常状態（だから電荷がたまらない）。
- 第4章：半径（電線からの距離）と道に沿った一歩（Δℓ）を別の線・別の文字で描き分け、dr は「位置の小さな変化＝道に沿った一歩」と明示。
- 全章：場が場所で変わるときの有限の和は ≈、細かくした先で＝。
- 第5章：起電力を ℰ と書き、単位 V と区別（ℰ＝2 V、R＝4 Ω → I＝0.5 A）。
