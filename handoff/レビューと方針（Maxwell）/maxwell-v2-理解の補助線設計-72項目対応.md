## 方針：文章を増やす前に、見える関係を変える

ここでいう補助線は、文字通りの線だけではない。「比較する相手」「固定するもの」「矢印の影」「同じ物の別表現」「一瞬前の状態」「消せる未知数」も含む。

良い補助線は、視聴者が頭の中で補っていた一つの関係を、目の前に出す。短い説明でも推論を省略しない。補助線を出した直後に結論へ飛ばず、その補助線から何が読み取れるかを一つ説明する。

ただし、誤った等号・不十分な条件・未証明の一般化は、演出だけでは直らない。以下ではそれらを「要修正」と区別する。物理の経験法則を絵から証明したことにはしない。

既に理解を助けている試験電荷の比較、半径と円周の相殺、四辺の寄与の確認は維持・強化する。72個の新しい場面を追加する計画ではない。

## 特に効きそうな五つ：短い場面の組み立て

### A. 面積分：追加するのは「電場方向への投影」

1. 一様な電場と、小さな平面の窓を固定する。
2. 窓の縁から電場に平行な点線を伸ばし、電場に垂直な面へ投影する。
3. 窓を傾けると投影面積が減ることを見る。
4. 「同じ電場でも、受け止める広がりが減りました」。
5. 見かけの面積で考えるE×(A cosθ)と、成分で考える(E cosθ)×Aを同じ図へ対応させる。

土台は長方形の面積・投影・掛け算の結合法則。cosを知らない場合は直角三角形の比から導入する。窓を通る実体の粒を想定しなくても説明できる。

### B. 一般のガウス：追加するのは「同じ方向範囲を結ぶ線」

1. 正の点電荷と、形の違う二つの面をそのまま残す。
2. 電荷からごく細い円錐状の範囲を選び、両面の対応する部分だけ色を付ける。
3. 電荷からの距離が2倍なら、同じ角度範囲の垂直断面は縦横2倍、面積4倍になる。
4. クーロン則の電場は1/4になるので、積は変わらない。
5. 斜めの面はAの投影へ戻す。小部分を足して閉じた面全体へ進む。

土台は相似による面積比・逆二乗則・符号付きの和。凹面や外部電荷では同じ方向の交点を出入りで対にする段階が必要。これを省いて「一本の線で全証明」とはしない。静電場での導出であることも守る。

### C. 起電力：追加するのは「短い移動の拡大図」

1. 固定した回路の小区間を拡大し、電荷、力、移動の三つを区別して描く。
2. 力から移動方向への点線を下ろす。
3. 「この区間で電場がする仕事は、移動方向の力×距離」。
4. 電荷で割り、1 Cあたりへそろえる。力qEのqも割られてEが残る。
5. 各区間の値を一周分足す。これが固定回路で電場による起電力を表す線積分。

土台は仕事・一単位あたり・加算。磁場の線積分にも形は似ているが、同じ仕事とは呼ばない。動く導体は別の力も必要。

### D. 変位電流：追加するのは「二枚の膜の間の閉じた領域」

1. 同じ輪を縁とする面S₁、S₂を二枚とも見せる。二面の向きは輪に合わせてそろえる。
2. 二面の間の体積だけ薄く塗る。閉じた境界の向きはS₁と−S₂に取る。
3. その中の電荷Qが増える／減ると、流入と流出に差が出る。電荷保存よりI₁−I₂=−dQ/dt。
4. ガウス則ではΦ₁−Φ₂=Q/ε₀。その変化を取るとε₀(dΦ₁/dt−dΦ₂/dt)=dQ/dt。
5. 二式を足すとQの変化が消える。したがってI₁+ε₀dΦ₁/dtとI₂+ε₀dΦ₂/dtが一致する。

この補助線は、なぜ「和」で面依存がなくなるかを説明する。ただし、この整合性だけでアンペール–マクスウェル則全体が一意に証明されたとはしない。語りでは先に「流れの差」と「たまり方」の図を見せ、その後に上の符号と式を追う。

### E. 光速：追加するのは「前の波面の位置」

1. 固定した四角い経路に波面を入れ、少し前の位置を点線で残す。
2. 点線から現在の位置までの細長い長方形だけ塗る。
3. 幅は速さ×時間、高さはh。増えた面積はhvΔt。
4. 一様なBを掛け、Δtで割る。Bhvが、暗記する式でなく長方形の計算に戻る。
5. 別向きの面も同じ順に計算し、二本の関係から未知のEとBを消す。

土台は等速の移動・長方形の面積・一秒あたり・連立関係の代入。第一の関係だけでは速さを決められないことを、代入する前に確認する。

## 共通化して、動画を長くしすぎない

| 一度身につける見方 | 後で使う場所 |
|---|---|
| 一単位あたりへそろえる | 電場、起電力、変化率、速度 |
| 矢印の必要な方向への影を取る | 面積分、線積分、仕事、波の四辺の寄与 |
| 同じ状態で一つだけ変える | クーロン則、試験電荷、窓の傾き、半径、h |
| 前後の差を取る | 磁束変化、電流、変位電流、進む波面 |
| 何が変わらないか探す | 電荷保存、同じ束の電気束、同じ輪の線積分 |
| 欲しい量以外の未知数を消す | Eの定義、二式から光速を求める計算 |

同じ見方を使う場合も、その場面の図を使って再提示する。無関係な同一アニメーションを使い回すという意味ではない。既に説明したことは一言で呼び戻し、同じ講義を再演しない。

## 制作へ進むときの基準

- 補助線を追加した直後に、分からなかった関係が読み取れるか。
- 補助線の意味を理解するために、さらに未知の概念を大量に要求していないか。
- 式変形を見せるときは式へ、図を説明するときは図へ集中させる。常時全部を並べない。
- 同じ物を説明し続ける場面では、図を消して再登場させず、目印を残して変化させる。
- 意図的な比較を除き、色の意味・向き・観測点・正方向を途中で入れ替えない。
- 理解の確認は補助線を外した簡単な別例で行う。分かった気になる演出と、使える理解を区別する。
- 前の一覧にある音声同期・発音・表示欠落等の8項目は別の品質確認。理解の補助線を考えただけで解消したことにはしない。
