## 結論

最も困るのは難しい物理が出ること自体ではありません。

**簡単な足し算・掛け算は何度も説明される一方、文字式、三角関数、積分の計算で必要な前提が急に増える。その理解を確かめないままバトルに勝ててしまう**ことです。

想定する体験は「最初は分かった」→「また同じ話？」→「急に分からない」→「でもクリアになった」→「次の式が読めない」です。

単純に説明文やスライドを増やすより、前提の順序、問題との整合、復習への戻り方を直す効果が大きいと考えます。

## 1. 優先して直したい、理解以前の引っかかり

### 1-1. 「前問」を参照する問題がランダム出題される

高校「落体の運動」に「前問のボールが達する最高点の高さ」、高校「放物運動」に「前問で、着地までに水平方向へ進む距離」があります。一方、バトルは問題配列をシャッフルします。

必要な初速・高さが直前に出る保証がありません。「条件が書いていないのに解けと言われた」となる組み合わせが生じ得ます。シャッフル実装と問題文の照合による指摘で、今回の放物運動バトルでは、その条件不足の問題が出る前に敵HPが0になりました。

**対応：各問題を単独で解ける文章にする。連続問題にするなら順序と共通条件を固定する。**

### 1-2. 跳ね返る話が、途中で止める話になる

大学力学・中級「力積と運動量」6〜8ページ。

- 質量0.15kg、速度−20→+20m/sなら運動量変化は6kg·m/s。
- 直後の見出しは「0.010sで止める」ですが、計算は6÷0.010=600N。
- 同じ球を−20→0m/sに止めるなら変化は3kg·m/sで、平均力は300Nです。

また「符号を落とすと半分になる」という説明も、どの誤計算を指すのか不明確です。速度の大きさ同士を引けば20−20=0です。

**心の声：『止まるの？ 跳ね返るの？ 自分が何か読み落とした？』**

### 1-3. 「まとめて1回では計算できない」が強すぎる

大学力学・中級「内積で書く仕事」4ページ。一定の右向き4Nの力で、右3m・上2m・左1mと進む例です。

「辺ごとに角度が変わるので、まとめて1回では計算できない」とありますが、一定力なら合変位との内積で4×(3−1)=8Jと一度で計算できます。「全道のり6mをそのまま掛けられない」と区別する必要があります。

### 1-4. 本文の慎重な説明が、問題側で失われている

| 場所 | 本文と問題の食い違い |
|---|---|
| 大学力学・上級「トルクと角運動量」 | 本文は楕円軌道で `mr v⊥` と区別するが、ケプラー第2法則の選択肢は `mvr一定` とする。 |
| 大学数学・上級「微分方程式入門」 | 本文は連鎖律で変数分離を説明する一方、問題は「微小量の比だから分母を払える」という説明を正答にする。 |
| 大学数学・上級「単振動の方程式」 | 本文は `U''>0` という条件を示すが、問題は安定点なら「必ず放物線」と言い切る。 |
| 大学電磁気・上級「電流のミクロな正体」 | 中級本文は信号が順に伝わると説明するが、上級問題の正答は「全区間の電子が同時に動き始める」。 |
| 大学電磁気・上級「ローレンツ力」 | 本文はオーロラが低緯度にも現れると説明するが、問題は「極地方でしか見られない」を前提にする。 |
| 同「ローレンツ力」 | 「ローレンツ力が速さを変えられない」という問題文は、電場を含む全ローレンツ力と磁気力の区別が不足。 |
| 高校「単振動」 | 本文は振り子の小角近似を説明するが、振幅を増やす問題にはその条件が書かれていない。 |
| 高校「波の基本」 | 本文は実際の水面波の漂流に注意するが、問題は海水を例に「移動しない」と断定する。 |

初心者は本文を読み分けた結果、不正解になるのを特に嫌がるはずです。本文だけでなく、正答選択肢・誤答選択肢・解説を同じ前提で点検する必要があります。

### 1-5. 微分を理解しなくても「微分の道具箱」をクリアできる

大学数学・初級では、合成関数、三角関数の微分、積の微分を3ページで扱います。しかしバトルは「入力3を2倍して二乗」の1問だけです。36を選ぶと敵HP24が0になり、実際にクリアしました。

登録データ全体で、この1問構成の単元が39あります。初級の確認を簡単にすること自体は適切ですが、説明した内容との隔たりが大きく、クリアが理解の目安になりません。

### 1-6. ヒントが、その問題を解く助けになっていない

上記の算数問題のヒントが「対象・正方向・成立条件を決めてから、図と式を対応させてみよう。」でした。実画面で確認しました。

この問題なら「まず3を2倍するといくつ？ その数を自分自身に掛けよう」が必要です。汎用的な勉強方法と、その問題で一歩進めるヒントを分けるべきです。

## 6. やめたくなりそうな体験上の問題

1. **入口が決めづらい。** 高校範囲と大学初級のどちらが自分向けか判断が必要。実際には高校側のほうが単位・記号に丁寧な部分がある。
2. **「全部読む」が長すぎる。** 今回の主レッスンだけで1,051ページ。実際の学習時間は測定していないが、全員へ同じ反復を求める負担は大きい。
3. **簡単な話は繰り返し、難しい話は急。** 速度・仕事・短冊・内積が分野間で重複する一方、三角関数・対数・置換は速い。
4. **読めたことと解けたことが分からない。** 途中で自分の理解を試す機会が少なく、最後の四択が簡単だと理解の穴が残る。
5. **30秒制限が熟考と相性が悪い。** 実装上は1問30秒、早答えボーナスあり。ヒント閲覧中もタイマーを止める分岐がなく、設定画面に時間無制限の選択肢は見当たらなかった。時間切れ自体の再現試験は未実施。
6. **間違えたら、どこへ戻るかを自分で判断する。** 誤答後の説明はあるが、「この一手が分からないなら、このページ」の導線を強めたい。
7. **バトル後、次へ自然につながらない。** 実プレイでは「マップへ戻る」で高校力学の一覧に戻る。大学数学の続きには分野を選び直した。
8. **レッスンの続き位置を保ちにくい。** 標準レッスンのページは開くたび0からの状態で初期化される実装。短い休憩を挟む学習と相性が悪い。
9. **スマホに近い狭い表示で、図が遠い。** 約319px幅の表示では、長いタイトル・前提・目標・学習段階・本文・図の案内が積み重なり、図や式までスクロールが必要。画面幅によるため全端末共通とは断定しない。
10. **必要な補足を、自分で探して開く負担。** 記号・途中式・前提の折りたたみが複数ある。初めての記号ほど、どの欄に答えがあるか分からない。
11. **図が動いていても、自分で確かめる課題になっていない。** 「この条件ならどちらに動く？」と予想し、操作して答え合わせする流れが欲しい。
12. **本文と図が同じ条件とは限らない。** 一般的な概念図の流用や、操作で本文の前提から外れるケースでは、初心者は自分の読み方を疑ってしまう。
13. **AI先生が即座の救済にならない。** 設定ではAnthropic APIキーの用意と従量課金が必要。質問したい初心者に、別サービスの設定という壁がある。接続や送信は試していない。
14. **ゲーム上の成長と理解の成長が別。** XP・敵HP・コンボはあるが、苦手だった操作ができるようになったことを、バトル結果からは判断しづらい。

## 8. 改良するなら、この順番

1. **条件不足・本文と問題の不一致を直す。** 理解不足ではない失敗を先になくす。
2. **初級の急な段差を直す。** 特に文字式の展開、三角関数、指数・対数、原始関数。全範囲を長くするのではなく、必要な直前に短い橋を置く。
3. **説明途中に一手だけの問題を入れる。** 「式全部を導け」ではなく、「今回固定する量は？」「ここで代入する数は？」「次の符号は？」を問う。
4. **重複は確認問題で短縮できるようにする。** 同じ説明を削除するだけでなく、初見の人には残し、既習なら飛ばせるようにする。
5. **練習は時間無制限、バトルは任意にする。** 理解の途中で速さを競わせない。
6. **現在位置を保存し、誤答から必要な一ページへ戻れるようにする。** マップを探し直す負担をなくす。
7. **図・本文・途中式を同じ例にそろえる。** 操作で条件が変わったら、式や注意表示も追従させる。
8. **任意で使える自動音声ガイドを追加する。** 文章を読む負担を減らし、図や式に目を向けながら説明を聞けるようにする。詳細は下記。音声だけで説明の飛躍が解消するわけではないため、内容・出題の修正と合わせて進める。

最初の改良対象には「大学数学・初級の後半」を推します。ここで三角関数・指数関数・微分の足場ができないと、その後の力学・電磁気の説明を増やしても、同じ数学の箇所で止まるためです。

- 図の条件を操作した場合は、古い条件の音声を流し続けない。停止または現在の条件に合う案内へ切り替える。
- 音声の重要な情報は画面にも残す。音声だけに新しい前提や導出を隠さない。
- まず初級1単元で試作し、説明の長さ・聞き取りやすさ・図への集中しやすさを確認してから全範囲へ広げる。

読み上げ例：`d r⃗ = r⃗′(u) du` に対し、「求めたいのは小さな移動です。位置が目盛りあたりに変わる割合に、小さな目盛りの幅を掛けます。」と意味を説明する。記号の読み方は別操作でも確認できるようにする。

実装時の確認項目：

- [ ] オン／オフと設定保存が動き、オフでは勝手に音声が出ない。
- [ ] スライド移動・連打・画面終了でも音声が重ならず、古い音声が止まる。
- [ ] 一時停止・再開・再再生・速度調整が動く。
- [ ] 数式、添字、単位、ギリシャ文字を誤読せず、説明内容が表示式と一致する。
- [ ] 音声の説明箇所と強調表示・図の条件が一致する。
- [ ] 音声を使わなくても、同じ前提・説明・導出を確認できる。
- [ ] 対象のiPhoneアプリとブラウザーで、再生開始の制約や利用不可時の案内を確認する。
