# ⚡ Physics Quest — 高校物理RPG

**暗記は絶対ダメ。理解できる喜びを、ゲームの気持ちよさで。**

高校物理(物理基礎)を、RPG風のゲーミフィケーションで基礎から順番に学べるWebアプリ。
すべての公式に「なぜそうなるか」の導出レッスンが付いており、丸暗記を一切要求しない。

## 遊び方 / 学び方

1. **📖 レッスン** — 各ステージの敵に挑む前に、公式を1ステップずつ自分で組み立てる。
   例:「$x = v_0t + \frac{1}{2}at^2$ の ½ は三角形の面積の ½」まで理解してから進む。
2. **⚔️ バトル** — 制限時間つきの一問一答で敵のHPを削る。正解でダメージ、コンボで倍率UP、
   間違えるとハートが減る。**不正解でも必ず解説が読める**(むしろ間違いが一番の学び)。
3. **⭐ 復習** — 気になる問題にスターを付けて、あとからまとめて解説を読み返せる。
4. **📖 公式集** — 全公式+意味の一言+導出レッスンへのリンク。
5. **🤖 AI先生** — どの画面からでもワンタップでClaudeに質問できる(要・自分のAPIキー)。

## 技術構成

| 層 | 技術 |
|---|---|
| フロントエンド | Vite + React + TypeScript(SPA、サーバー不要) |
| 数式表示 | KaTeX(オフライン動作) |
| 進行データ | localStorage(アカウント不要) |
| オフライン対応 | PWA(Service Worker + Web App Manifest) |
| AIチューター | Anthropic API(Claude)/ ユーザー自身のキーを端末内に保存 |

## デプロイ(ブラウザ版)

`dist/` を静的ホスティング(Cloudflare Pages / GitHub Pages / Vercel 等)に置くだけ。
サーバーもDBも不要。

## Google Play への道(予定)

## AI先生についての注意

- 設定画面で入力したAPIキーは**この端末のlocalStorageにのみ**保存される。
- **一般公開する場合はこの方式のまま配布しないこと。** 不特定多数向けには
  サーバー側プロキシ(キーをサーバーに置き、利用制限を付ける)への切り替えが必要。

## 収録コンテンツ(5分野・27ステージ・142問・公式48本)

大学受験(物理基礎+物理)の基本範囲をカバー。

| 分野 | ステージ |
|---|---|
| 🏃 力学 (10) | 速度 / 加速度 / 等加速度3公式 / 落体 / 放物運動 / 力と運動方程式 / 仕事とエネルギー / 運動量と力積 / 円運動と万有引力 / 単振動 |
| 🔥 熱力学 (4) | 熱と温度 / 気体の法則 / 状態方程式 PV=nRT / 熱力学第一法則 |
| 🌊 波動 (5) | 波の基本 / 音波 / ドップラー効果 / 光波 / 干渉と回折 |
| ⚡ 電磁気 (5) | 電流とオーム / 電力とジュール熱 / 磁場と電磁誘導 / 電場とクーロンの法則 / コンデンサー |
| ⚛️ 原子 (3) | 光子と電子 / 物質波とボーア模型 / 原子核と放射線 |

分野同士は独立(学校の進度に合わせてどこからでも始められる)。分野内はステージクリアで順に解放。
問題はすべて**基礎レベル中心**のオリジナル問題で、全問に「なぜそうなるか」の解説付き。

### 図解エンジン

レッスンには**24種のアニメーションSVG図解**が組み込まれている(v-tグラフの面積、気体分子の運動、
ドップラーの波面、電磁誘導など)。エネルギー保存と気体分子はスライダーで操作できるインタラクティブ図解。
開発時は URL に `#figs` を付けると全図解のギャラリーが見られる。

## 利用状況の計測 (任意)

「何人が、どのくらい遊んでいるか」を見るための仕組みが入っている。**初期状態は完全にオフ**
(通信も一切しない)で、下記の設定をして初めて有効になる。

### 設定手順

1. [Umami Cloud](https://cloud.umami.is/) に無料登録 → Websites → Add website で
   `https://peterpeterpeter333.github.io` を登録し、**Website ID** をコピー
2. `src/analytics.ts` の先頭を書き換える:
   ```ts
   const PROVIDER: Provider = "umami";
   const SITE_ID = "コピーしたWebsite ID";
   ```
3. commit → push すると自動デプロイされ、以後 Umami のダッシュボードで数字が見られる

GoatCounter を使う場合は `PROVIDER = "goatcounter"`、`SITE_ID` にサブドメイン名を入れる。

### 見られるもの

| 標準で取れる | 送っているカスタムイベント |
|---|---|
| 訪問者数 / 訪問回数 / 滞在時間 / 国 / 端末 / 流入元 | `lesson-start` `lesson-complete` `battle-start` `battle-victory` `battle-defeat` `chat-open` `formulas-open` `review-open`(いずれもステージIDつき) |

このアプリは画面が変わってもURLが変わらないため、**カスタムイベントがないと「開いた」しか分からない**。
上記イベントにより「どの単元が人気か」「どこで脱落するか」まで追える。

### プライバシー方針

- Cookieを使わず、個人を識別するIDも発行しない(Umami / GoatCounter はいずれもCookieレス)
- 送るのは匿名の行動イベントのみ。**問題の解答内容・AIチャットの内容・APIキーは一切送らない**
- 主な利用者が未成年であることを踏まえ、個人特定につながるデータは収集しない
