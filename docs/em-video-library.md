# 大学電磁気・音声付き動画版

## 範囲

大学電磁気の初級16・中級14・上級10単元（40単元）。既存の315枚を、学習単位の境界を保った100本・合計約60.5分へまとめた。各動画は2～4枚に対応し、約21～51秒。短い説明を1分にするための無意味な間は足していない。高校電磁気・力学・数学はこの動画化の対象外。

元の良い図を使い、図の時計と音声・字幕を一本のMP4へ焼き込んだ。これは図全体を毎回作り直した映像ではない。静的な比較図も含む。数式はMathJaxのベクター描画。動画は計算の要点を最大3式で示し、省略した途中式を含む元の導出・記号説明はアプリの補足欄で確認できる。長い証明を動画だけで完全に代替する設計ではない。

各文は電場・電荷・力・道・面などの対象を明示して書き直した。「電場」は音声入力では「でんば」。位置・移動・力のベクトル、電位と電位差、電気束ゼロと電場ゼロ、経験法則と導出を区別する。

## 再生と画面

- 大きな動画、現在の場面の短い補足、折りたたむ途中式・記号・操作可能な図。
- 点で動画を選択し、場面ボタンで音声と図を同じ時刻へ移動。
- 自動再生なし。補足を開くと一時停止。端末読み上げとの同時再生を防ぐ。
- バトルと他単元への移動は視聴完了を必須にしない。
- 動画が読み込めない場合は直接MP4を開くか元のスライドへ戻れる。
- MP4はH.264/AAC、1280×760、24fps（元図の生成12fps）。図は上下のタイトル・字幕を除いた中央の大部分を使う。
- Web版は動画全体の自動オフラインキャッシュをしない。Rangeリクエストはサービスワーカーが横取りしない。iOSアプリに含めるには通常のビルド・Capacitor同期・署名・配布が別途必要。

## 音声の商用利用

音声は **VOICEVOX Nemo 男声1**（speaker 10001、Nemo Engine 0.24.0、speedScale 0.90）。動画内とプレイヤー下へクレジットを記載。音声エンジン自体はアプリへ同梱しない。

公式規約は https://voicevox.hiroshiba.jp/nemo/term/ 。生成音声の商用・非商用利用は、クレジットを含む規約の遵守を条件に認められる。YouTube転載時も動画内クレジットを残す。第三者による公式の保証・推奨を意味しない。3Blue1Brownの音声・映像・ロゴは使用していない。

## 再生成

1. `node scripts/build-em-film-plan.mjs`
2. 公式Nemoエンジンをlocalhost:50123で起動。
3. numpyを用意したPythonで `python scripts/render-em-film-audio.py`
4. `FFMPEG=/path/to/ffmpeg node scripts/render-em-films.mjs`
5. `npm run test:em-videos` と `python scripts/check-em-video-media.py`
6. `npm run build`

音声・中間ファイルの既定キャッシュは `/private/tmp/physics-em-films`。`EM_FILM_CACHE`で変更できる。音声は台本と声設定のハッシュで再利用。途中で止まった場合も音声生成、動画生成を同じコマンドで再開できる。特定の映像だけを更新する場合は `EM_FILM_FORCE=1` と末尾の動画IDを指定する。生成には日本語フォント、Node依存、ffmpeg、Pythonのnumpy（検証にはimageio-ffmpeg）が必要。

## 検証と限界

- 40単元、315枚が順番通り一度ずつ100本へ対応することを自動照合。
- 現行台本・字幕・音声タイムライン、ポスター、式の保持、全図の描画を検査。
- 100本すべてのH.264/AACを最後までデコードし、音声付き・長さ一致・破損なしを検査。
- ビルド、10項目の既存回帰検査、guided/math/remediation/narration検査。
- 狭い画面の動画表示・点による移動・補足表示を目視確認。
- Codex内ブラウザではMP4再生操作時にブラウザ接続が落ちた。ファイルのデコード検査は成功しているが、これは実機再生の成功を意味しない。iPhone実機・App Store版の確認と提出は未実施。
- 構造テストは、すべての説明の教育的な完成度や全動画の通し視聴を保証しない。
