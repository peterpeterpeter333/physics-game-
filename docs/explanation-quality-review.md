# 説明品質の再点検（2026-09-16）

## 結論

前回の「全章に反映」は共通UIと学習単元構成についての報告であり、各スライドの説明・図・導出がすべて学習基準を満たすことの証明ではなかった。表示テストの合格と教材としての分かりやすさを混同しない。

今回、全56章の元データ686枚を対象に、数式欄の種類と図の対応を棚卸しし、登録図131種類の説明文を横断点検した。これは全スライドの専門的な内容査読の完了を意味しない。電磁気冒頭2章は元データ31枚から68枚に構成されるため、表示枚数の合計は723枚。

## 今回の修正

- 電位の比較図：横軸「位置x [m]」、縦軸「電位V [V]」、青棒「電場Eₓ [V/m]」を表示。3 Vの差を3 m→1 mで比較し、1→3 V/mを数値で示す。「異なる一様電場の比較」であることを明記。
- 微分の図：比較図とは別に、同じ電位分布で二点を近づけるインタラクティブ図を作成。ΔVも変わる。粒子の軌道ではないこと、観測点と比較点、軸・色を説明。
- 電位から電場：目的→静電場の線積分→有限の差を距離で割る→連続性の下で極限→偏微分→微分の記法→三成分、の順に修正。「dxで割って極限」という順序の混同を除去。
- 電場の成分Eₓ,Eᵧ,E_z、位置x,y,z、積分用変数sの定義を追加。
- 数式欄の近くにも単元の目的を表示。ただし単元目標だけでは各操作の理由を説明できないため、個々の説明は別途点検が必要。
- 本文の数式再掲を、導出と誤認させない表示に変更。
- 電子の平均移動と電場を逆向きに修正。図は散乱の模式図と明記。
- 電位差の図の負号・仕事を電荷で割る操作を補足。
- ガウス則の適用対象を「3種類だけ」とする断言を修正。球殻内部の結論に球対称性を補足。
- 運動量保存に外力の力積、振り子に小振幅、円運動に一様磁場・垂直速度・電場なしの条件を補足。
- ケプラーの図のL=mrvをL=mr v⊥へ修正。一般の楕円では全速度と半径は直交しない。
- 速度グラフの符号付き面積と道のりを区別。
- 熱の「必ず一方通行」、安定点の「必ず単振動」を条件付きに修正。
- 共振曲線に速度比例の減衰項を反映し、共振点は固有振動数の近くと説明。
- 電場測定を実際に1 C置く説明から、小さな試験電荷でF/qを測る説明へ修正。

## まだ合格扱いにしない事項

1. 185枚の数式欄は専用の途中式ではなく式の再掲。定義・実験法則・直前の導出のまとめも含むため、185件の誤りという意味ではない。章内で導出済みか、定義・法則として導入すべきか、足りない途中式があるかを一件ずつ判定する必要がある。
2. 通常54章では図を複数スライドで再使用している。既存の良い図を維持する指定は満たすが、各スライドの操作・数値に図が対応するかは別の点検が必要。同じ図があるだけで合格にしない。
3. 記号辞書は章単位。すべての添字・記号について、その場での意味と単位の正しさを保証してはいない。
4. 図131種類の説明文点検と、全アニメーションの全時刻・全操作・小画面表示の検証は別。今回の実画面確認は指摘された電位周辺と変更した代表例。
5. 「目的」「結論」の共通欄があっても、本文の各操作が目的に結び付いているかは自動テストでは判定できない。

## 今後の合格条件

- 何を知っていて、何を求めるかが本文だけで分かる。
- 図の対象、軸、単位、矢印・色、固定量と変更量が分かる。
- 定義・実験法則・数学的帰結を分け、成立条件を先に示す。
- 各式変形に「その操作で何が分かるか」がある。
- 結論で目的に答え、次に使えることが分かる。
