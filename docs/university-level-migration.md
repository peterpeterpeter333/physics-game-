# 大学編の三段階化（2026-09-17）

## 対象と結果

数学9・力学10・電磁気10の全29単元に、初級／中級／上級の対応を設定。
既存41の準備レッスンに39を追加し、初級・中級は計80レッスン。
高校編27と大学上級29を合わせて全136ステージ。高校編は削除していない。

追加39レッスンは既存の良い説明・図・導出を選んで移したものを中心とする。
39個の確認問題を新たに作成した。すべての図を新規制作したという意味ではない。
対応と各段階の到達目標の正本は `src/content/university-curriculum.ts`。

## 内容の移動

- 上級の標準スライド216枚を初級／中級へ移動。155枚は新設レッスンの本編、61枚は既存レッスンの任意の補足。
- 電磁気の専用構成は5サイクル・20カードを準備レッスンの任意の補足へ移動。
- 上級は一般化・証明・応用を本編とし、前提は初級／中級へのリンクから確認できる。
- 元の問題ID・ステージIDを保持。移動した説明は元の図と途中式も保持。
- 元スライド番号を保存し、削除後の番号ずれによる別の要約の表示を防ぐ。
- ガウスの中心球は中級でクーロンの法則から電気束を計算し、上級の偏心球・一般化へつなぐ。
- 線積分では有限区間の近似と、極限で定義する正確な仕事を区別。

## 検証

`npm run build`、カリキュラム・初中級・教材・数式・途中式・学習順序・10原則の各監査を実行。
移動先の一意性、元の本文・図・式の保持、全29単元の三段階の存在、既存問題IDの保持を検査する。
追加39レッスンの全155スライドをブラウザで操作し、見出し・図・数式の読み込み・移動を確認。
同一単元の中級から上級への導線も確認。

自動テストは学習効果や全読者の理解を保証しない。初見の学習者による通し読みは別途必要。
