   - Web Speech API。速度0.75〜1.5倍。自動再生なし

### 検証結果（2026年9月18日実施）

**合格したもの:**

- `npm run build` 成功。監査9本すべて PASS
- コーデック `avc1.640020`（H.264 High@L3.2）+ AAC、faststart 済み → iOS/Android/PC で再生可能な形式
- カタログとファイルの整合: 欠けファイル0 / 孤児ファイル0 / タイムラインの隙間0
- Service Worker が `.mp4` と Range リクエストを除外 → 206レスポンスのキャッシュ事故なし、77MBがオフラインキャッシュに流れ込まない
- 動画読み込み失敗時のフォールバック（直接リンク＋「元の図と解説を開く」）あり
- ナレーション文への生TeX混入0。`render-em-film-audio.py` で 電場→でんば / 磁場→じば の読み変換が全100本に適用済み
- VOICEVOX クレジットが全フレームに焼き込み済み＋UI表示あり

**確かめられなかったもの:**

- **実機での再生**。この作業環境の Chromium は H.264 を持たないため不可（環境の制約であってアプリの不具合ではない）。ファイル自体が正しいH.264+AACであることはバイナリ解析で確認済み
