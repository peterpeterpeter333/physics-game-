## 共振の振幅式を係数比較で導く｜上級

**今回の問い：共振の分母の二つの項は、どこから来る？**

- 対応単元：`uc-shm`
- 条件：b>0、線形な強制振動の定常解。過渡解は別。
- 台詞を読む時間の目安：約43秒（合成音声で未計測。図を眺める時間や途中計算の間は別に確保し、動画をこの秒数に収めない）
- 前提の話題：`uc-shm`

### 場面1：出発点と疑問

**音声・字幕**

私たちは、外力と同じ角振動数のコサインとサインを足した関数を位置の候補にします。私たちは二回微分して運動方程式へ入れます。

**映像指示**：x=C cosΩt+D sinΩtを微分し、cosとsinの列へ整理。

**表示式**：mx″+bx′+kx = F₀cosΩt

**記号の説明**：mは質量、bは抵抗係数、kはばね定数、F₀は外力振幅、Ωは外力角振動数、C・Dは未知定数。

### 場面2：図と計算で確かめる

**音声・字幕**

すべての時刻で式を一致させるには、コサインとサインの係数をそれぞれ一致させます。二つの式を二乗して足すと、交差項が消えます。

**映像指示**：(k−mΩ²)C+bΩD=F₀と(k−mΩ²)D−bΩC=0を作り、二乗の和を展開。

**表示式**：[(k−mΩ²)²+b²Ω²](C²+D²) = F₀²

**記号の説明**：C²+D²は定常振幅の二乗。

### 場面3：分かったことと次への橋渡し

**音声・字幕**

位置の最大振幅は、二つの係数の二乗の和の平方根です。私たちは前の動画の振幅式を、候補の代入と係数比較から導けました。

**映像指示**：A=√(C²+D²)を入れ、Aの式を解く。

**表示式**：A = F₀/√((k−mΩ²)²+b²Ω²)

**記号の説明**：Aは定常振幅。これは解の定常部分であり、初期条件に依存する過渡部分を含まない。

**接続の区切り**：この主題の区切り。次の別主題との因果関係を無理に作らず、章選択へ戻れる。

## 逆数を使って軌道の方程式を作る｜上級

**今回の問い：距離の逆数へ変えると、どの項が消える？**

- 対応単元：`uc-frontier`
- 条件：中心力−GMm/r²。角運動量がゼロでない平面運動。
- 台詞を読む時間の目安：約45秒（合成音声で未計測。図を眺める時間や途中計算の間は別に確保し、動画をこの秒数に収めない）
- 前提の話題：`uc-frontier`

### 場面1：出発点と疑問

**音声・字幕**

私たちは、単位質量あたりの角運動量を一定値エイチと置きます。半径の逆数をユーとすると、角度の時間変化率はエイチかけるユーの二乗です。

**映像指示**：h=r²φ̇とu=1/rからφ̇=hu²を作る。

**表示式**：h = r²φ̇；u = 1/r

**記号の説明**：hは単位質量あたり角運動量、rは半径、φは角度、上の点は時間微分。

### 場面2：図と計算で確かめる

**音声・字幕**

半径を角度を通じて時間微分すると、一回目はマイナスエイチかけるユーの角度微分になります。二回目にも連鎖律を使うと、角速度の因子が現れます。

**映像指示**：ṙ=(dr/dφ)φ̇=−u⁻²u′hu²を約分し、さらに時間微分。

**表示式**：ṙ = −hu′；r̈ = −h²u²u″

**記号の説明**：u′とu″は角度φによる一階・二階微分。時間微分と記号を分ける。

### 場面3：分かったことと次への橋渡し

**音声・字幕**

半径方向の運動方程式へ二つの微分を入れると、共通の因子が消えます。残る方程式は、定数でずらした単振動と同じ形です。

**映像指示**：r̈−rφ̇²=−GM/r²へ代入して−h²u²で割る。

**表示式**：u″+u = GM/h²

**記号の説明**：Gは万有引力定数、Mは中心天体の質量。r>0、h≠0の範囲で割る。

**次につながる問い**：[単振動の解から、どう楕円の形が出る？](advanced-followups.md#uc-frontier-advanced-followups-3)

## 軌道の方程式を解いて楕円へ進む｜上級

**今回の問い：単振動の解から、どう楕円の形が出る？**

- 対応単元：`uc-frontier`
- 条件：前動画のu″+u=GM/h²を使用。近点方向をφ=0に選ぶ。
- 台詞を読む時間の目安：約44秒（合成音声で未計測。図を眺める時間や途中計算の間は別に確保し、動画をこの秒数に収めない）
- 前提の話題：`uc-frontier`

### 場面1：出発点と疑問

**音声・字幕**

ユーから右辺の定数を引くと、残る関数は角度について単振動の方程式を満たします。その解はサインとコサインの組です。

**映像指示**：w=u−GM/h²を導入し、w″+w=0へ変形。

### 場面2：図と計算で確かめる

**音声・字幕**

私たちは角度の原点を適切に選び、解を定数とコサイン一つの和にまとめます。距離へ戻すには、ユーの逆数を取ります。

**映像指示**：u=(1+e cosφ)/pからr=1/uへ戻す。

**表示式**：r = p/(1+e cosφ)；p = h²/(GM)

**記号の説明**：pは長さの定数、eは初期条件で決まる離心率、hは単位質量あたり角運動量。

### 場面3：分かったことと次への橋渡し

**音声・字幕**

離心率が一より小さい非負の値なら、距離はすべての角度で有限となり、軌道は円または楕円です。離心率は自由に選ぶ飾りではなく、初期の位置と速度から決まります。

**映像指示**：同じpでeを変える比較と、同じ初期条件ではeが固定される表示を分ける。

**接続の区切り**：この主題の区切り。次の別主題との因果関係を無理に作らず、章選択へ戻れる。

## サインの微分とラジアン｜上級

**今回の問い：サインを微分するとコサインになるのはなぜ？**

- 対応単元：`um-derivative`
- 条件：加法定理と単位円の極限sin h/h→1を前提から確認する。
- 台詞を読む時間の目安：約44秒（合成音声で未計測。図を眺める時間や途中計算の間は別に確保し、動画をこの秒数に収めない）
- 前提の話題：`um-derivative`

### 場面1：出発点と疑問

**音声・字幕**

私たちはサインの差の比へ加法定理を使い、入力の値と小さい増分を分けます。小さい増分だけの二つの比が現れます。

**映像指示**：sin(x+h)=sinx cosh+cosx sinhを差の比へ代入。

**表示式**：[sin(x+h)−sinx]/h = sinx(cosh−1)/h + cosx sinh/h

**記号の説明**：xは角度、hはゼロでない角度の増分。いずれもラジアン。

### 場面2：図と計算で確かめる

**音声・字幕**

単位円では、正の小さい角度でサイン、弧の長さ、タンジェントを比べられます。サイン、弧、タンジェントの長さの不等式から、サインを角度で割った比は一へ近づきます。

**映像指示**：sin h<h<tan hからcos h<sin h/h<1を描く。負の側は偶対称で確認。

### 場面3：分かったことと次への橋渡し

**音声・字幕**

コサインから一を引いて増分で割った比はゼロへ近づきます。差の比に二つの極限を入れると、コサインだけが残ります。

**映像指示**：(cosh−1)/h=−sin²h/[h(1+cosh)]を使って0を示す。

**表示式**：d(sinx)/dx = cosx

**記号の説明**：d/dxは角度xによる微分。ラジアンだからこの係数になる。

**次につながる問い**：[二つの変数が同時に変わるとき、変化をどう足す？](university-math.md#um-rules-advanced-draft)

## 円板と球の慣性モーメント｜上級

**今回の問い：球の慣性モーメントを、円板の積み重ねで計算できる？**

- 対応単元：`uc-rigid1`
- 条件：一様な密度。円板は中心垂直軸、球は直径を軸とする。
- 台詞を読む時間の目安：約46秒（合成音声で未計測。図を眺める時間や途中計算の間は別に確保し、動画をこの秒数に収めない）
- 前提の話題：`uc-rigid1`

### 場面1：出発点と疑問

**音声・字幕**

薄い円板を輪へ分けると、輪の面積は円周かける厚みです。輪の質量へ半径の二乗を掛けて積分すると、円板の慣性モーメントが求まります。

**映像指示**：半径sの輪にdm=σ2πs dsを付け、0からaまで積分。

**表示式**：I円板 = ∫₀ᵃ s²σ2πs ds = Ma²/2

**記号の説明**：σは面密度、aは円板半径、Mは円板質量、sは積分用半径。

### 場面2：図と計算で確かめる

**音声・字幕**

球を回転軸に垂直な薄い円板へ切ると、断面の半径の二乗は球の半径の二乗から高さの二乗を引いた値です。各円板の質量は密度かける体積です。

**映像指示**：3D球を高さzの円板で切り、a²=R²−z²、dm=ρπa²dzを示す。

### 場面3：分かったことと次への橋渡し

**音声・字幕**

各円板の慣性モーメントを高さ方向で積分した値は、球の慣性モーメントです。球の全質量を使って密度を消すと、五分の二という係数が残ります。

**映像指示**：(ρπ/2)∫₋ᴿᴿ(R²−z²)²dzを展開し、偶関数の積分を計算。

**表示式**：I球 = 8πρR⁵/15 = 2MR²/5

**記号の説明**：ρは体積密度、Rは球半径、M=4πρR³/3は球質量。

**次につながる問い**：[斜面を転がる輪と円板は、どちらが速くなる？](university-mechanics.md#uc-rigid2-advanced-draft)

## 体を縮める回転とエネルギー｜上級

**今回の問い：角運動量が一定なのに、回転エネルギーは増える？**

- 対応単元：`uc-rigid2`
- 条件：外部トルクなし。変形する物体なのでI一定の回転方程式は使わない。
- 台詞を読む時間の目安：約46秒（合成音声で未計測。図を眺める時間や途中計算の間は別に確保し、動画をこの秒数に収めない）
- 前提の話題：`uc-rigid2`

### 場面1：出発点と疑問

**音声・字幕**

回転する人が腕を縮めると、質量は回転軸へ近づきます。慣性モーメントが小さくなるので、角運動量を保つには角速度が大きくなります。

**映像指示**：人の模式図と質量位置を3Dで内側へ動かす。

**表示式**：L = Iω = 一定

**記号の説明**：Lは角運動量、Iは変形に伴って変わる慣性モーメント、ωは角速度。

### 場面2：図と計算で確かめる

**音声・字幕**

回転エネルギーを角運動量で書き直すと、慣性モーメントが分母に入ります。角運動量一定で慣性モーメントが減ると、回転エネルギーは増えます。

**映像指示**：K=Iω²/2へω=L/Iを代入。

**表示式**：K = L²/(2I)

**記号の説明**：Kは回転の運動エネルギー。

### 場面3：分かったことと次への橋渡し

**音声・字幕**

増えたエネルギーは、腕を引き込む内部の仕事などから供給されます。外部トルクがゼロという条件は、内部で仕事をしないという条件ではありません。

**映像指示**：化学エネルギー→内部の仕事→回転エネルギーの収支を表示。

**接続の区切り**：この主題の区切り。次の別主題との因果関係を無理に作らず、章選択へ戻れる。
