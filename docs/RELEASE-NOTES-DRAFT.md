| # | 項目 | 状態 |

### 1 について

動画100本の音声は VOICEVOX Nemo 男声1（speaker 10001）で生成している。
クレジットは全フレームに焼き込み済み＋UI にも表示している（`EMVideoLesson.tsx`）ので
表示義務は満たしているが、**生成済み音声をアプリに同梱して配布する**形態が
規約の許諾範囲かどうかは公式の利用規約で確認すること。
無料アプリなので商用利用制限には当たらない見込みだが、確認せずに提出しない。

### 2 について

App Store の上限（4GB）にも、セルラー回線でのダウンロード確認が入る 200MB にも達しないため
**提出自体は問題ない**。ただし既存ユーザーの更新ダウンロードが約90MBに増える。

### 3 について

このリポジトリには `ios/` が無い（`.gitignore` ではなく未生成）。Mac で `npx cap add ios` してから
実機で `um-line-integral-entry` など動画のあるステージを開き、再生できることを確認する。
再生できない場合でも `EMVideoLesson.tsx` に「元の図と解説を開く」フォールバックがあるため
致命的ではないが、動画が主目的の更新なので確認は必須。

## 1. バージョン番号

`package.json` は `0.1.0` のままだが、**iOS の版番号は Xcode 側で持つ**ため package.json は提出に影響しない。

Xcode → App → General で設定する:

| 項目 | 設定 |
|---|---|
| Version (`MARKETING_VERSION`) | 現在ストアにある版より大きい値（例 `1.1.0`） |
| Build (`CURRENT_PROJECT_VERSION`) | 前回より必ず大きい整数。同じ値だと App Store Connect が弾く |

## 6. Mac での手順

```bash
git clone https://github.com/peterpeterpeter333/physics-game-.git
cd physics-game-
npm install
npx cap add ios                 # ios/ は未生成のため必須
npm run sync                    # build + cap sync（dist 107MB を ios/ へ複写）
npx @capacitor/assets generate --ios \
  --iconBackgroundColor '#0b1026' --splashBackgroundColor '#0b1026'
npm run open:ios
```

Xcode で:

1. Signing & Capabilities → Team を選択
2. General → Version / Build を上げる（§1）
3. **実機**を選んで ▶ で起動し、大学電磁気のステージで動画が再生できることを確認（§0-3）
4. Any iOS Device (arm64) → Product → Archive
5. Organizer → Distribute App → App Store Connect → Upload

アップロード後、App Store Connect で §2〜§4 の内容を入力して提出。
