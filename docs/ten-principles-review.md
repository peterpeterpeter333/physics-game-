# 10項目による全範囲の改良・検査

対象：8分野・56章。元データ686枚、電磁気冒頭の再構成を含む表示723枚。問題266問は維持。

## 今回追加したもの

- 56章それぞれに、前に使える知識・出発点の定義や法則・成立条件・具体例・例から読める結論を執筆。短い本文を押し下げないよう、例と条件は開いて読む欄に配置。
- 131種類の図に、対象・軸や矢印の読み方・模型の条件を個別に執筆。章タイトルから自動で生成した説明ではない。
- 再生速度と物理量、視点変更と現象、模式図と実寸を区別する説明を追加。
- 空気抵抗の時間尺度をRC回路の図で説明していた箇所を終端速度の図へ修正。
- 磁場の導入に電荷の電場図が表示されていた箇所を、直線電流の磁場図へ修正。
- ガウスの法則32枚にも式の読み方・記号・単位・出発点からの途中式を併設。特にuは距離の二乗、dは球中心のずれ、Gは原始関数と明記。
- 波の媒質の往復を「移動しない」とする表現、一般の角運動量をmvrと読める表現、平面剛体の式で任意の運動が解けるように読める表現を修正。
- 式の参照欄185枚の本文と周辺の途中式を照合し、30箇所を追加修正。熱効率の仕事の符号、送電電力と線の損失の混同、インピーダンスの大きさと位相、初期位置と積分定数、微分で小項を捨てる理由、光電効果の模型、半減期の期待値などを明確化。
- 起電力ℰを電場Eと誤認しないよう記号照合を修正。εの字体違い、仕事や送電の添字も確認できるようにした。
- 熱機関には新しいインタラクティブ図を作成。100 Jの吸収熱を仕事と排熱へ分け、操作と効率・エネルギー収支が連動する。熱が移るだけの図から置換した。図の説明は計132種類。

## 10項目の検査表

自動検査は `npm run test:ten-principles`。公開前のCIでも実行する。項目の存在を検査するだけの箇所と、数学・物理の回帰検査を行う箇所を区別する。

|項目|今回の検査内容|機械判定の限界|
|---|---|---|
|1 知識のつながり|56章の前提、全学習単元の目的・結論、スライド範囲の整合|一つ前の知識だけで全操作が理解できるかは内容確認が必要|
|2 段階構成|基本事項・可変個数のステップ・結論、短い単元を含む既存構成の保持|枚数を増やすだけでは合格にしない|
|3 今の目的|章の目標、段の目的、計算の目的、電位の有限差分から微分への回帰検査|目標欄だけでは本文の一文一文の明確さを保証しない|
|4 短文と論理|通常本文150字以内、電磁気カードの長さ、元の補足の保持、入口説明の長さ|字数以下でも論理が飛んでいれば修正対象|
|5 式の意味と計算|56章の具体例、1423種の生成SVG、記号欄、電磁気の式ガイド、途中式のTeX、参照欄185枚の本文照合|参照欄を全て導出済みとは数えない。図・補足を含む全式の独立査読は別|
|6 現象と式|全スライドの図、132種の個別説明、SVGの有限な座標、電気と磁気・回路と落下の取り違え防止、熱機関の全スライダー値で収支を検算|全アニメーションの全時刻・全操作までは未検証|
|7 3Dの目的|面と法線・外積・らせん・電磁波の立体図、視点変更の説明、回転不変量・電気束の数値検査|すべての2D図を3Dにすべきかは個別判断|
|8 用語|章別の記号辞書、微積分記法、立体角・置換変数などの意味の明示|章辞書だけでは式ごとの全添字と単位の一致を保証しない|
|9 前提と証明|全章の法則・定義・条件、ガウスの内外・境界・重ね合わせ、球対称性、固定軸、崩壊の期待値|全導出の独立した数学的査読は別工程|
|10 操作・耐障害性|章ロックなし、点のナビ、強制停止文なし、SVGの404・オフライン代替表示|全端末のレイアウト検査は別工程|

## 結果の読み方

10項目の自動検査は合格。ただし「自動検査10/10」を「全教材の説明品質10/10」と呼ばない。上表の未検証事項は合格扱いにしない。

実ブラウザで全56章を未クリアの状態で開き、通常655枚と電磁気冒頭68枚、計723枚で目的と図の表示・スライド移動・数式エラーの有無を走査した。56章の具体例の欄も開いて確認。電磁気冒頭68枚は画像フォールバックが発生していないことも検査した。代表画面では具体例のSVG、図の説明、ガウス則の記号と途中式を目視確認。これは全画面の目視査読や全操作条件の網羅テストとは区別する。

`docs/explanation-quality-review.md` は前回時点の詳細な棚卸し。今回の表示・用語の改善後も、専用途中式でない185枚などの残課題を隠さず保持する。
