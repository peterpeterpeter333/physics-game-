# 磁束の角度と変化

対象：e-magnet-middle（67.6秒・3ページ）、he-why-06（45.0秒・2ページ、中級場面1後）。差し替え台本03が基準。

- 面、磁場、法線を固定視点の立体投影で示し、θが磁場と法線の間の角度だと白い弧で示す。
- 垂直成分B cosθに面積Sをかけて磁束へ進む。記号・読み・単位を式の近くに置く。
- 一巻きの磁束が0.01 Wb変わる例で、変化する2秒間の平均0.005 Vと、1秒間の平均0.01 Vを比較。グラフの停止後まで平均する意味にはしない。
- 傾けて止めた場面で、磁束0.005 Wbは残るが、起電力は0 Vとなることを示す。
- B・面積・角度を一つずつ変える。面積を二倍にする際は、一辺を√2倍にする立体モデルを使用。
- 0.5 T、0.02 m²、0°・60°・90°で0.01・0.005・0 Wbという元の数値を維持。
- 角度ゼロの例は面積を変えずに表示をフェードインする。軸ラベルと数値の重なりも修正。

検証：12音声区間・48時点・9専用図、磁束と平均変化率の数値。実MP4の各区間80%時点を2本とも目視。全体デコード、音声トラック、台本と字幕時刻の一致、全体回帰・手動ページ・ビルドを確認。

耳での音声通し聴取・全フレームの連続視聴・実学生での評価は未実施。確認方法を区別して記録する。
