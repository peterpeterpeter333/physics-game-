# 磁場と磁束の入り口

対象：prep-field-flux（95.9秒・4ページ）、e-magnet-intro（50.6秒・3ページ）。差し替え台本03・04と未変更指定場面に基づく。

- 電場は小さい試験電荷が受ける力を電荷量で割って定義。実際に1 Cの大きな電荷を置く必要があるような説明を避ける。
- 電場の矢印と、負電荷の力の矢印を区別。磁場の矢印は動く電荷の力と同じ向きではない点も付記。
- 方位磁針の向きと周囲の磁場を一致させた。磁力線は接線方向をつないだ線と説明。
- 描画本数を変えても測定値0.5 Tは一定。同じ描画ルールが必要な理由を比較図にした。
- 磁束は粒が通過する個数ではない。磁場・面積・面の向きという実測量で求める。
- 面・磁場・法線を固定視点の立体投影で表示。別の2D直角三角形で法線成分を示し、その後にΦ=BS cosθを表示。
- ファラデーの法則は実験による出発点として示し、一巻きの平均起電力の大きさと向きの説明を分離。
- 法線凡例と磁場矢印の重なり、3枚目カードの右端、下端の注記を修正。面に垂直な場合は角度0度に統一。

検証：14音声区間・56時点・11専用図。3Dの法線と面内ベクトルの直交、単位長、磁束数値を検証。実MP4の各区間80%時点を2本とも目視。全体デコード・音声トラック・台本一致・字幕時刻、全体回帰・手動ページ・ビルドを確認。
