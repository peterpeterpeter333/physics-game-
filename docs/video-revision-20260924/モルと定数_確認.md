# モルと定数：確認記録

対象：prep-mole（77.9秒、手動3ページ）、hp-why-06（39.9秒、場面3後）。台本04の内容と挿入を保持。

粒子数Nと物質量n、モル質量と全体の質量を区別。水36 g/18 g mol⁻¹=2 molを具体例として追加。n=N/N_Aを代入し、係数R/N_Aをまとめてk_Bへ置き換える操作を別々に表示。

定数の値は[NISTのSI定義](https://www.nist.gov/pml/special-publication-330/sp-330-section-2)で照合。台本の丸めた6.022×1.381=8.316382は小数第二位に丸めると8.32になるため、正確な定義値の積6.02214076×1.380649=8.31446261815324を使用し、最後に8.31と丸めるよう修正。十の累乗の相殺も別画面で説明。
