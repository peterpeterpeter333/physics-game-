# サインの微分と前提順序

対象：prep-sin-derivative。既存の前提教材を、台本04が指定するサインの運動への橋渡しとして再構成。

- 半径1の円の三角形・扇形の面積比較から sin h / h の極限を導く。
- 扇形の面積 h/2 は、一周2πに対する割合と円の面積πから説明する。
- 負のh、h=0では割れないこと、はさみうちの意味を説明する。
- (cos h−1)/h は分子分母に同じ数を掛けて変形し、先ほどの極限を利用する。
- 加法定理で差分を二つに分け、sin x の微分がcos xになるまで順番に示す。
- 動画は139.6秒、4つの手動区切り。14発話・56描画時点を検査し、実際のMP4から全発話の映像を取り出して確認した。
- とことんモードだけ、prep-sin-motionの直前に加法定理→サインの微分を配置する。一般的な依存関係の再帰展開はせず、無関係な単元には追加しない。
- モードをさっとへ戻したときは、非表示になる証明の代わりにサインの運動へ戻す。視聴済みかどうかは表示条件に使わない。
