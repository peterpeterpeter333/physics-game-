# 電位の値と傾き

対象：e-field-advanced（84.9秒・4ページ）、he-why-10（40.7秒・2ページ、上級場面3後）。差し替え台本03を基準に、物理上の誤解を招く表現を修正。

- 「電場は力なので」を、力を電荷で割った向きのある量と修正。
- 電場・力がゼロという話と、位置エネルギー・電位の値を明確に分ける。
- V=U/qの意味とJ/Cの単位を、18 J・2 Cの換算例で説明。電位の符号と空間の向きを区別。
- V=kQ/rは無限遠をゼロとする静止点電荷の式として提示。仕事の積分による導出を大学編で扱うことを明示し、この場面で証明したとはしない。
- 元の9+9=18 Vを維持。単に「数だから足せる」ではなく、位置エネルギーの和を同じqで割る式から説明。
- 「少し動いても電位が変わらない」を修正。中央で傾きゼロでも、そこから離れると電位が増える実際の点電荷のグラフを使用。
- グラフは左右1 mの同じ正電荷、中央で各9 Vの例。中央の18 V、x=0.4 mで約21.43 Vを同じ軸で表示。
- 電位の寄与を示す矢印と、電場の向きの矢印を区別する注記。値・接線のラベルの重なりを修正。

検証：12音声区間・48時点・8専用図。換算、電位の加算、中央の傾き、周辺での値の変化。実MP4各区間80%時点を2本確認。全体デコード、音声トラック、台本と字幕時刻、全体回帰、手動ページ、ビルドを検証。
