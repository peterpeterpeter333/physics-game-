# 進む波の式：確認記録

対象：prep-traveling-wave（93.1秒、手動3ページ）、w-basics-advanced（73.3秒、手動3ページ）、hw-why-02（27.3秒、上級場面2後）。台本02・04の例を保持。

原点の振動→伝わる時間x/v→原点の過去の時刻t−x/v→波の式という順序。前提は、形を変えず一定の速さで右へ進む波。原点の振動の時刻ゼロの状態も明示した。

前提動画では2 Hzと0.5秒、一周期2πから角振動数を説明。括弧を開いてωを両項に掛け、ω=2πf・v=fλを代入し、上下のfを約分して波数を導入。位置固定と時刻固定のグラフの横軸を分ける。

上級では同じ山を追い、tをt+Δt、xをx+vΔtへ置き換えて、増えた時間が打ち消し合うことを計算で確かめる。補足は4 m÷2 m/s=2秒を保持し、現在5秒なら原点3秒の状態を見る例を追加。伝播の目印を物質の粒と誤解しないよう注記。
