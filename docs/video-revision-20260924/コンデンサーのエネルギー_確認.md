# コンデンサーのエネルギー：個別確認

- 対象：e-capacitor-advanced（83.9秒、手動3ページ）、he-why-12（46.0秒、手動2ページ）。台本03の元の3場面と、2 μF・10 Vの数値例を保持。
- 最後の電圧を全電荷に掛ける過大評価 → 少量の電荷を分ける仕事 → 長方形の和 → 三角形 → Q=CVの代入、の順に再構成。
- 一定容量・ゆっくり電荷を分ける仕事と、抵抗を通して一定電圧の電池で充電する際の電池の全仕事を区別した。模式的な分岐図は、箱の面積がエネルギーの量を表すグラフではない。
- 記号Δと途中のq、最後のQ・V、マイクロの単位換算を明示。数値は二通りとも0.0001 Jになる。
- 図専用6種類、12音声区間、48時点の描画検査。実際のMP4から全音声区間の80%時点を抽出して、字幕・図・数式の対応と欠落を確認。全編デコード、音声トラック・尺・30 fpsも確認。
- 25回帰検査群、読みの検査、再現可能な再生ルート検査、手動ページ、全台本計画、0.9倍速と速度調整、ビルドが通過。
- 限界：音声を耳で通して聴いた確認や実際の初学者による理解度測定ではない。映像も全フレームの目視ではなく、上記区間ごとの抽出点検。
- 全範囲の完成ではない。前提動画の順序・重複点検は継続点検メモに残す。
