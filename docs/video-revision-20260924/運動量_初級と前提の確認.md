# 運動量の初級・前提・補足

対象：prep-impulse、m-momentum-intro、hm-why-16。差し替え台本01・04の例と意図を維持。

一定の合力と加速度 → 時間を掛ける目的 → 運動量の定義 → 力積 → 変化する力の面積 → 平均の力 → 内力の力積の相殺、という順序で導入する。

- 有限時間の速度変化を加速度に置き換える条件として、質量だけでなく合力も一定であることを明記。変化する力は後段で平均値と面積に拡張。
- 初級は2 kg・4 kgの台車を同じ3 m/sで動かし、同じ3 Nで止める。停止までの2 s・4 sを、停止後にも表示して比較できるようにした。
- 速度・合力・力積の矢印を区別。負の運動量変化は、最初の運動と逆向きという意味を説明。
- 作用反作用の図は「押し合う瞬間の力を整理した図」と明示。外力の力積がゼロという保存の条件を省略しない。
- 前提4区切り、初級3区切りは手動移動。補足は初級の指定場面1の後。
