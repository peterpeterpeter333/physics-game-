# 平行板の形と容量

対象：e-capacitor-middle（78.3秒・3ページ）、he-why-11（87.1秒・3ページ、中級場面1後）。差し替え台本03を基準。

- 平行板・電場・間隔を立体投影し、端を無視する条件を明記。
- Q、S、ε、dの意味と単位を説明。電場から仕事を経て電圧V=Edへつなげる。
- 電池なしでQ固定なら、間隔半分でE同じ・V半分・C二倍。電池ありでV固定なら、間隔半分でC二倍・Q二倍。比較条件を図の上と数値で明示。
- C=Q/VへV=Qd/(εS)を代入し、分数の逆数とQの約分を説明。Qの約分は物理的に電荷が消える意味ではない。
- 電気力線の本数を描く約束だけで法則を証明したことにせず、電場の重ね合わせの結果を表す図だと説明。
- 元の0.01 m²、1 mm、真空、88.5 pFの例を維持。mmからm、十の指数、ピコへの変換を段階化。
- 立体図で面積二倍にするときは縦横を√2倍にする。矢印の長さが間隔を示す場面では、電場の大きさは別の数値で比較すると注記。
- 図の事前点検で、矢印関数の引数が線幅でなくラベルになっていた箇所を修正。無意味な数字を消した後で動画を生成。

検証：15音声区間・60時点・6専用図。間隔・面積・容量の比、88.5 pFの数値計算。実MP4各区間80%時点を2本とも確認。全体デコード、音声トラック、台本と字幕時刻、全体回帰、発音回帰、再生ルート生成、手動ページ、ビルドを検証。
