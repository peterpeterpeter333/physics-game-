# 円運動の前提

対象：prep-circular。台本04に従い、万有引力の出どころ・Gとgの区別を保持し、元の接線・速度差・相似・加速度・周期を順に再構成。

- 速度は接線、ひもが切れた後の直進は「ほかに力が働かない」条件付き。
- 前後の速度の根元を平行移動でそろえてから、前の先端→後の先端へ差の矢印を描く。
- 時刻を近づける場面は、差の矢印を向きだけ拡大していると明記。矢印の長さを実際の速度変化の大きさと誤解させない。
- 二つの二等辺三角形は頂角が等しいため相似。黄色の辺の対応を説明。左右で異なる色の長辺を「同じ色」と呼ぶ記述は事前確認で訂正。
- 正確な有限角度の関係には直線距離ℓを使い、弧との長さの比が1へ近づくことを示してから極限へ進む。
- 時間で割る目的、v²/rの向きと単位、衛星の軌道半径は地表からの高さでないことを明記。
- 接線方向へ飛ぶ物体と速度の矢印が画面外へ出ない移動量に修正。
