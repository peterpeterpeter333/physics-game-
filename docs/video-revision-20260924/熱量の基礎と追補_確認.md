# 熱量の基礎と追補

対象：t-heat-intro、t-heat-middle、prep-heat-units、ht-why-10、hm-why-25。
台本02・04と01-02追補の指定内容・差し込み位置を保持した。

- 初級45.2秒：温度と水の量、熱として移るエネルギー、同じ温度差で質量10倍の比較。
- 中級62.9秒：実験的比例関係と適用範囲、比熱、100×4.2×10、温度差を求める代数、同じ質量・熱量で比熱だけを変える比較。
- 前提56.0秒：温度と熱量の単位、gとkg、最後の温度ではなく温度差を入れる理由。
- 追補ht-why-10は30.7秒、熱初級場面3の後。100 gと1000 gを同じ1℃だけ温める計算を、10組の熱量の和と対応させる。
- 追補hm-why-25は31.6秒、単振動初級場面3の後。両端と中央で力・速度を比較し、慣性で中心を通過した後の減速を見せる。

修正した表現：

- 「端ではばねが伸びる」を「伸びや縮みが最大」に修正。水平ばねの左端も正しく扱う。
- 「速度が最大」は方向によって誤解するため「速さが最大」とした。
- 往復が続く理由を単なる「ずれ」で片付けず、中心での慣性と、その先で速度に逆らう力を説明。
- 表示文の「水が融ける」を削除し、沸騰などの状態変化がない範囲とした。
- 同じ熱量なら温まり方を比熱で比較できるという説明に、同じ質量という条件を付けた。
