# 速度・加速度：初学者目線の再点検（2026-09-24）

## 確認方法と限界

前提知識が少ない初学者を想定し、読み上げ原稿、式、図、発話タイミングを照合した。実際に生成した MP4 の各発話の約80%時点からフレームを抽出し、時間順に確認した。別途、描画テストで発話内の複数時点を検証する。

これは全編を音声付きで通して視聴した検査ではない。この環境では音声を直接聴取できず、声の自然さ・聞き取りやすさの最終確認は未実施。静止フレームの確認だけで動き全体の滑らかさを保証することもできない。実際の学生による理解度の評価とは区別する。

## 今回の修正方針

- 未定義の用語は図上の場所を指してから使用する。
- 数値を列挙する場合は、一つの発話と一つの強調表示を対応させる。
- 式の読み上げでは括弧の範囲を言葉でも明確にする。
- 物理的な条件を省略しない。加速度一定と速度増加は同義ではない。
- 元の台本の論旨を保ち、必要な説明だけを補う。

## 残る確認

- 音声を実際に聴く検査と全編の連続再生確認。
- 平均を表す単独の上線付き記号の大きさなど、スマートフォンでの視認性の追加確認。
