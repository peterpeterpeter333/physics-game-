# 気柱とうなり：確認記録

対象：prep-sound-boundary（80.8秒、手動3ページ）、w-sound-middle（77.5秒、手動3ページ）、hw-why-03（28.7秒、中級場面3後）、w-sound-advanced（68.5秒、手動3ページ）、hw-why-04（33.2秒、上級場面2後）。台本02・04の各例を保持。

閉端・開端で、空気の変位と圧力変化を区別。前者の節は後者の腹になることを、管の中の空気の往復で示す。変位を縦に描いた曲線は、実際の空気の上下運動ではないと明記。灰色の延長は波長を読むためで、管外の実際の振動形ではない。

節から隣の腹、腹から隣の腹という距離からL=λ/4、L=λ/2を作り、両辺への乗算、f=v/λへの代入、比の整理を別の式画面で説明。端の補正を無視し、最も低い音・同じ音速・同じ長さで比較する条件を付記。0.5 m、340 m/sから170 Hz・340 Hzを計算。

うなりは、二つの振動の相対的な進みを針で表示。一回ぶん追い越すたびにタイミングが戻ることから差の絶対値へつなぐ。5 Hz・7 Hzは観察用の遅い模型で、可聴音の実演ではないと補足。440 Hzと442 Hzの元の振動数と2 Hzの強弱を区別し、0.5秒ごとの山を数える図も追加。
