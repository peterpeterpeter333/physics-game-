# 位置エネルギーと保存条件

対象：prep-potential-conservation、hp-why-07。
差し替え台本04を使用。元の場面はmanuscriptScenesに保存。

一定速度で持ち上げる手の仕事 → 重力の負の仕事との区別 → 高い位置から落ちる際に受けられる仕事 → 位置エネルギーの定義 → 基準を決めてmgh → 落下中の交換 → 保存条件、とつなぐ。

原稿の「ゆっくり」だけでは力のつり合いを厳密に言えないため、一定速度の条件にした。地表近く、重力加速度一定を明記。
位置エネルギーは運動エネルギーとは別の量であり、持ち上げて速さが変わらなくても位置エネルギーは増えることを補足。
摩擦・空気抵抗があるときに減るのはKとUの合計であって、エネルギー全体が消えるのではないと区別。
数値例は1 kg・高さ2 m・静止から落下・空気抵抗なし。19.6 Jからv²=39.2への両辺2倍と、正の平方根を取る理由を分けて説明。等加速度の方法と同じ約6.3 m/sへつながる。

前提動画は4区切りを手動で移動。数値補足は原稿どおり場面3の後に挿入する。
