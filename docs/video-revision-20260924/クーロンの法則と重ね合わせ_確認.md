# クーロンの法則と重ね合わせ

対象：e-field-middle（74.8秒・3ページ）、he-why-09（69.8秒・2ページ、中級場面1後）。差し替え台本03を基準とする。

- 同じ二電荷で距離だけを変え、(2r)²=4r²から力の1/4を説明。
- 力を試験電荷の大きさで割り、約分して電場を求める。試験電荷を替える比較と、元の電荷の符号を替える比較を区別。
- 各電荷の電場を同じ観測点で足す。上下にずらした矢印には表示上の理由を明記。
- 放射状の電場と半径r・2rの球面を立体で表示。線の絵だけを物理法則の証明にせず、クーロンの法則と面積の対応として説明。
- kの別表示とESの計算が一続きの式に見えたため別画面へ分割し、音声も再生成。
- 元の1 μC、1 m、0.009 N、2 m、0.00225 Nを維持。マイクロと指数の計算を補足。
- 数値例の図は説明中の1 mに固定し、表示と音声の比較条件を一致させる。

検証：14音声区間・56時点・5専用図。力の比、実数値、電場の符号和、球面の面積比。実MP4各区間80%時点を2本確認し、修正後の差し込みも再確認。全体デコード、字幕時刻、音声トラック、全体回帰、手動ページ、ビルドを検証。

耳での音声通し聴取・全フレームの連続視聴・実学生での評価は未実施。画像による映像点検とは区別する。
