# 電場と力と速度

対象：e-field-intro（74.4秒・3ページ）、he-why-08（26.4秒・1ページ、初級場面3後）。差し替え台本03の例を維持。

- 元の電荷と試験電荷を明確に区別。電場は力そのものではなく、正の試験電荷が受ける力を電荷量で割ったもの。
- 「一クーロンあたり」は換算であり、実際に1 Cを置く必要はないと説明。
- 試験電荷の符号だけを替えて、元の電場が変わらず力が反転する比較。
- 電場・力・速度の色を固定。上向きの電場、負の電子への下向きの力、右から下へ曲がる速度を示す。
- 軌道と接線速度を描く場面と、三つの矢印の意味を分ける場面を別の図にした。
- 元の3 N/C、±2 C、±6 Nを維持。計算練習用の理想化であることと正方向を明記。
- 電場マップの矢印の長さは距離の二乗に反比例。端の矢印と説明の重なりを修正し再描画。

検証：10音声区間・40時点・6専用図。実MP4の各区間80%時点を2本確認し、修正後の初級も再確認。全体デコード、音声トラック、台本・字幕時刻、全体回帰、手動ページ、ビルドを検証。
