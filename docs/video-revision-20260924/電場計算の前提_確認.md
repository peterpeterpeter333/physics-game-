# 電場計算の前提

対象：prep-coulomb-field（57.5秒・2ページ）。差し替え台本04で指定された、回路・送電を含めない電場専用の前提動画。

- 同じ電荷で距離を変える比較と、距離を固定して試験電荷を変える比較を分離。
- 距離二倍で分母四倍、試験電荷二倍で力二倍、力÷電荷が一定という順に説明。
- 同じ観測点での電場を加える。反対向きで同じ大きさならゼロ、違えば差が残ることを別の図で示す。
- 電場の矢印を上下にずらす図には、同じ場所の量を見分けるためと明記。
- 完成ファイルの登録だけでは新規前提が再生用一覧に入らないため、専用の登録処理を追加。台本04の指定通りe-field-middleだけに割り当て、無関係な回路の場面は追加しない。
- 新規前提を旧来の数値インデックス復元から除外し、以前の続き位置をずらさない。初級・上級の電場への割り当ては増やさない。

検証：6音声区間・24時点・4専用図。実MP4の各区間80%時点を確認。全体デコード、音声トラック、台本と字幕時刻、全体回帰、手動ページ、ビルドを検証。

耳での音声通し聴取・全フレームの連続視聴・実学生での評価は未実施。確認方法を区別して記録する。
