# 二重スリットと一つのスリットの回折

対象：w-interference-middle（70.2秒）、hw-why-09（75.3秒）、w-interference-advanced（70.7秒）、hw-why-12（40.5秒）。差し替え台本02を基準に図と式を専用化。

## 初学者向けの修正
- 二重スリットの間隔dと、一つの隙間の幅aを図で区別。
- 道の差を表す三角形から、明線の位置、隣り合う縞の距離へ進む。小角・遠方近似の条件を明示。
- sinとtanを同一視できる範囲を、角度を小さくする図で確認。
- 一つの隙間の上半分・下半分で点を組にし、半波長の差で各組の電場が打ち消し合うことから最初の暗い方向を導出。
- 両辺を二倍する操作と幅で割る操作を別の音声区間に分割。
- nm、mmをmに直す指数計算を説明。0.006は角度ではなくサインの値と明示。
- 同じ角度でも遠いスクリーンで間隔が大きくなることを表示。図の縦方向の拡大、強度グラフの最大値をそろえた比較を明示。
