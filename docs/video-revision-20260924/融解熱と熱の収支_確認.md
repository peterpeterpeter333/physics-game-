# 融解熱と熱の収支

対象：t-heat-advanced、prep-melting、ht-why-01。台本02・04の内容と、熱上級場面3の後という差し込み位置を保持。

- 上級51.2秒：氷が融ける質量と熱量は増えるが温度はほぼ一定、mLとmcΔTの役割、混ぜるときの熱収支。
- 前提60.8秒：融点を説明し、0℃の氷100 gを融かして20℃の水にする例を33400 J＋8400 J＝41800 Jまで計算。
- 補足50.4秒：80℃と20℃の水各100 gについて、熱量の等式→共通の係数で割る→両辺にTと20を足す→2で割る→50℃、と順番に説明。
- 容器への熱、外への熱、仕事の出入りを無視する条件を明記。質量・比熱が違えば単純平均ではないと補足。
- 氷と水の割合の棒は体積ではなく質量を表すと明示。融点の条件は一気圧の純粋な氷。
- 融かす質量gと融解熱J/gをそろえ、氷が残る場合と全部融ける場合を混同しない。
