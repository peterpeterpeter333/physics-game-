# 斜めの力の仕事と、三角比の前提・補足

対象：m-energy-middle、prep-trig、hm-why-14、hp-why-01。
差し替え台本01・04に対応。元の場面はmanuscriptScenesに保持。

## 説明の順序

横4・縦3・斜め5の三角形 → 拡大しても辺の比が一定 → cosとsinの定義 → 分母を消す掛け算 → 速度を横8・縦6に分ける例。
中級は、床から浮かない台車 → 力の成分と移動の対応 → cosθ = Fₓ/F → 両辺にFを掛ける → 横の力を仕事の式へ代入 → 摩擦も含めた仕事の合計。
hp-why-01は原稿どおり前提の場面2直後。数値で二乗・通分を確かめ、三平方の定理で一般化する。
hm-why-14は中級の場面2直後。cos60°=1/2は突然の数値として出さず、正三角形を半分にする図を補った。

## 修正した点

- 縦の力の仕事がゼロなのは、縦への移動がゼロだからと明示。「仕事は運動エネルギーを変えた分なので」と一つの力について断定する説明は修正。
- 合計の仕事と個別の仕事を区別。10 Jと−4 Jの合計6 Jの例。
- 図の拡大倍率を1倍から2倍にし、端の値を4・3・5から8・6・10にそろえた。
- 完成MP4で、三角形の頂点が見出しに近づく点、縦の矢印が文字に重なる点を発見。配置を修正して該当2本を再生成。
- 角度90°の表示時間を設け、仕事ゼロの場面を一瞬で通り過ぎないようにした。
- 前提の補足も、とことんモードから手動で進める。さっとモードでは補足を挟まない。
