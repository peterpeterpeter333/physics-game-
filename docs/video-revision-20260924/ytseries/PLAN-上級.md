## 1. um-derivative（微分・上級）— 中・3本
目標：べき関数・三角関数の微分を導き、微分できない点も判別する。
理由：中級は x＝t² を展開して 2t を出しただけ。上級は一般の n（二項展開の「h を1個含む項」）、加法定理と2つの小角の極限による sin・cos、そして傾きが決まらない点、と別々の3つの一歩がある。（上級に残る本：本6・本8〜本12＝表示0〜5。本0・本1 は初級、本2〜本5・本7 は中級で使用済み。準備：ui-average-to-now、um-average-rate、um-simple-derivative-equation、ui-motion-record〔シリーズ外〕）

**1/3 本6（＋上級の入口の部品リスト）「tⁿ の微分が ntⁿ⁻¹ になるのは、なぜどの n でも言える？」**
- 最初の問い：（中級の締め、um-ac-maxwell-2 の最後の2文）中級では、x²、sin、cos、指数関数の微分を、差の商と中身の倍率を頼りに使ってきた。では、t の n 乗や sin の微分は、どんな関数でも同じ手順で導けるのか？ 傾きが決まらない点はあるのか？
- 要点：冒頭1場面で上級の入口の部品リスト（4つ）を示し、今回は部品③（極限）を使うと告げる。振り返り1場面：(t+h)²−t²＝2th+h²、h で割って 2t+h → 2t（中級 01）。(t+h)³＝t³+3t²h+3th²+h³ → 差商 3t²+3th+h² → 3t²。一般の正の整数 n：(t+h)ⁿ を n 個の (t+h) の掛け算と見て、h をちょうど1個選ぶ選び方が n 通り → ntⁿ⁻¹h。h² 以上の項は h で割っても h が残り 0 へ（導いた結果）。定数倍 (atⁿ)′＝antⁿ⁻¹、和の微分は各項の微分の和（差商が項ごとに分かれるから）。確かめ：x＝5t² → 10t（初級 01 の t＝1 で 10）。
- 補助線：①立方体の辺を t → t+h に伸ばす図：増える体積は「面の板 t²h が3枚」「棒 th² が3本」「角 h³ が1個」を式の3項と同じ色（初級 03-1・中級 01 の正方形の図の3次元版）。新しい数値例：t＝1、h＝0.001 で ((1.001)³−1)/0.001＝3.003001 → 3。②(t+h)(t+h)(t+h) の3つの括弧のうち、どれから h を取るかの3通りを並べた表（「h を1個含む項の係数＝n」）。新しい数値例：x＝2t³−4t → v＝6t²−4、t＝2 で 20。
- 最後の問い：べき関数は展開で片付いた。しかし sin(t+h) は展開の公式がない。sin の差をどうほどけば、傾きが cos になると示せる？

**2/3 本8・本9・本10（本7 は中級で使用済み＝振り返り）「sin の傾きが cos になることを、差の計算で示せる？」**
- 最初の問い：sin(t+h)−sin t を、どうほどくか？
- 要点：加法定理 sin(t+h)＝sin t cos h＋cos t sin h（高校の公式として使う）。差商＝sin t×(cos h−1)/h＋cos t×(sin h)/h（2つの部品に分ける）。必要なのは2つの小角の極限：sin h/h → 1、(cos h−1)/h → 0（ラジアン。中級 01-2 補4 の振り返り）。単位円で「三角形 ≤ 扇形 ≤ 大きい三角形」の面積 ½sin h ≤ ½h ≤ ½tan h → cos h ≤ sin h/h ≤ 1 → 両側が 1 へ（はさみうち）。(cos h−1)/h＝−(sin h/h)×sin h/(1+cos h) → −1×0＝0。よって (sin t)′＝cos t。cos も同じ手順で cos t×0−sin t×1＝−sin t（本10）。本9 の「傾きを記録すると cos の形」は、観察だったものが今は証明になった、と対比する。度で測ると sin(1°)/1≈0.01745（＝π/180）で 1 にならない。
- 補助線：①単位円の3つの図形（小さい三角形・扇形・大きい三角形）を重ね、高さ sin h、弧 h、接線 tan h を同じ色で。新しい数値例：h＝0.1 で sin h/h＝0.998334、(cos h−1)/h＝−0.049958。h＝0.01 で 0.9999833、−0.0049999。②新しい数値例：t＝0.5、h＝0.01 の差商 (sin 0.51−sin 0.5)/0.01≈0.8752、cos 0.5≈0.8776 を並べ、差商の2つの部品（sin t×(−0.005)、cos t×0.99998）を色分け。
- 最後の問い：導関数の表がそろった。位置の式から速度・加速度を順に出すと何が読め、どんな関数でも傾きは1つに決まるのか？

**3/3 本11・本12「位置 → 速度 → 加速度の階段と、傾きが決まらない点」**
- 最初の問い：微分を運動へ使い、傾きが1つに決まらない点を見分けるには？
- 要点：v＝dx/dt、a＝dv/dt＝d²x/dt²（「2乗」ではなく「2回微分」の印）。x の傾き → v の値、v の傾き → a の値。新しい数値例：x＝t³−3t（m、s）→ v＝3t²−3、a＝6t。t＝1 で v＝0（折り返し）だが a＝6 m/s²（速度0でも加速度は0でない）。x＝3 sin 2t → v＝6 cos 2t、a＝−12 sin 2t＝−4x（中級 03 の連鎖律の振り返り）。x＝|t|：t＝0 で右からの差商 +1、左から −1 → 行き先が一致せず微分できない（導いた結果）。つながっている（連続）ことと、なめらか（微分できる）ことは別。物理の読み：壁で瞬間に跳ね返る球の理想化では速度が跳び、その瞬間の加速度は決まらない（モデルの限界）。
- 補助線：①x、v、a のグラフを縦に3段並べ、各時刻の傾き → 下の段の高さを同じ色の点で結ぶ（中級 01-2 の2段の図の3段版）。②|t| の角を拡大し続けても角のまま（なめらかな曲線は拡大すると直線に見える＝中級 04-1 の対比）。新しい数値例：h＝0.01 → (|0.01|−0)/0.01＝+1、h＝−0.01 → (|−0.01|−0)/(−0.01)＝−1。
- 最後の問い：微分の道具はそろった。逆向き――傾きから元の量を戻す積分――で、中級で図で納得した「面積の増え方＝その場所の高さ」は、どう証明できる？

**前提（未習）**：加法定理（高校の公式として使う）、はさみうちの原理（図で納得）、二項係数の一般の形（「h を1個含む項」だけ使う）。

## 2. um-integral（積分・上級）— 中・2本
目標：微積分の基本定理から定積分を計算し、初期条件付きの位置を求める。
理由：中級 02-3 で「証明は上級」と約束した基本定理の証明が中心。後半の本10・本11（一定加速度の公式を積分で作る）は中級 10 で済んでいるので振り返りに留め、新しい数値例（加速度が時間で変わる場合）で「公式に頼らない」利点を見せる。（上級に残る本：本6・本9〜本12＝表示0〜4。本0・本1 は初級、本2〜本5・本7・本8 は中級で使用済み。準備：ui-area-is-distance、um-sum-to-integral、um-constant-force-derive、ui-curve-tiles・ui-work-changing・um-work-sum〔シリーズ外〕）

**1/2 本6「"面積の増え方＝高さ"は、どう証明する？――微積分の基本定理」（中級 02-3 の回収）**
- 最初の問い：「面積の増え方＝その場所の高さ」は、どう証明できるか？
- 要点：A(x)＝∫_a^x f(s)ds（上端を変数にした面積の関数、中級 02-2）。右端を h だけ動かすと増える帯 A(x+h)−A(x)。f が連続なら、帯の中の f の最小値 m_h と最大値 M_h で m_h·h ≤ 帯 ≤ M_h·h。h で割ると m_h ≤ (A(x+h)−A(x))/h ≤ M_h、h → 0 で両側が f(x) へ → A′(x)＝f(x)（導いた結果。有限の帯では ≈、極限で ＝）。次に、微分すると f になる任意の F について (A−F)′＝0 → A−F は定数（前提として使う）→ A(x)＝F(x)−F(a) → ∫_a^b f dx＝F(b)−F(a)。中級 02-3 の「図による納得」がここで証明になった、と言う。
- 補助線：①帯を下から長方形（高さ m_h）、上から長方形（高さ M_h）ではさむ図、h を縮めると2つの長方形の高さが f(x) に寄る。新しい数値例：f(s)＝s²、x＝1、h＝0.1：帯の面積 (1.1³−1³)/3＝0.110333、h で割って 1.10333 は f(1)＝1 と f(1.1)＝1.21 の間 → h→0 で 1。②「差の鎖」：Σ[F(xᵢ₊₁)−F(xᵢ)] で途中の F が打ち消し合い F(b)−F(a) だけ残る図（上級 ue-integrals 本6 b2 でもう一度使う）。
- 最後の問い：原始関数が見つかれば積分は引き算1回。では tⁿ の原始関数は何で、使えない n はあるか？ 加速度が時間で変わるとき、位置はどう求める？

**2/2 本9〜本12（本10・本11 は中級 10 の振り返り）「tⁿ の積分と例外 n＝−1、そして変わる加速度から位置を求める」**
- 最初の問い：tⁿ の原始関数と、使えない n は？
- 要点：候補 tⁿ⁺¹/(n+1) を微分すると (n+1)tⁿ/(n+1)＝tⁿ（微分で検算：部品として毎回使う）。n＝−1 だけ分母が 0 → 1/t の原始関数は ln|t|（t≠0。ln の微分は次の単元で確かめる、と予告）。定積分の計算は必ず「上端の値−下端の値」：v＝2t で 0〜3 s は 9 m、2〜3 s は 9−4＝5 m（本12）。一定加速度の公式 v＝v₀+at、x＝x₀+v₀t+½at² は中級 10 で2回積分して作った（振り返り1場面、積分定数2つ＝初速度・初期位置）。
- 補助線：①表：n＝2、1、0、−1、−2 の行に「微分」「原始関数」を並べ、n＝−1 の行だけ ✕ と ln|t|。新しい数値例：∫t⁻²dt＝−t⁻¹、微分して t⁻² に戻る。②新しい数値例（加速度が変わる）：a＝6t m/s²、v(0)＝1 m/s、x(0)＝2 m → v＝1+3t²、x＝2+t+t³。t＝2 で v＝13 m/s、x＝12 m。一定加速度の公式では出ないことを、2つの扉（C₁＝初速度、C₂＝初期位置）の図で。
- 最後の問い：中級では連鎖律・積の微分を「差の比」で確かめた。上級ではそれを何の"証明"と言えるのか？ そして ln|t| の傾きが本当に 1/t だと、どう確かめる？

**前提（未習）**：「導関数が常に 0 なら定数」（平均値の定理。図で納得）、f の連続性（跳ぶ関数は扱わない）。ln の定義と微分（次の単元）。

## 3. um-rules（微分の法則・上級）— 中・2本
目標：差の比の極限から微分法則を証明し、複数変数が同時に変わる場合へ進む。
理由：本2（連鎖律は差の比の積の極限）・本6（積の角の項が消える）は中級 03-1 がすでに差の比で説明した → 振り返り1場面。上級の新しい中身は、その応用で ln・逆数・実数乗の微分を作ること（スライドに無い補い：um-integral 2/2 の ln|t|、um-ode の ln、um-taylor の (1+x)ⁿ、ue-gauss の √u・u^(−1/2) の前提になる）と、本10 の全微分の連鎖律。（上級に残る本：本2・本6・本10＝表示0〜2。本0・本3・本7 は初級、本1・本4・本5・本8・本9 は中級で使用済み。準備：ui-function-rules、um-function-rules）

**1/2 本2・本6（＋ln・逆数・実数乗の補い）「微分の法則を"証明"すると何が使える？――ln の傾きは 1/x」**
- 最初の問い：連鎖律・積の微分の"証明"から、ln|t| の傾きが 1/t だと言えるか？
- 要点：振り返り1場面：連鎖律 Δy/Δt＝(Δy/Δu)(Δu/Δt) の極限（本2）、積 Δ(fg)＝gΔf+fΔg+ΔfΔg の角の項が (Δf/Δt)Δg で 0 へ（本6）。上級で加える注意：使った仮定は「各関数が微分可能」。Δg→0 は微分可能から従う連続性。応用1（スライドに無い補い）：ln は「e の何乗か」を返す関数、e^(ln x)＝x（x>0）。両辺を微分し、連鎖律で e^(ln x)×(ln x)′＝1 → (ln x)′＝1/x（e^x の微分が e^x であることは初級・中級 08）。x<0 でも ln|x| の微分は 1/x（中身 −x の倍率 −1 が2回掛かる）→ um-integral 2/2 の ln|t| を確かめた。応用2：f×(1/f)＝1 を積の微分で微分 → (1/f)′＝−f′/f²。応用3：xⁿ＝e^(n ln x) → (xⁿ)′＝xⁿ×n/x＝nxⁿ⁻¹（n は実数でよい。√x で 1/(2√x)）。

## 29. ue-maxwell（マクスウェル方程式・上級）— 難・4本
目標：変位電流で電荷保存を確かめ、真空の波動方程式と光速を導く。
理由：変位電流、小さな長方形で周回積分を場の差に直す、B を消去して波動方程式、E と B の関係、シリーズの締め、と別々の段がある。中級 29-2 の台本で「この項が必要な理由の詳しい確かめは上級」と言い、初級 29-2 の台本で「光の速さを電場と磁場の法則から導くのは上級」と言った。（上級に残る本：本9〜本17＝表示0〜8。本0・本1・本7 は初級、本2〜本6・本8 は中級で使用済み。準備：ui-ac-waves、um-ac-maxwell）

**1/4 本9・本10「コンデンサのすき間に"電流"はあるのか？――変位電流と電荷保存」（中級 29-2 の回収）**
- 最初の問い：充電中のコンデンサのすき間を貫く電流はあるのか？
- 要点：充電中の導線のまわりに1つの輪を取る。輪を縁とする面を「導線を切る平らな面」にすると電流 I が貫く。「板の間を通る袋の面」にすると伝導電流は 0 → アンペールの法則（μ₀I だけ）は面の選び方で答えが変わり、矛盾する。板の間の電気束 Φ_E＝EA＝q/ε₀ → ε₀ dΦ_E/dt＝dq/dt＝I（電荷保存：導線から板へ流れ込んだ分だけ q が増える）。この項を加えると ∮𝐁·d𝐫＝μ₀(I＋ε₀ dΦ_E/dt) はどちらの面でも同じ（本9）。4本の法則がそろい（中級 29-2 の表の振り返り）、ファラデー（磁場の変化 → 電場の渦）とアンペール・マクスウェル（電場の変化 → 磁場の渦）が連鎖する → 電磁波の予感（本10）。
- 補助線：①同じ輪に、平らな面（電流が貫く）と袋の面（電気束が変わる）の2枚を張った図。②新しい数値例：I＝1 A、板の面積 0.01 m² → dE/dt＝I/(ε₀A)≈1.13×10¹³ V/(m·s)、ε₀ dΦ_E/dt に戻すと 1 A（導線の電流と同じ数）。
- 最後の問い：電場の変化が磁場を作り、磁場の変化が電場を作る。互いに生み合うなら、空間を伝わる波になるのでは？ その式を、一周の積分からどう取り出す？

**2/4 本11・本12・本13「一周の積分を小さな長方形に縮めると、場の"差"が現れる」**
- 最初の問い：一周の積分から、各点の場の式をどう取り出すか？
- 要点：電荷・電流のない真空、x 方向へ進み、𝐄 は y 方向（E_y）、𝐁 は z 方向（B_z）と絞る（本11）。xy 面の小さな長方形（横 dx、縦 dy）を +z から見て反時計回り：左右の辺の寄与 E_y(x+dx)dy−E_y(x)dy、上下の辺は 𝐄 と直角で 0（本12）。貫く磁束 B_z dx dy → ファラデーの右辺 −(∂B_z/∂t)dx dy。面積 dx dy で割ると ∂E_y/∂x＝−∂B_z/∂t（本13、偏微分：中級 03-2）。xz 面の長方形（法線 +y）で同じ計算をアンペール・マクスウェルに行い −∂B_z/∂x＝μ₀ε₀ ∂E_y/∂t。負号は法線と周回の向きの約束から。
- 補助線：①小さな長方形の4辺を色分け（右 +、左 −、上下 0）、x と x+dx の 𝐄 の矢印の長さの差。②新しい数値例：dx＝1 mm で E_y が 3.0 → 3.3 V/m なら差 0.3 V/m、1 mm で割って 300 V/m²（「差 ÷ 幅 → 偏微分」の一操作）。
- 最後の問い：2本の偏微分の式から B を消すと、E だけの式は何になり、どんな速さの波を表す？

**3/4 本14・本15「B を消すと波動方程式――速さ 1/√(μ₀ε₀) は光の速さ」（初級 29-2 の回収）**
- 最初の問い：B を消した E だけの式と、その波の速さは？
- 要点：1本目を x で微分：∂²E_y/∂x²＝−∂²B_z/∂x∂t。2本目を t で微分：−∂²B_z/∂t∂x＝μ₀ε₀ ∂²E_y/∂t²。同じ混合微分を置き換え（微分の順序は入れ替えてよい：前提）→ ∂²E_y/∂x²＝μ₀ε₀ ∂²E_y/∂t²（波動方程式、本14）。進む波 E_y＝f(x−ct) を入れる：x で2回微分 f″、t で2回微分 (−c)²f″＝c²f″ → 1＝μ₀ε₀c² → c＝1/√(μ₀ε₀)（本15）。μ₀ と ε₀ は電気・磁気の実験で測った定数なのに、出てきた速さが測られていた光速と一致 → 光は電磁波（本10 の歴史）。
- 補助線：①f(x−ct) の形が t＝0 と t＝1 で c だけ右へずれる図（初級 29-2 の「山が λ/T で進む」の式版）。②新しい数値例：μ₀ε₀＝4π×10⁻⁷×8.854×10⁻¹²≈1.113×10⁻¹⁷ s²/m² → c≈3.00×10⁸ m/s。混合微分の順序を sin(kx−ωt) で確かめる（どちらの順でも kω sin(kx−ωt)）。
- 最後の問い：波の速さが分かった。電場と磁場の大きさ・向きは、互いにどんな関係で進むのか？ そして、このシリーズで何ができるようになったのか？

**4/4 本17・本16「電磁波の 𝐄・𝐁・進む向き、そしてシリーズの終わりに」**
- 最初の問い：電場と磁場は、どんな関係で進み、シリーズで何ができるようになったか？
- 要点：E_y＝E₀ sin(kx−ωt) をファラデーの式 ∂E_y/∂x＝−∂B_z/∂t に入れる → B_z＝(k/ω)E₀ sin(kx−ωt)、B₀＝E₀/c（ω/k＝c）。𝐄 と 𝐁 は同位相で互いに直角、𝐄×𝐁 が進む向き（ŷ×ẑ＝x̂、um-cross の成分式で確かめる）。図の2色は物の変位ではなく、場の値を空間に描いたもの（本17）。締め（本16）：微分・積分で小さな変化を記述し、基本法則から運動と場を導いてきた。式が何を定義し、何を仮定し、どの範囲の実験を説明するかを読む。量子論や相対論では出発点をさらに広げる。
- 補助線：①3次元の一瞬の図：𝐄（水色）が上下、𝐁（橙）が前後、同じ位相で、進む向きの矢印＝𝐄×𝐁。新しい数値例：太陽光（1361 W/m²）の電場の振幅 E₀≈1000 V/m → B₀＝E₀/c≈3.4×10⁻⁶ T。②シリーズ全体の地図：数学9 → 力学10 → 電磁気10 の単元を点で並べ、「微分 → 運動方程式 → 仕事とエネルギー → 線積分・面積分 → ガウス → ファラデー → マクスウェル → 光」の太い道を光らせる（各点に初級・中級・上級で学んだ一言）。
- 最後の問い（シリーズ全体の締め）：マクスウェル方程式から出た光の速さ c は、止まった観測者にも、光を追いかける観測者にも、同じ値なのか？ もしそうなら、力学で当たり前に使ってきた「時間」と「空間」そのものを、どう書き直さなければならないのか？（→ 相対論へ。シリーズの外）

**前提（未習）**：偏微分の順序の入れ替え（シュワルツの定理。なめらかな場で成り立つと明言）、3次元のベクトル微分（div・rot。微分形の4本の法則は1方向の平面波に絞る）、偏光・電磁波のエネルギーの流れ（ポインティング・ベクトル、名前も出さなくてよい）。
