# 物質波の入り口：個別確認

- a-bohr-intro（64.4秒、手動3ページ）、ha-why-04（62.9秒、手動3ページ）。台本03の100 V、運動量約5.4×10⁻²⁴ kg·m/s、波長約0.12 nmを保持。
- 電子源と二つの隙間 → 一個ずつの記録 → 多数の干渉分布 → ド・ブロイの波長、の順。途中の経路や、電子が水面の波になるという描写を避けた。
- 縞は明示した模式的な確率分布から生成した点であり、実験の写真とは表示していない。どちらの隙間を通ったか測定しない条件を明記。
- 波長式のpはベクトルではなく運動量の大きさとして、m×速さと説明。非相対論的な範囲であることも表示。
- 数値例はp²/(2m)=Kを約分から組み立て、K=eVを代入、平方根、h/p、nm換算まで追加。
- 結晶を文字通り二重スリットと呼ぶ表現を、多数の原子で散乱された波の干渉へ修正。
