# 衝突と運動エネルギー

対象：m-momentum-advanced、hm-why-17。台本01の二台がくっつく衝突と、2 kg・3 m/s、1 kg・静止の数値例を維持。

対象を二台に決める → 外からの水平な力積を無視する条件 → 内力の力積の相殺 → 共通速度でくくる → 質量の合計で割る → 約分 → 運動エネルギーと比較、の順序。

- タイトルも「エネルギーが減る」から「運動エネルギーが減る」へ限定。熱・音・変形などへ移ったエネルギーを消失と扱わない。
- 主編86.1秒は3区切りで手動移動。補足59.2秒を指定の場面3の後に配置。
- 分子と分母を両方表示する途中式を追加。初回書き出しで分数の表示崩れを見つけ、TeXの二重エスケープを訂正して再書き出し・再確認。二重のfracを拒否する回帰テストを追加。
- 接触中の移動距離の比較図は、上下に分けた模式図であることを明記し、台車が離れたまま押し合う映像にしない。
- 補足では6 = 3Vを3で割り、2 m/sを得る。9 Jと6 Jを個別に計算して、差の3 Jを別の形への移行として表示。
- before・afterの意味も式の近くに記載。
