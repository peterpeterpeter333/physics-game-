# 大学編・1分動画（YouTube 用）制作基準

対象：大学編 29 単元（数学の武器庫 9・力学 10・電磁気学 10）× 初級／中級／上級 の「とことん」内容を、それぞれ約1分（55〜75秒）にまとめた横長動画（1280×760）。
順番は `src/content/university-curriculum.ts` の並び（um-derivative → … → ue-maxwell）、各単元で 初級 → 中級 → 上級。
アプリには入れない（YouTube 用のローカル出力）。アプリの既存動画・カタログ・区分（初級/中級/上級、さっと/とことん）には触れない。

## 内容の出どころ
- 各レベルの学習目標・例題・用語は、アプリのステージ本文に合わせる：
  初級 `src/content/levels/intro-*.ts`、中級 `middle-*.ts`、上級 `univ-math.ts`/`univ-mechanics.ts`/`univ-em.ts`、
  対応表 `university-curriculum.ts`（intro/middle の stage id、advanced の目標文）。
- 1分なので「そのレベルで一番大事な一歩」を一つだけ選び、とことん（なぜ？まで）で見せる。網羅しない。

## 構成（約1分・8〜11文）
現象・疑問 → 予想（必要なら）→ 図で調べる → 式を組み立てる → 計算 → 元の現象に戻る → 次の問い。機械的にこの型でなくてよい。
- 1文（cue）＝字幕2文まで・3行以内（1行44字）。1文に新しい要素は1つ。
- 最初の文で「何が分かるようになるか」が伝わる問いにする。最後は次の単元・レベルにつながる問い。
- 初級は完全初心者（高校の前提も曖昧）、中級は初級を見た人、上級は中級を見た人を想定。前のレベルで出た言葉は使ってよいが、突然の新語は初出で一言説明。

## 数式のルール（基準動画 v4 から引き継ぎ・改善）
- 今何を求めたいか／各文字の意味と単位／図のどこにあるか／既知と未知／なぜ掛ける・割る・足す・積分するか／何が分かったか を追えるようにする。
- 記号の説明は初出時にその近くへ短く。長い記号一覧は出さない。
- 式変形は一操作ずつ。代入する項・両辺に加える量・約分で消える因子を動き（移動・打ち消し線・枠）で示す。複数の項を一度に足して消さない。
- ナレーションは操作の目的を言う（「h で割って、1秒あたりに直します」）。
- 有限の近似（≈）と極限の等式、スカラーとベクトル、半径と位置の変化、量と変化率を混同しない。
- 定義／実験に支えられた原理／仮定／導いた結果 を区別する。
- 単位を正しく（例：6 N ÷ (2 A × 3 m) = 1 N/(A·m) = 1 T。1 N ではない）。

## 補助線
- つまずきを A（前提知識がない）と B（図と式の対応・次の一手の理由が見えない）に分け、最小限の補助線を付ける：数値例、同じ番号・色の対応、拡大・投影・分割・重ね合わせ、固定するもの／変えるものの対比、前後比較、比喩。
- 比喩は、絵で対応を示せるときだけ。「何が何に対応し、何は対応しないか」を必要な範囲で示し、必ず元の現象と式に戻る。比喩の説明が要るなら使わない。同じ概念には同じ比喩。
- 基準動画から直す点：k→ε₀ は「両替」ではなく ε₀＝1/(4πk) という別の定数の定義／部屋・改札の比喩で電荷保存（出入りの収支）とガウスの法則（中の電荷の量）を混同させない／線積分で「扇風機の風が円周方向に吹く」と思わせず、一歩を半径方向と接線方向に分ける図を優先。

## 画面と音声
- 画面の主役は一つ（図が主役なら図を大きく、式変形が主役なら式を大きく）。対応を示す瞬間は必要な一項だけ図の近くに残す。
- 上下・左右・手前奥・正負・色・番号を映像と語りで一致させる。3D は立体に意味があるときだけ。
- 色：位置 x 水色、速度 v 紫、加速度 a 赤、力 F 緑、時間 t 金、エネルギー E 橙、運動量 p 桃、強調 黄（`anim.mjs` の C）。電場 E は水色、磁場 B は橙（電磁気編）。
- 音声：VOICEVOX Nemo 男声1（speaker 10001、speedScale 0.90）。字幕（表示）と読み（reading）を分け、全 cue に kana（区切り・アクセント）を付けて照合する。
- BGM・効果音は `scripts/umech/mix-audio.py` の合成音のみ（外部素材なし）。効果音は意味のある瞬間だけ（1本に1〜2個）。

## 確認（正直に記録）
1. 台本確認：物理・数値・単位・符号の検算、読みの機械検査 0、kana 照合 0
2. 静止画確認：全 cue を実際の音声の時間で 3 時点（始め・中・終わり）目視（`mxr-review.mjs`）
3. 出力確認：MP4 のデコード検査と長さ
4. 想定レビュー（物理が苦手な大学1年生の目で）：知らない言葉／図のどこを見るか／計算の目的／前の説明だけで分かるか／覚えておく量／何が分かったか
- 連続再生・通しの聴取は、実施した場合だけ「実施」と書く。実際の初心者の視聴テストとは区別する。
