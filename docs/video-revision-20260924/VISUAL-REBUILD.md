# 全動画の再構成：制作・点検記録

## 目的と範囲

最新の依頼は全動画の再制作。円運動・万有引力で承認された、図で理由をつかみ、式変形を音声と動きで追える方式を各単元へ展開する。汎用の配色変更や字幕変更だけでは完成と扱わない。

公式参考：3Blue1Brownの [微分](https://www.3blue1brown.com/lessons/derivatives/) と [積分](https://www.3blue1brown.com/lessons/integration/)。具体的な運動・有限の変化・図形の変化から局所的な関係へ進む構成を参考にする。図、台本、アニメーションは本アプリ独自制作。

`visual-rebuild-inventory.generated.json` に公開中353本と、以前の差し替え計画中の未挿入167本を別状態で記録する。さらに問題・解説18本、旧単独動画の使用状況も点検対象。重複する差し替え版は別教材として数えない。

## 今回着手した制作単位

- 位置の変化から速度へ：初級・中級・上級の本編6本中3本。
- 速度の変化から加速度へ：初級・中級・上級の本編6本中3本。
- 入力：`motion-foundations.mjs`。既存のClaude原稿を保存したまま、説明のつながりを再編集。
- 図：`scripts/motion-foundation-visuals.mjs`。27種類の図を説明文単位で指定。未定義の図には代替図を出さず失敗させる。
- 音声：既存Nemo、明示的な読み、空白正規化。音声を変更していない再描画では音声を作り直さない。
- 全本編以外の前提動画・補足動画は、この6本の完成だけを理由に完了扱いしない。
- 未完成の台本にある補足を、存在する動画としてカタログへ登録しない。

## 制作基準と、点検の分担

|基準|機械点検|人が内容を見る点検|
|---|---|---|
|1. 知識のつながり|単元・難易度・経路の整合|既知の内容から結論へ進むか|
|2. 必要な段階だけ置く|場面の順序・再生区間|足踏み、重複、飛躍がないか|
|3. 今何を求めるか|台本・字幕の一致|目的、主語、量の意味が明確か|
|4. 短い文章、十分な論理|字幕が3行以内に収まるか|式が理解できる長さを優先できているか|
|5. 式の意味と導出|数式SVG、数値例・恒等式|式変形の目的と各操作の理由が語られるか|
|6. 図と式を別画面でつなぐ|各文にD/F指定、未定義図で失敗|ナレーションが指す図が実際に見えるか|
|7. 必要な立体を3Dに|2D/3Dは自動判定しない|今回の直線・平面円運動には2Dが適切か|
|8. 平易な言葉から用語へ|読み仮名の明示・一致|変位・極限・微分・ベクトルを突然出していないか|
|9. 前提と結論の範囲|具体例の式を数値検算|平均と瞬間、一定と変化を混同していないか|
|10. 操作の邪魔を減らす|0.9倍速、手動ページ、バトルの回帰テスト|スマホ相当の表示・途中停止・図欠落を見る|

テスト成功だけで「初学者全員に分かりやすい」とは断定しない。実動画のコマ確認は音声の全編聴取とは別。音声の読み指定・モーラ照合も、人による聞こえの評価とは区別する。

## 再現手順

1. 原稿を編集し、`applyMotionFoundations` で該当6本だけ全体計画へ反映する。全計画コンパイラを走らせると無関係な旧メタデータも変わるため、無差別には再生成しない。
2. 専用キャッシュの `plan.json` に対象本編だけ書き出す。
3. `render-em-film-audio.py` で音声、`render-all-films.mjs` で30fpsの動画を作る。
4. `test-motion-foundations.mjs` で全文・全表示指定、212個の時点、数学を検査。
5. `review-motion-encoded.mjs` で実MP4から全53発話の画像を抽出し、欠落・重なりを見る。
6. `register-motion-foundations.mjs` で音声・映像を全デコードしてから、対象6本のみ登録する。前提・補足の既存経路は保存する。
7. ビルド、再生速度、モード、手動ページ、バトル、円運動の回帰点検。検証に失敗した範囲を公開しない。

## 残作業

速度・加速度の関連前提・補足 → 高校力学の残り → 熱・波動 → 高校電磁気・原子 → 大学数学 → 大学力学 → 大学電磁気 → 問題・解説動画の順に、同じ制作・点検を行う。全範囲の完了宣言には、各教材の台本・実映像・経路の記録が必要。
