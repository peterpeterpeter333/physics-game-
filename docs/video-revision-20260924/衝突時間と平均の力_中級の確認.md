# 衝突時間と平均の力（中級）

対象：m-momentum-middle。差し替え台本01の60 g・5 m/s、0.01 s・0.1 sの例を維持。

クッションの変形 → 同じ運動量変化 → 同じ力積の面積 → 両側を時間で割る → 平均と最大の違い → 数値計算 → 合力と接触力の違い、の5区切り。122.8秒の映像は区切りごとに手動で進める。

重要な訂正：30 Nと3 Nは平均の合力であって、床やクッションからの接触力ではない。上向きを正として、平均接触力は平均合力に重力0.588 Nを加え、約30.6 N・3.6 Nになる。接触力そのものを「正確に10分の1」とは説明しない。

- 卵が跳ね返らずに停止する条件を明記。落下速度−5 m/sから0への変化は+5 m/s。
- 同じ面積を保ちながら長方形が広がる図と、同じ平均値でもピークが異なる図を別々に用意。
- 小さい平均力だけで「必ず割れない」と断定しない。
