# 円運動と万有引力：式変形アニメーション試作

## 初学者目線の10点を反映した再改訂

| 点検項目 | 修正内容 |
|---|---|
| 図の配置と言葉 | 相似の説明を「上の位置の三角形／下の速度の三角形」に統一 |
| 速さ一定でも加速度 | 初級から速度の向きの変化を加速度と結び付ける |
| Δvの意味 | 前・後の速度を平行移動し、前の先端から後の先端へ赤い矢印を描く |
| 相似の根拠 | 半径を90度回す図、回転・縮小で重なる図、対応辺の強調を追加 |
| 時間で割る目的 | 1秒あたりに直す目的と、6 m/s ÷ 2 sの具体例を追加 |
| 極限 | 球の実際の道のりと近道を分け、同一区間を拡大して長さの比を表示 |
| 加速度の方向 | 前の位置に移した速度変化の方向が中心へ近づく図を追加 |
| 記号読み上げの負荷 | 計算操作と物理的意味を中心に語り、文字そのものは画面で追う |
| 計算から分かること | 同じ円軌道の軽い衛星と重い衛星が同じ速さで進む図を追加 |
| 図が小さい | 三角形・拡大図・速度比較を画面幅に展開し、ラベルを図に直接配置 |

中級・上級は本編を各3ページに分ける。さっと／とことんの両方で
区切りを表示し、とことんだけ補足ページも加える。自動で別動画には移らない。
原本の追補は circular-clarity.mjs、専用図は circular-clarity-visuals.mjs。
台本・読み・描画・数式・同期をテストするが、実際の初心者の理解を保証するものではない。

今回の検証：66音声文・264描画時点、6本のMP4全編デコード、
字幕と台本の一致、25本の回帰スクリプト、速度・手動ナビゲーション・バトル検査が通過。
生成MP4から取り出した相似の場面も目視確認した。
本編は48.4秒／159.1秒／114.0秒、補足は17.3秒／20.4秒／22.8秒。
アプリ上で中級の「さっと」3ページ／「とことん」4ページと0.9倍速を確認。
音声の聴感や実際の学生の理解度まで自動テストで保証した、という意味ではない。

## 単一表示と再生速度の改訂

- 6本の動画は音声文ごとに「図のみ」「式変形のみ」を選択し、同時には表示しない。
- 式変形は画面中央に拡大し、図の説明中には数式パネルを出さない。字幕は両方に残す。
- 本編・補足・問題・解説・旧線積分プレーヤーに共通の速度メニューを追加。
- 標準0.9倍。0.5／0.75／0.9／1／1.25／1.5／2倍から選択し、端末内に保存。
- 既存音声を再合成せず、動画のplaybackRateを変更するため映像・字幕・音声の同期は保たれる。
- ブラウザーで初期0.9倍、1.25倍への変更、難易度変更後の保持、0.9倍への復帰を確認。
- 描画検査では全184時点で図と式が併存しないことを検査。以下は初版の設計記録。

対象は高校 `m-circular` の初級・中級・上級と専用補足3本のみ。
台本・読み・数式・操作・図の対応は `circular-pilot.mjs` が原本。
ユーザーの「式変形の説明不足_改善案.md」の、一段につき声で説明する方針を採用した。
3Blue1Brown公式教材 https://www.3blue1brown.com/lessons/derivatives/ の
有限の変化を図で見せてから極限へ進む説明を参考にした。映像や音声の転用はない。

## 設計

- 本編だけでも導出を省略しない。「とことん」では作用反作用、速さ2倍、分数の逆数を補足する。
- v（青）、r（黄）、m（紫）、M/G/F/a（赤）、T（緑）を図と式で対応させる。
- 直前の式と現在の式を最大2段で表示し、共通の項を移動、変更部分を枠で強調する。
- 分数も文字も同じ数学フォントサイズ・ベースラインで描く。
- 全ての式の進行は合成音声の文の開始時刻に連動。30fpsで生成する。
- 弧と弦は同一視しない。相似では直線距離ℓを使い、Δt→0でℓ/Δt→vとする。
- 万有引力は実験に基づく法則、導くものは円軌道の速さと周期。M≫mの近似を明記。
- 大文字Mと小文字mを区別し、両辺÷m、両辺×r、二乗、代入、逆数、r²×rを順番に説明。
- 古い共通前提動画の内容は本編に統合。この章だけその自動挿入を止め、他章は変更しない。
- バトル・4択・ダメージ演出は変更しない。

## 検証

`node scripts/test-circular-pilot.mjs` で全音声文の複数時点のSVG、数式構文、
読みの空白、相似と極限、周期、二乗、逆数、章内の前提ルートを確認する。
レンダリング後は `register-video-revision-batch.mjs m-circular` による全MP4デコード、
音声・動画長、台本・字幕一致を確認してからアプリのカタログに登録する。
自動テストだけで人間の理解しやすさ・聴感まで保証するものではない。
