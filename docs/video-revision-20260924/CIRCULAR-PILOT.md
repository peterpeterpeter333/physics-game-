# 円運動と万有引力：式変形アニメーション試作

対象は高校 `m-circular` の初級・中級・上級と専用補足3本のみ。
台本・読み・数式・操作・図の対応は `circular-pilot.mjs` が原本。
ユーザーの「式変形の説明不足_改善案.md」の、一段につき声で説明する方針を採用した。
3Blue1Brown公式教材 https://www.3blue1brown.com/lessons/derivatives/ の
有限の変化を図で見せてから極限へ進む説明を参考にした。映像や音声の転用はない。

## 設計

- 本編だけでも導出を省略しない。「とことん」では作用反作用、速さ2倍、分数の逆数を補足する。
- v（青）、r（黄）、m（紫）、M/G/F/a（赤）、T（緑）を図と式で対応させる。
- 直前の式と現在の式を最大2段で表示し、共通の項を移動、変更部分を枠で強調する。
- 分数も文字も同じ数学フォントサイズ・ベースラインで描く。
- 全ての式の進行は合成音声の文の開始時刻に連動。30fpsで生成する。
- 弧と弦は同一視しない。相似では直線距離ℓを使い、Δt→0でℓ/Δt→vとする。
- 万有引力は実験に基づく法則、導くものは円軌道の速さと周期。M≫mの近似を明記。
- 大文字Mと小文字mを区別し、両辺÷m、両辺×r、二乗、代入、逆数、r²×rを順番に説明。
- 古い共通前提動画の内容は本編に統合。この章だけその自動挿入を止め、他章は変更しない。
- バトル・4択・ダメージ演出は変更しない。

## 検証

`node scripts/test-circular-pilot.mjs` で全音声文の複数時点のSVG、数式構文、
読みの空白、相似と極限、周期、二乗、逆数、章内の前提ルートを確認する。
レンダリング後は `register-video-revision-batch.mjs m-circular` による全MP4デコード、
音声・動画長、台本・字幕一致を確認してからアプリのカタログに登録する。
自動テストだけで人間の理解しやすさ・聴感まで保証するものではない。

## 今回の確認結果

- 本編：初級46.4秒、中級83.3秒、上級105.1秒。補足：13.2秒、15.1秒、22.8秒。
- 46音声文・184時点の描画検査、全6本のMP4デコード、字幕一致、全体の回帰検査とビルドが通過。
- ローカルのアプリ画面で新タイトル、難易度切り替え、さっと／とことん、バトルへのボタンを確認。
- 上級動画のメタデータは105.1秒、readyState=4、エラーなしで読み込めた。
- 埋め込みブラウザーは再生ボタンを押すと対象タブが閉じたため、この環境での連続再生確認は未完了。
  これを「実機での全編視聴済み」とは扱わない。
