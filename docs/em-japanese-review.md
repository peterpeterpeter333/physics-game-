# 電磁気の動画解説：日本語・説明の分かりにくさの監査

## 対象と読み方

対象は現在の大学電磁気・初級16単元、中級14単元、上級10単元。動画100本に対応する台本315場面を通読し、動画画面の補足生成処理も確認した。原文は `src/content/em-video-narration.ts`、動画との対応は `src/content/em-video-catalog.generated.json`。アプリ全分野の監査ではなく、直前まで話題にしていた電磁気動画の監査である。

「物理と数学に苦手意識があり、専門用語から具体的な場面を想像するのが難しい大学1年生」を想定した机上レビュー。偏差値で理解力を断定したものではなく、実際の学生のユーザーテストでもない。今回は動画を全本再生して音と図の同期を評価したものではない。図で補えている可能性がある箇所も、音声文だけでは負担になる点として記録した。

以下は今回見つけた指摘の全件。原文欄は連続した抜粋。場所の番号は各単元の台本内での場面番号（1始まり）であり、動画番号ではない。未掲載の文まで完全に分かりやすいと保証するものではない。

分類：**文**＝不自然・係り受けが曖昧な日本語、**指示**＝対象・基準・操作が不明、**用語**＝名前だけで意味が浮かばない、**接続**＝説明間の橋渡し不足、**条件**＝言い方が必要条件を隠し誤解を誘う。専門語そのものを消すのではなく、初出で意味を添える方針。

修正方向は編集用メモで、完成台本ではない。今回は教材本体や動画を変更していない。

## 修正の優先順位

1. 文の意味を誤らせる表現。「本数は比喩」「球面積の二乗」「電荷と速度と磁場の外積」「面と磁場の角度」。
2. 操作や比較対象が分からない表現。「それぞれ」「その係数」「両端の差」「追加の条件」「前の問いを使う」。
3. 抽象語が説明を代行している表現。「寄与」「集計」「対応」「整合」「式を与える」。
4. 耳で保持しづらい式の直訳。長い掛け算、分数、二階微分などは、画面上の式と短い意味の説明を組にする。

どの指摘も全ての場面で長い説明を追加するという意味ではない。一度導入した言葉は再利用できる。初出を具体化し、同じ量を一貫した名前で呼び、一文に一つの操作を置く。日本語の明快さは初級・中級・上級で共通とし、変えるのは計算の深さにする。
