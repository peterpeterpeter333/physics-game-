# 電磁気の学習のつながり

大学編の最初の2章は `em-spiral.ts` と `SpiralLesson.tsx` を使用する。
以前の質問一覧・マイクロスライドは保存するが、この2章の表示には使用しない。

各段は「基本事項 → よくある疑問 → つながったこと」。前提と、次に使える知識を明示する。
本文は180文字以内。詳細な導出・物理的前提は折り畳みから確認できる。進行のロックは設けない。

## 第1章

一定力の仕事と長方形 → 小区間の和 → 一次関数の積分と三角形
→ 電場と仕事の内積 → 道のパラメータ表示 → 変化する場の線積分
→ 経路と電位差 → 面積ベクトルと電気束 → 二重積分 → 球面の面積要素。

一定値・一次関数の積分を、曲線上の仕事と正方形の電気束の計算で再利用する。
元の線積分・面タイル図は改変しない。磁場Bの図は磁束の復習であることを明記する。

## 第2章

クーロンの法則と球面積 → 球の電気束 → 中心のずれた球の内積
→ 置換積分 → 内部・外部の評価 → 立体角 → 任意の閉曲面と重ね合わせ
→ ガウスの法則の対称性を使った応用 → 束ゼロと場ゼロの区別。

クーロンの法則は数学から導くのではなく、静電気の物理的前提として扱う。
ずれた球は面を取り直さずに計算する。その後、立体角と符号付き交差で一般化する。
