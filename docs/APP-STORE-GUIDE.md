# App Store 提出ガイド (iOS)

Physics Quest を App Store に出すための手順と、審査に必要な入力内容をまとめたもの。

---

## 0. 必要なもの(先に揃える)

| 必要 | 内容 | 代替手段 |
|---|---|---|
| **Mac** | Xcode(Mac専用)がないとApp Storeへ提出できない | 中古Mac mini / MacBookを借りる / [MacinCloud](https://www.macincloud.com/) 等のクラウドMac(月2〜3千円) |
| **Apple Developer Program** | **$99 / 年**(買い切りではない) | なし。個人名義でよい |
| **iPhone(任意)** | 実機確認用。シミュレータでも提出は可能 | Xcodeのシミュレータ |
| Apple ID | 二段階認証を有効にしておく | — |

> **Windowsだけでは提出できません。** これがiOS版の最大の関門。

---

## 1. Macでプロジェクトを準備する

```bash
git clone https://github.com/peterpeterpeter333/physics-game-.git
cd physics-game-
npm install
npx cap add ios          # iOSプロジェクトを生成 (Macでのみ実行可能)
npm run sync             # ビルド + iOSへ反映
npx @capacitor/assets generate --ios \
  --iconBackgroundColor '#0b1026' --splashBackgroundColor '#0b1026'
npm run open:ios         # Xcode が開く
```

CocoaPods が未導入なら先に `sudo gem install cocoapods` を実行。

---

## 2. Xcodeでの設定

1. 左のツリーで **App** を選択 → **Signing & Capabilities** タブ
2. **Team**: Apple Developer Program のアカウントを選択
3. **Bundle Identifier**: `app.physicsquest.game`(`capacitor.config.ts` と一致させる)
4. **General** タブ → **Display Name**: `Physics Quest`
5. Deployment Target: iOS 14.0 以上でよい
6. 実機かシミュレータを選んで ▶ で起動し、動作確認

---

## 3. アーカイブして提出

1. 上部のデバイス選択を **Any iOS Device (arm64)** に変更
2. メニュー **Product → Archive**(数分かかる)
3. Organizer が開く → **Distribute App** → **App Store Connect** → **Upload**
4. アップロード完了後、[App Store Connect](https://appstoreconnect.apple.com/) に反映されるまで10〜30分待つ

---

## 4. App Store Connect に入力する内容(コピペ用)

### 基本情報

| 項目 | 内容 |
|---|---|
| App名 | Physics Quest — 高校物理RPG |
| サブタイトル | 暗記しない物理。理解して攻略する |
| プライマリカテゴリ | 教育 |
| セカンダリカテゴリ | ゲーム |
| 言語 | 日本語 |
| プライバシーポリシーURL | `https://peterpeterpeter333.github.io/physics-game-/privacy.html` |
| サポートURL | `https://github.com/peterpeterpeter333/physics-game-` |
| 価格 | 無料 |

### キーワード(100文字以内・カンマ区切り)

```
物理,物理基礎,高校物理,受験,大学受験,勉強,学習,公式,力学,電磁気,波動,熱力学,原子,問題集,ゲーム
```

### 説明文

```
「暗記は絶対ダメ。理解できる喜びを、ゲームの気持ちよさで。」

Physics Quest は、高校物理を RPG のように攻略しながら学べる学習アプリです。

■ すべての公式に「導出」がある
x = v₀t + ½at² の「½」は、v-tグラフの三角形の面積から来ています。
本アプリは、すべての公式について「なぜそうなるか」を1ステップずつ組み立てます。
丸暗記を求める説明は、ひとつもありません。

■ 24種類の動く図解
グラフの面積が距離になる様子、気体分子が壁を叩いて圧力を生む様子、
ドップラー効果で波面が詰まる様子 — 文字だけでは伝わらないことを、
実際に動く図で見て理解できます。一部の図はスライダーで操作できます。

■ バトルで演習
制限時間つきの一問一答でモンスターのHPを削ります。
正解でダメージ、連続正解でコンボ、間違えるとハートが減少。
不正解でも必ず「なぜそうなるか」の解説が読めます。

■ 収録内容
・5分野27ステージ、142問(すべて基礎レベル中心のオリジナル問題)
・力学 / 熱力学 / 波動 / 電磁気 / 原子
・公式集48本(それぞれ導出レッスンへリンク)
・スターを付けた問題をまとめて復習

■ こんな人に
・物理の公式を覚えられない、意味が分からない
・定期テストや大学受験の基礎固めをしたい
・机に向かうのは苦手だけどゲームなら続けられる

完全オフラインで動作。アカウント登録は不要です。
```

### 年齢制限(レーティング)

すべての項目に「なし」を選択 → **4+** になります。
(暴力・性的表現・ギャンブル・SNS機能のいずれも含まないため)

### App プライバシー(重要)

「データを収集しない」ではなく、以下を申告します。

| 質問 | 回答 |
|---|---|
| データを収集していますか? | **はい** |
| 収集するデータの種類 | **使用状況データ → 製品インタラクション** |
| 用途 | **アナリティクス** |
| ユーザーに紐付けられますか? | **いいえ** |
| ユーザーの追跡に使用しますか? | **いいえ** |

> 匿名の利用統計(どのステージが遊ばれたか)のみ。氏名・連絡先・位置情報などは一切収集しません。

### スクリーンショット(必須)

6.7インチ(iPhone 15 Pro Max 等)で最低3枚、以下がおすすめ:

1. クエストマップ(5分野が並んだ画面)
2. レッスンの図解(v-tグラフの面積 or 気体分子)
3. バトル画面(敵とHPバーと問題)
4. 正解フィードバック(解説が出ている画面)
5. 公式集

Xcodeのシミュレータで該当機種を選び、`⌘S` で撮影できます。

## 5. 審査対策(ガイドライン 4.2 について)

Appleは「Webサイトを表示するだけのアプリ」を却下します(4.2 最低限の機能)。
本アプリは以下の点で対策済みです。**審査コメント欄にこの内容を書いておくと通りやすくなります。**

- コンテンツ(142問・24図解)は**すべてアプリ内に同梱**され、**完全オフラインで動作**する
- 正解/不正解時の**触覚フィードバック(Haptics)**を実装
- ネイティブのスプラッシュ画面・ステータスバー制御を実装
- 独自に執筆した学習コンテンツであり、既存Webサイトの再表示ではない

**AI先生機能はネイティブ版では非表示にしています**(`src/config.ts` の `SHOW_AI_CHAT`)。
利用者自身のAPIキーが必要な機能は審査員が検証できず、ガイドライン2.1に抵触する恐れがあるため。

### 審査コメント欄の記入例

```
本アプリは高校物理の学習アプリです。
142問の演習問題、27の解説レッスン、24種類のアニメーション図解を
すべてアプリ内に同梱しており、ネットワーク接続なしで全機能が動作します。
外部Webサイトの表示は行っていません。
アカウント登録やログインは不要で、すべての機能をそのままご確認いただけます。
```

---

## 6. 提出後

- 審査は通常**1〜3日**。初回は長めにかかることがある
- リジェクトされた場合、Resolution Center に理由が届く。多くは修正して再提出すれば通る
- 承認後、「販売開始」を手動または自動リリースに設定

---

## 補足: 費用を抑えたい場合

**まず Google Play($25買い切り・Windowsのみで完結)から始めるのが安全です。**
ストア公開の実務を一度経験してから、Macを用意してApp Storeに挑む方が失敗が少なく、
$99/年の課金開始も後ろ倒しにできます。

なお、App Storeに出さなくても、**iPhoneのSafariで公開URLを開き「ホーム画面に追加」すれば
アプリとして全画面で動作します**(オフライン対応済み)。費用も審査もかかりません。
