# 大学電磁気・最初の2章の導出設計

対象は `ue-integrals` と `ue-gauss` のみ。他の54ステージの教材・問題データは変更しない。

## 到達点

- 線積分：指定した曲線の位置・接線・電場から被積分関数を作り、電子に対する電気力の仕事を積分する。外力で運ぶ例であり、電場線を電子の自由軌道として描かない。
- 面積分：小片、法線、射影、面のパラメータ、接線の外積から二重積分を作る。球面積要素と非一様な場の正方形の電気束を実際に積分する。
- ガウスの法則：クーロンの法則と重ね合わせを出発点にする。偏心球を変更せず内積・置換・原始関数・上下限を計算。符号付き立体角で任意の閉曲面へ一般化してから複数電荷を足す。
- 証明後の応用を明示的に分離する。同心球を選ぶことを一般のガウスの法則の証明としない。

## 前提と限界

数学の全公理を導出する教材ではない。実数、座標、高校代数、三角関数、微分と極限の定義を前提として明記する。積の微分、連鎖律、三角関数の微分、基本定理の補足は使用箇所に付ける。

ガウスの法則の証明は真空の静電場。区分的に滑らかな自己交差しない閉曲面を扱い、点電荷が面上にある特異な場合は除く。一般の時間依存場の証明とは区別する。

## 検証

`npm run test:guided` は各段階のSVG・数式画像・前提/目標/結論を検査する。また、元の偏心球の被積分関数の数値積分と解析的な上下限評価を、内外の複数のずれ・半径について比較する。電子の仕事の数値積分・累積関数の微分・力と接線の内積を照合する。
